# 营地 UI 规整：星座符命痕 + 共用固定库存格

日期：2026-07-31  
状态：实现完成；计划见 `docs/superpowers/plans/2026-07-31-camp-ui-glyph-inventory.md`  
关联：`CampView` / `CampMinghenLayout` / `CampEquipmentLayout` / `specs/260608-pve-destiny-expedition/design.md`  
前置：`2026-07-28-minghen-camp-synth-ui-design.md`、`2026-07-28-equipment-camp-synth-ui-design.md`、`2026-07-31-camp-materials-v1-design.md`

## 1. 目标

1. 命痕台与装备台视觉规整：装配/穿戴/库存/合成材料格统一为**同边长正方形**。
2. 命痕不再用小格文字名；用代码绘制「象形星座符」，装配与库存一致展示；点击看详情。
3. 共用库存固定 **25** 格空位（5×5），版面不因物品增减上下跳动。
4. 保留命痕台 / 装备台分台（装配与合成逻辑不同）；下方库存共用，滤镜切换。

## 2. 已定决策

| 项 | 选择 |
|---|---|
| 物品区分 | **C**：分台装配 + 共用库存 + 滤镜；材料不单独开 Tab |
| 起步容量（UI） | **25**；规划扩容 `25→35→45→60`（本轮不做经济） |
| 本轮范围 | **A**：只做 UI 规整；扩容扣费/云端容量字段留后 |
| 命痕视觉 | 星座骨架 + 象形笔画；稀疏连线；青白/淡紫荧光；**禁止孤立星点** |
| 页面 | 两台都带共用 25 格；默认滤到本台类型 |
| 实现路径 | 最小改动：现有 `CampView` + Layout；符号纯函数模块 + Graphics |

## 3. 页面结构

营地 Tab 不变：命痕台 / 装备台 / 远征情报 / 角色区。本轮只改前两个。

### 3.1 命痕台（上→下）

1. 摘要（收集/装配/星尘等，可含 `库存已用/25`）
2. 已装配：固定 **10** 格（5×2，正方形 + 星座符或空槽）
3. 滤镜：`命痕 | 装备 | 材料 | 全部`（默认命痕）
4. 共用库存：固定 **25** 格
5. 命痕合成区（现有三角台逻辑保留；格子改正方形 + 符号）

### 3.2 装备台（上→下）

1. 摘要（背包占用/星尘/材料数量可并入摘要或材料滤镜下）
2. 穿戴：5 槽，正方形，同边长
3. 滤镜（默认装备）
4. 同一套共用库存 25 格
5. 装备合成区（上 1 下 3，同尺寸；逻辑不变）

### 3.3 版面锚定（防跳动）

- 库存区块**外层高度**始终按 25 格（5 行）计算。
- 合成区 Y、整页 `contentHeight` 只依赖该固定高度 + 装配区，**不**依赖当前已用数量。
- 过滤后物品 ≤ 25：填格 + 画空槽。
- 过滤后物品 > 25（旧档装备上限仍可能到 60）：库存区块**内部**可滚动，外层高度与合成锚点不变；摘要提示持有数。硬容量与扩容经济留后对齐。

## 4. 共用库存口径（本轮 UI）

数据源仍三分，仅 UI 合成展示：

- 命痕：未装配剩余副本（`copies − 已装则1`；无剩余不列出）
- 装备：未穿戴实例
- 材料：`quenchSand` / `fusionCore` 各占 1 格 + 数量角标（种类少，不占几十格）

滤镜只替换 25 格内容，不重算外层高度。空槽点击无操作。

点击：

- 命痕 → 现有详情（装/卸、追踪、投合成）
- 装备 → 现有详情（锁/强化/出售/投合成）
- 材料 → 简单说明弹层（名称、用途、持有量）；本轮不可拖入操作

## 5. 命痕符号（`MinghenGlyph`）

### 5.1 模块

- 新建纯逻辑：`assets/scripts/pve/core/minghen/MinghenGlyph.ts`（**禁止** `import 'cc'`）
- 输入：`minghenId`（及可选 category 调色）
- 输出：确定性笔画数据（节点、线段）
- 视图：`Graphics` 绘制（装配格 / 库存命痕格 / 合成材料格共用）

### 5.2 形状规则

- 由 id 确定性哈希选择象形骨架族（杖/人、眼、山门、钩折、角符等），再微调节点。
- 星点约 4–7；笔画 1–3 段；像简化象形文字，不是封闭星座多边形。
- **硬约束：每个星点度数 ≥ 1**（禁止孤立点；生成后校验，失败则回退到保底连通模板）。
- 同 id 图案稳定；I/II 共用形状，阶位只在详情文案标出。
- 小格内不写命痕名。

### 5.3 绘制

- 圆底暗底 + 细边
- 线：青白/淡紫；先半透明粗描（光晕）再实线细描（可双层）
- 星点：亮芯 + 轻外晕

## 6. 格子尺寸

- 共用常量 `CAMP_SLOT_SIZE = 96`（与现装备台背包格对齐）。
- `CampMinghenLayout` 废除扁矩形 `106×64`；装配/拥有/合成与装备台同边长 96。
- `CampEquipmentLayout` 穿戴/背包/合成对齐同一常量（穿戴若原为 88，本轮一并改为 96）。

## 7. 实现边界（最小改动）

改：

- `CampMinghenLayout.ts` / `CampEquipmentLayout.ts`（尺寸与 `*ContentMetrics` 按固定 25 行）
- `CampView.ts`（正方形格、符号绘制、滤镜、固定空位）
- 新建 `MinghenGlyph.ts`（+ 单测：稳定性、无孤立点、多样本快照可选）

不改（本轮）：

- 云端容量/材料扩容经济
- `minghenCollection` / `equipmentInventory` / `materials` 数据结构
- 装配槽数 10、穿戴 5 槽规则
- 情报区 / 角色区
- Controller 装配/合成权威回调语义（仅适配新点击入口若需要）

## 8. 非目标

- 背包扩容消耗与云端 `bagCapacity` 字段
- 统一背包权威数据模型
- 命痕 PNG/图集资源
- 营地整页架构重写

## 9. 验收

1. 命痕台与装备台相关格子同为正方形、同边长。
2. 命痕装配/库存/合成格为代码符号；小格无名称文字；点击有详情。
3. 任意命痕符号无孤立星点；同 id 两次生成一致。
4. 库存外层始终按 25 格占位；增减物品、切滤镜时合成区不跳。
5. 命痕台默认滤「命痕」，装备台默认「装备」；「全部」可混看。
6. 装/卸、强化、出售、两类合成不回归。
