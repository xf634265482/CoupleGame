# 饰品类型分化与品质阶段

日期：2026-08-04  
状态：已确认方向（设计评审通过，待实现计划）  
关联：`specs/260608-pve-destiny-expedition/design.md`、`specs/260712-pve-persistent-floor-progression/equipment-catalog.md`、`docs/superpowers/specs/2026-08-04-shoes-type-quality-design.md`、`assets/scripts/pve/core/EquipmentSystem.ts`

## 1. 问题

饰品槽 17 件目录存在与改版前鞋子类似的问题：

- 主玩法几乎只有一条线：`baseStat` 当「灵气获取 +N%」，品质只是把同一数字拉高。
- 名字上的「灵气 / 幸运 / 财运」大多只是风味；仅约 1/3 挂 `trinket_gold`，且非传奇财运的星尘加成未真正接线。
- 口径打架：UI/注释写灵气%，`EquipmentProgression` 却把饰品 `baseStat` 计入最大生命；永久层灵气获取也不稳定吃到该百分比。
- 质变几乎只在三件橙装传奇上。

## 2. 目标

1. **类型有区别**：灵气 / 幸运 / 财运三岔，像鞋子轻/战/铁一样可构筑选择。
2. **品质有区别**：白/绿薄灵气%；蓝起分支身份；紫专精；橙顶配 + 传奇。
3. **主数值统一为灵气获取 %**；饰品不再贡献最大生命。
4. **保留现有 17 个中文名**，只改归属、区间与效果挂载。
5. **永久层与非永久层**灵气获取都吃主数值百分比；财运星尘%真实生效。

非目标（本轮不做）：

- 新增/删除饰品条目；重做 Boss 战利品饰品 trait 线。
- 改命痕灵气相关效果，或重做灵气爆发职业系统。
- 其它槽位再分化（鞋已完成）。

## 3. 核心模型

| 层 | 含义 | 成长方式 |
|---|---|---|
| 主数值 | 灵气获取 +N% | `baseStat` × 品质倍率 × 强化；白/绿即有薄加成 |
| 类型效果 | `trinket_spirit` / `trinket_luck` / `trinket_gold` | 由**实例品质**查阶段表；不读旧「有无 gold 标签」凑合逻辑 |

品质节奏（对齐鞋子）：

| 品质 | 感知 |
|---|---|
| COMMON / FINE | 只有薄灵气%，无分支专精 |
| RARE | 分支身份开启 |
| EPIC | 本支专精加强 |
| LEGENDARY | 本支顶配 + 传奇独特 |

同阶主数值相对关系：**灵气饰 ≥ 幸运饰 ≥ 财运饰**（财运用星尘收益补短板）。

## 4. 品质阶段表

### 4.1 灵气饰 `trinket_spirit`

| 品质 | 类型效果 |
|---|---|
| COMMON / FINE | （无） |
| RARE | 击杀获得 +5 灵气（永久层 spirit / 非永久 anima，按模式入账） |
| EPIC | 击杀 +8 灵气；灵气爆发后回复 8 HP |
| LEGENDARY | 击杀 +10 灵气；爆发回 12 HP；再叠加传奇 |

### 4.2 幸运饰 `trinket_luck`

| 品质 | 类型效果 |
|---|---|
| COMMON / FINE | （无） |
| RARE | 主动攻击暴击率 5%（伤害 ×2） |
| EPIC | 暴击率 10% |
| LEGENDARY | 暴击率 12%；再叠加传奇连击 |

暴击与噬魂斧必暴、Boss `boss_crit_15` **独立掷骰**（每次相关判定仍消耗 RNG，满足 AC-13）。多来源暴击：任一触发即按 ×2 结算，不叠乘为 ×4。

### 4.3 财运饰 `trinket_gold`

| 品质 | 类型效果 |
|---|---|
| COMMON / FINE | （无） |
| RARE | 星尘（字段 `gold`）获取 +15% |
| EPIC | 星尘 +25% |
| LEGENDARY | 阶段表星尘 +30%；再叠加传奇（财神赐福 +80% 等，加算） |

白/绿财运饰**不再**展示虚假「星尘获取加成」；仅蓝起有真实星尘%。

## 5. 主数值区间（灵气获取 %）

| 目录品质档 | 灵气饰 | 幸运饰 | 财运饰 |
|---|---|---|---|
| COMMON | 5–9 | 3–7 | 2–6 |
| FINE | 10–16 | 7–13 | 5–11 |
| RARE | 16–22 | 12–18 | 9–15 |
| EPIC | 22–30 | 17–24 | 13–20 |
| LEGENDARY | 32–40 | 27–35 | 22–30 |

生效灵气加成：`round(获得量 × (1 + 生效主数值/100))`，永久层与非永久层同一公式。强化/品质倍率规则与其它装备一致。

## 6. 目录映射（17 名保留）

| 类型 | 装备名 |
|---|---|
| 灵气 ×6 | 灵力宝珠、聚灵碧玉、灵魂宝珠、英雄徽章、命运碎晶、命运护符 |
| 幸运 ×5 | 幸运铜币、幸运吊坠、幸运宝典、幸运圆盘、幸运女神眼 |
| 财运 ×6 | 财运符、财运挂件、聚财宝石、财运宝玉、财神徽章、财神赐福 |

归属约定：

- **英雄徽章 / 命运碎晶** → 灵气（贴命运护符线）。
- **聚财宝石** → 财运。
- 幸运刻意少 1 件。
- 现有 `IMPLICIT_TRINKET_GOLD` 保留 id，扩展为财运类型阶段表入口；新增 `trinket_spirit` / `trinket_luck`。

## 8. 废止与修正

- 饰品 `baseStat` / scaledStats **不得**再写入 `maxHp`。
- `EquipmentDefinition` 中 `trinket_gold → fixed.spiritGain: 0.1` 删除；灵气%只走主数值。
- UI：主属性保持「灵气 +x/y%」；详情展示类型名 + 当前品质已解锁阶段效果；白/绿提示「稀有品质起生效分支效果」。
- 掉落星尘结算读取财运阶段表（及传奇加算）；非财运类型星尘加成为 0。

## 9. 战斗 / 经济接入点（实现指引）

- 阶段表 API：对齐鞋子 `resolveShoesStageEffects`，新增 `resolveTrinketStageEffects(implicit, quality)`。
- 灵气%：`AnimaSystem.addAnima` 与永久层 spirit 入账路径统一读取生效主数值。
- 击杀灵气 / 爆发回血：`CombatSystem` 或永久层击杀/爆发钩子。
- 暴击：`CombatSystem` 玩家攻击路径，独立 `rng.chance`。
- 星尘%：`LootSystem`（及任何发星尘的结算）乘算。
- 模板源：`EquipmentSystem.ts` → `EQUIPMENT_POOL.TRINKET`。

落地后同步：`design.md` 装备节、`equipment-catalog.md`。

## 10. 验收口径

1. 同品质蓝及以上，三类型专精可辨；白/绿仅灵气%差异（灵气 ≥ 幸运 ≥ 财运）。
2. 穿饰品后最大生命**不**因饰品主数值变化。
3. 永久层获得灵气时，数量随饰品灵气%增加。
4. 蓝幸运有暴击；蓝财运有星尘加成；蓝灵气有击杀灵气。
5. 三件传奇在对应类型上仍可触发。
6. UI 类型/阶段文案正确；无虚假白绿「星尘加成」。

## 11. 决策摘要

| 项 | 选择 |
|---|---|
| 框架 | 对齐鞋子（白绿薄基础 → 蓝起身份） |
| 身份 | 灵气 / 幸运 / 财运 |
| 主数值 | 统一灵气获取 % |
| 幸运专精 | 输出偶然（暴击） |
| 落地 | implicit + 品质阶段表 |
| 目录 | 17 名全保留，按 §6 映射 |
