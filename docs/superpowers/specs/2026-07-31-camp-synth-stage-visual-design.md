# 营地合成台视觉：熔炉 / 星盘（代码绘制）

日期：2026-07-31  
状态：已确认，待写实现计划  
关联：`CampView` 合成区、`CampMinghenLayout` / `CampEquipmentLayout`  
前置：`2026-07-28-minghen-camp-synth-ui-design.md`、`2026-07-28-equipment-camp-synth-ui-design.md`、`2026-07-31-camp-ui-glyph-inventory-design.md`

## 1. 目标

把营地两台合成区从「方格 + 折线」升级为有器具感的**代码绘制台面**：

| 台 | 隐喻 | 气质 |
|---|---|---|
| 装备合成 | **熔炉台** | 暖色凹槽、炉口弧光 |
| 命痕合成 | **星盘台** | 冷色圆环、荧光实线光晕（承接命痕符） |

去掉廉价折线连线；合成规则与交互不变。

## 2. 已定决策

| 项 | 选择 |
|---|---|
| 底板制作 | **A · 纯代码 Graphics**（零新图集） |
| 气质 | **A · 分题隐喻**（熔炉 / 星盘，非统一祭坛框） |
| 星盘线 | 双环 + 刻度均为**荧光实线光晕**（宽半透明晕 + 细亮芯）；**禁止虚线** |
| 交互 / 权威 | 不改；仅视觉与布局占位 |

## 3. 视觉规格

### 3.1 装备 · 熔炉台

- 台面：圆角矩形底板；径向暖色（底部偏橙褐 → 外缘深蓝夜色）
- 底部：炉口弧形高光（低透明橙），暗示熔池
- 槽位：上 1 结果、下 3 材料（仍 `CAMP_SLOT_SIZE` 正方形），嵌在凹痕描边内
- 结果与材料之间：可用极短竖向「炉气」渐变条暗示流向，**不画折线**
- 标题「装备合成」收在台面顶边内侧
- 「合成」按钮仍在台面正下方（现有费用文案逻辑保留）

### 3.2 命痕 · 星盘台

- 台面：圆角底板；径向冷色（中心青蓝 → 外缘深蓝）
- **外环 / 内环**：各画两遍——先宽半透明光晕，再细亮实线（青白 / 淡紫）；**不用虚线**
- 四向短刻度：短实线 + 同色光晕
- 槽位：上 1 结果、下 2 材料；外轮廓可用圆框，内容区仍放命痕符（`MinghenGlyphPainter`）
- 可合成时：环线颜色略提亮（静态加色即可，本轮不做动画）
- 标题「命痕合成」收在台面顶边；按钮在台面下

### 3.3 共用

- 结果槽空置、不预告产物名（装备既有口径；命痕可保留台外短提示或收进按钮旁，不在结果格内堆字）
- 台面高度写入 Layout metrics；背包固定 25 格锚点逻辑不变

## 4. 实现边界

**新增**

- `assets/scripts/pve/views/CampSynthStagePainter.ts`
  - `paintFurnaceStage(g, width, height): void`
  - `paintStarchartStage(g, width, height, opts?: { ready?: boolean }): void`

**修改**

- `CampView.ts`：合成区去掉折线；先画台面节点再叠槽/按钮
- `CampMinghenLayout.ts` / `CampEquipmentLayout.ts`：为台面块预留固定尺寸与 Y

**不改**

- `CampController` / 云端合成权威
- 槽位数量与投入规则
- 新 PNG/图集底板、粒子/全屏特效

## 5. 非目标

- MeowArt 整板背景
- 合成成功演出、炉火粒子
- 改星尘/材料消耗表

## 6. 验收

1. 两台合成区无折线连线。  
2. 熔炉台 / 星盘台一眼可辨；槽可点、装/卸/合成不回归。  
3. 星盘无线段为虚线；可合成时环线可略提亮。  
4. 不新增合成底板 PNG。  
5. 滚动画布时台面与背包锚点不互相跳动。

## 7. 文档同步

- 本文为合成**视觉**权威；合成规则仍以 `2026-07-28-*-camp-synth-ui-design.md` 与 `design.md` 为准。  
- 实现后可在 `design.md` 营地合成条补一句：显式合成区以代码绘制熔炉/星盘台面展示，无折线连线。
