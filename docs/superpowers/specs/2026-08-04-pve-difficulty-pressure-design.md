# PVE 关卡压力与节奏设计

> 日期：2026-08-04  
> 状态：第一章试点已实现，待自测  
> 关联：`specs/260712-pve-persistent-floor-progression/`（各章内容表）、`specs/260608-pve-destiny-expedition/design.md`

## 1. 问题与目标

自测从第 1 章打到第 3 章时，很少需要重复挑战，节奏偏顺。怪物血量已接近「可接受的磨血上限」，继续堆血只会拉长战斗、不会制造真正失败压力。

**目标体感（受众锚点 C）**

- 铺路 / 教学层：新人可过，熟手基本不重试。
- 加压层 / Boss：熟手也会紧张；目标约 **30–50%** 玩家在该层至少重试一次。
- 难度类型（混合 D）：普通层偏资源与读题（B/C），关键层允许失误即死威胁（A）。

**非目标（本轮不做）**

- 不以堆怪物 HP 作为主加压手段。
- 不砍永久成长曲线（装备 / 命痕 / 伙伴）来制造难度。
- 不以体力惩罚或强制清图作为加压手段。
- 第一章试点通过前，不同时大改第 2–5 章。

## 2. 方案选择

采用 **关卡角色 + 压力杠杆表**，并用每章节拍模板做验收：

- 主方案：每层标注角色；加压用非血量杠杆。
- 验收尺子：每章固定「教 → 练 → 加压 → 喘息/预演 → Boss」节拍，至少 **2 加压 + 1 Boss**。
- 延后：永久成长削弱（仅当杠杆改完仍偏易时再评估）。

## 3. 关卡角色

| 角色 | 目标体感 | 允许重试率 | 主要手段 |
|---|---|---|---|
| 铺路 | 教操作 / 熟悉主题 | 接近 0 | 几乎不加压 |
| 教学 | 学会本层 1 个新机制 | 低 | 机制可读，失败代价轻 |
| 加压 | 用已学机制做取舍 | 约 30–50% 至少重试 1 次 | 非血量杠杆（见下） |
| Boss | 综合考核，允许致命失误 | 约 30–50% 至少重试 1 次 | 伤害锋利 + 阶段压力 + 读招 |

## 4. 压力杠杆优先级（全章通用）

按优先级使用，同一加压层通常 **1 主 + 至多 1 辅**：

1. **时间窗** — 回合上限、逃离窗口、狂暴切入、潮汐推进。
2. **空间压迫** — 追击密度、包夹、出口/目标被封、冲锋距离。
3. **资源税** — 沙坑扣 AP、环境伤、绕路、打断回血/准备窗口。
4. **读题失败即罚** — 哨兵逃离、护运被毁、站错区、忽略预警。
5. **伤害锋利** — 提高「一失误掉一大截」的惩罚感；**仍不优先堆 HP**。

堆血只允许作极小补丁，且不得把战斗拖成无聊磨血。

## 5. 每章节拍验收

建议骨架（可按章微调，但不得缺加压与 Boss）：

`铺路/教学 → 教学 → 加压 → 教学或喘息 → 加压 → 加压预演 → Boss`

跨章镜像层职责（与 `chapter-floors-overview.md` 对齐）在辐射阶段沿用同一杠杆表，例如：追逃 / 突围 / 波次 / Boss 各自对应时间窗、空间压迫、资源税、锋利读招。

## 6. 第一章试点分工

| 层 | 现职责 | 角色 | 本轮策略 |
|---:|---|---|---|
| 1 | 钥匙探索 | 铺路 | 基本不改 |
| 2 | 精英猎杀 | 教学 | 基本不改 |
| 3 | 清号角 | 教学 | 最多微调召唤节奏，仍偏教学 |
| 4 | 追逃 | 加压 #1 | 主：时间窗；辅：读题失败 |
| 5 | 火药爆破 | 加压 #2 | 主：空间压迫；辅：资源税 |
| 6 | 五波 | 加压预演 | 主：波次缝隙；辅：资源税 |
| 7 | Boss | Boss | 主：伤害锋利；辅：读招；HP 上限不动 |

### 6.1 第 4 层（加压 #1）

**现状锚点**：`unobstructedEscapeTurns: 6`；哨兵被打立刻再逃 1 格。

**改动**

1. 无阻挡逃离窗口：`6 → 4` 怪回合（被控/挡路仍可拖时间）。
2. 将 1 名守卫推到短路径截击位，逼玩家在「直冲哨兵」与「先清路」间取舍。
3. 目标/HUD 文案强调：哨兵抵达逃离点即失败。

**验收**：直冲仍可能一过；犹豫绕圈或先清半图再追，更容易失败。

### 6.2 第 5 层（加压 #2）

**现状锚点**：点桶后永久狂暴（攻×2、移+1）+ 冲锋最多 2 格。

**改动**

1. 点桶后冲锋：`2 → 3` 格；已在射程则当回合必打一刀。
2. 点桶瞬间加强包夹（侧路弓手更近，或立刻再刷 1 名轻兵到中路；不加工血）。
3. 爆破点前增加 1 格绕路税（可破坏石块或强制绕行），让「先清场再点桶」更贵。

**验收**：「点桶 → 带火冲爆」仍为最优；先清场再点桶明显更慢更险。

### 6.3 第 6 层（加压预演）

**现状锚点**：`prepareTurns: 0`，`waveRushSteps: 4`，五波。

**改动（采用 A）**

1. 保持无准备回合。
2. 第 3–5 波 rush：`4 → 5`。
3. 提高后半波弓手占比或交叉火力站位（不加工血）。
4. 波次怪仍不掉独立永久奖励。

**验收**：前两波可稳住；后半站位/灵气分配差会掉血或翻车。

### 6.4 第 7 层（Boss）

**现状锚点**：Boss HP 660；约 35% 血狂暴；重击每 3 回合、预警 1；号角 1→2，召唤上限 8。

**改动**

1. HP 上限 **不动**（不拉到 800+）。
2. 上调重击伤害一档，或掩体外命中更疼，鼓励躲石块。
3. 狂暴后号角节奏略加快（或更早形成交叉火力）；召唤上限不大幅上抬。
4. 可选：评估狂暴普攻锋利度，让硬扛不躲更易死。

**验收**：会躲重击、控增援可稳定过；硬刚不读招明显更吃力，偏磨血体感禁止出现。

## 7. 辐射流程（第 2–5 章）

1. 第一章试点实现并自测通过。
2. 按本章角色表与杠杆优先级，逐章改「加压层 + Boss」，铺路/教学层从轻。
3. 每章改完单独验收，再开下一章；禁止一次改完全部章节。
4. 各章内容文档（`chapter-N-content.md`）与主设计在实现时同步；本文件保留原则与第一章清单。

|---:|---|---|

| 3 | 夺控 / 冰面压力等 | 冰霜巨人 |

| 5 | 预言 / 镜像 / 改写试炼等 | 命运守卫 |

## 8. 第一章试点总验收

- 第 1–3 层：熟手基本不重试，机制仍可读。
- 第 4–7 层：符合各层验收条。
- 整章自测：至少出现 **1 次**「差点翻 / 需要重来」的紧张感，且不觉得无聊磨血。
- 实现时同步更新 `chapter-1-content.md` 对应规则与 AC；若触及全局玩法口径再改 `design.md`。

## 9. 实现边界（给后续 plan 用）

- 入口优先：`Chapter1FloorCatalog.ts`、`Chapter1Monsters` / 第 5 层狂暴冲锋逻辑、波次配置、`GoblinChief.ts`。
- 表现：逃离失败与狂暴包夹需有足够 HUD/toast 提示（沿用现有 toast / 目标弹窗模式）。
- 测试：覆盖逃离窗口、点桶冲锋、后半波 rush、Boss 重击/号角节奏的单测或回归用例。
