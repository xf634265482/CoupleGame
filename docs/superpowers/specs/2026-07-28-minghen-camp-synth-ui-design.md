# 命痕台布局与显式合成 — 设计

日期：2026-07-28  
范围：营地「命痕台」UI 调整 + I→II 改为玩家在命痕台显式合成（取消自动升 II）

相关文档：

- `docs/superpowers/specs/2026-07-18-minghen-acquisition-economy-design.md` §4（同名升级公式）
- `specs/260712-pve-persistent-floor-progression/minghen-catalog.md`（全局合成口径）

---

## 1. 目标

1. 已装配命痕格子加宽加高，文案尽量一行（名 + 罗马等级，如 `藏锋 II`）。
2. 拥有命痕字号略小，文案尽量一行（如 `回流 I ·×1`）。
3. 拥有区下方增加「命痕合成」三角台：上 1 结果格、下 2 材料格、斜线连接。
4. 拥有命痕详情增加「投入合成」；整页单栏可上下滑动。
5. **取消**获得第 2 枚副本时自动升为 II；必须由玩家在合成台确认合成。
6. 本期隐藏「保存方案」入口（逻辑保留，不展示）。

非目标（本期不做）：

- 异名随机合成、配方书。
- II→III 的材料台合成（III 仍走升格试炼）。
- 恢复或改版「保存方案」UI。

---

## 2. 页面结构

外层营地面板高度保持现有量级；**命痕台 Body 整页 ScrollView** 上下滑动。「返回大厅」钉在面板底，不随内容滚。

自上而下：

1. 摘要：已收集 / 已装配 / 方案数 / 星尘  
2. 已装配命痕（5 列 × 2 行，格子加宽加高，一行文案）  
3. 拥有的命痕（字略小，一行文案；随数量增高，由整页滚动承载）  
4. 命痕合成（三角台 + 合成按钮）  

「保存方案」**不渲染**。

## 3. 合成台交互

### 3.1 详情按钮

未装配命痕详情：`装配` · `追踪` · `投入合成` · `关闭`  
已装配详情：保持 `卸下` · `追踪`（无投入合成）。

### 3.2 投入规则

- 仅 **未装配** 且当前展示等级为 **I** 的命痕可投入。
- 「投入合成」填入下一个空材料格；两格已满则提示先清空。
- 同一命痕 ID 可占满两格，前提是该 ID 的 **可用副本** 足够（见 §4）。
- 点击材料格可卸下该格。
- 不符条件时「投入合成」灰显，并短文案说明原因（非 I / 副本不足 / 已装配等）。

### 3.3 结果预览

| 材料格状态 | 结果格 |
|---|---|
| 两格均为同名 I，且副本足够 | 预览 `名称 II` |
| 其他 | 空，或提示「需同名 I×2」 |

### 3.4 合成按钮

- 仅预览合法时可点。
- 成功：按 §4 改存档 → 清空材料格 → 刷新列表与装配展示。
- 失败：弹窗/提示错误码文案，不清空合法预览（或按云端错误回滚本地暂存）。

## 4. 进度规则变更（显式合成）

### 4.1 公式（不变）

| 步骤 | 规则 |
|---|---|
| I → II | 2 枚同 ID 的 I 级材料 → 1 枚 II 级 |
| III | `copies` 达材料门槛 + 专属升格试炼；失败不损失材料 |

禁止异名同级合成。

### 4.2 与当前实现的差异（必须改）

**旧行为：** `copies >= 2` 时 `level` 自动变为 2（`highestCraftableMinghenLevel` / 云端 `levelFor`）。  

**新行为：**

- 获得副本只增加 `copies`，**不**因 `copies >= 2` 自动把 `level` 升到 2。
- `level === 1` 且 `copies >= 2` 时，玩家可在命痕台投入同名两格并点「合成」→ `level = 2`。
- `level === 3` 仍仅由试炼完成授予（`trialCompleted` + 材料门槛），不走本合成台。
- 装配校验：装配等级不得超过已解锁的 `level`；`copies` 仍用于材料与商会兑换余量等现有逻辑。

### 4.3 合成扣减口径

同名 2×I → II：

- 前置：`level === 1`，`copies >= 2`，该 ID 未在装配中占用「不可用」冲突（实现时：已装配的同 ID 不可再当材料投入；未装配则可）。
- 成功后：`level = 2`；`copies` **不减少**（两枚 I 合成为一枚 II 的叙事下，copies 仍表示持有进度/材料存量，与现网「copies 门槛」模型对齐：II 的持有仍要求 `copies >= 2`）。

说明：现网用 `copies` 兼作「材料进度」。显式合成只把 **等级解锁** 从自动改为手动，不另造第二套库存。若后续要「合成后 copies-2 再 +1 个 II 实体」，另开设计；本期不采用。

### 4.4 云端权威

新增营地 action（名称实现时确定，如 `SYNTHESIZE_MINGHEN`）：

- 入参：命痕 `id`（两格必须同 ID，故只需一个 id + 客户端校验双格）。
- 校验：openid 存档、`level===1`、`copies>=2`、非已装配占用材料规则、非 III 路径。
- 写回：`level=2`；返回新 profile。
- 客户端 `CampController` 调现有 progression/camp 通道；UI 暂存仅本地，成功以云端为准。

## 5. 实现分期

| 阶段 | 内容 |
|---|---|
| Phase 1 | 布局 + 滚动 + 合成台 UI + 投入/卸下/预览/按钮态；合成可先禁用或提示「即将接通」 |
| Phase 2 | 去掉自动升 II；云端 + 客户端合成；单测覆盖 `copies>=2` 仍为 I、合成后为 II、副本不足失败 |

---

## 6. 验收

1. 已装配格明显比旧版宽高，一行可读。  
2. 拥有格字更小，一行可读。  
3. 合成台三角+连线可读；整页可滑到合成区。  
4. 详情有「投入合成」；保存方案不可见。  
5. 新获得第 2 枚副本后仍为 I，直到命痕台合成成功才显示 II。  
6. 同名 I×2 可合成；异名或不足不可合成。  
7. III 仍只能试炼，不能在本台合成出 III。
