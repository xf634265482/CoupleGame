# 大厅连续登录奖励（每日签到 + 累计签到）

日期：2026-07-31  
范围：大厅签到入口与弹层；云端签到 / 补签 / 累计里程碑领取；奖励直接入账星尘与材料。实现时同步 `specs/260608-pve-destiny-expedition/design.md`、`PROJECT_NAVIGATION.md`、`CALL_FLOW.md`。

## 背景

大厅已有邮箱、命痕商会、伙伴等弹层入口，尚无每日回流激励。营地经济已有星尘、淬星砂、聚星核、虚空革；需要一套云端权威、可防刷的签到与月累计奖励，并用补签卡覆盖轻度漏签（后续可接 GM / 广告发放）。

## 目标

1. 大厅左上头像卡下方有「签到」入口（与邮箱同区），可签 / 可领累计时显示红点。
2. 月历展示每日奖励；签到后当日标「已签」，奖励立刻入账。
3. 本月累计签到天数达 1 / 3 / 7 / 15 / 20 时可手动领取里程碑奖励。
4. 支持消耗补签卡补签本月过去漏签日；补签卡可由累计 7 天档附送，并由 GM 发放（广告激励预留）。

## 已确认决策

| 项 | 选择 |
|----|------|
| 累计口径 | 本月累计；断签不清零已签天数；月底随换月重置 |
| 每日奖励排布 | 月历固定表；按「当月第几天」7 日循环 |
| 补签 | 消耗补签卡；首版获取 = GM 发放 + 累计 7 天档附送 1 张；广告入口预留隐藏 |
| 领奖方式 | 每日签到自动入账；累计里程碑手动领取 |
| 入口 | 左上头像卡附近，独立「签到」按钮 |
| 权威 | 云端；奖励直入 `pveProfile`，不走邮箱 |
| 奖励池 | 星尘、淬星砂、聚星核、虚空革、补签卡 |

## 架构

```text
大厅签到按钮（红点）
  -> CheckInView 弹层
  -> PveService.checkIn(action)
  -> pve 云函数 -> PveCheckIn.js
       GET_STATE / SIGN_TODAY / MAKEUP / CLAIM_MILESTONE
  -> 入账 gold / materials / makeupCards
  -> 返回状态 + profile 片段，刷新弹层与大厅星尘芯片
```

落点建议：

- 云端：`cloudfunctions/common/pve/PveCheckIn.js`（经 `pve` action 转发）
- 客户端：`assets/scripts/pve/views/CheckInView.ts` + `PveLobbyController` 挂载入口
- 服务封装：`assets/scripts/network/PveService.ts`（或现有 PVE 调用封装处）

## 数据模型

统一挂在 `pveProfile.checkIn`（缺省按空状态归一化）：

```ts
checkIn: {
  monthKey: string;           // '2026-07'，东八区自然月
  signedDays: number[];       // 本月已签日，如 [1, 2, 5]
  claimedMilestones: number[]; // 本月已领档，如 [1, 3, 7]
  makeupCards: number;        // 补签卡 ≥0，跨月保留
}
```

换月：任意 check-in action 发现 `monthKey` 与当前东八区月份不符时，先重置 `signedDays` / `claimedMilestones` 并更新 `monthKey`，**保留** `makeupCards`。

奖励入账映射：

| 奖励 | 写入 |
|------|------|
| 星尘 | `pveProfile.gold` |
| 淬星砂 | `materials.quenchSand` |
| 聚星核 | `materials.fusionCore` |
| 虚空革 | `materials.voidHide` |
| 补签卡 | `makeupCards` |

不扩展邮件附件承载材料 / 补签卡。

## 规则

### 日界与签到

- 日界：东八区自然日。
- `SIGN_TODAY`：仅可签「今天」；已签则失败。
- 成功：按当日日历配置立刻入账，并将今日写入 `signedDays`。

### 补签

- `MAKEUP(day)`：`day` 须为本月「过去且未签」的合法日（1–本月天数，且早于今天）。
- 消耗 1 张补签卡；卡不足则失败且不改状态。
- 成功：发该日日历奖励，`signedDays` 加入该日。
- 不可补签今天（今天用 `SIGN_TODAY`）；不可补签未来日；不可对已签日补签。

### 累计里程碑

- 进度 = `signedDays.length`（含补签）。
- 档位：`1 / 3 / 7 / 15 / 20`。
- 达标且未在 `claimedMilestones` 中 → 可手动 `CLAIM_MILESTONE`。
- 可领未领保留至本月底；换月清空进度与已领记录。
- 每日签到 / 补签成功时若跨过里程碑，**不自动发**累计奖，仅点亮可领态。

## 奖励表

量级对齐营地消耗：强化 +1 ≈ 20 星尘 + 2 淬星砂；通关约 2–8 砂；Boss 约 +2 核 / +2 虚空革；扩容 25→35 = 120 星尘 + 3 虚空革。签到略低于一层通关，满勤可补贴低阶强化与一档扩容材料，不替代打本。

### 每日奖励（7 日循环）

以「当月第几天」`d` 取 `d % 7`：

| `d % 7` | 奖励 |
|:-------:|------|
| 1 | 星尘 30 |
| 2 | 淬星砂 2 |
| 3 | 星尘 40 |
| 4 | 淬星砂 3 |
| 5 | 星尘 50 + 淬星砂 1 |
| 6 | 聚星核 1 |
| 0（7 / 14 / 21 / 28） | 星尘 60 + 虚空革 1 |

满月约：星尘 ~760、淬星砂 ~24、聚星核 ~4、虚空革 ~4（另加累计档）。

### 累计里程碑（手动领取）

| 天数 | 奖励 |
|:----:|------|
| 1 | 星尘 50 |
| 3 | 淬星砂 3 |
| 7 | 星尘 100 + 补签卡 1 |
| 15 | 淬星砂 5 + 聚星核 1 |
| 20 | 星尘 200 + 虚空革 2 + 聚星核 1 |

## UI

### 入口与红点

- 位置：左上头像卡下方，与邮箱同区；独立「签到」按钮。
- 图标 path 预留：`pve/lobby/icon_checkin`（缺失时不崩，可用占位）。
- 红点：今日未签，**或** 存在可领未领累计档。

### 弹层 `CheckInView`

代码构建 UI，交互模式对齐 `MailView`：

1. 标题区：本月签到 + 「补签卡 ×N」。
2. 上区月历（日–六）：
   - 今日未签：高亮；主按钮「签到」。
   - 已签：「已签」态。
   - 过去未签：可选中 → 「补签」（卡为 0 时禁用并提示）。
   - 未来日：不可交互。
   - 格内可显示主奖励缩略；点格可看详情。
3. 下区累计：进度条 + 节点 1 / 3 / 7 / 15 / 20。
   - 未达标：灰。
   - 可领：亮 + 「领取」。
   - 已领：打勾。
4. 关闭后刷新大厅星尘芯片；材料与补签卡以弹层数量 / 下次开页为准。

### 首版不做

- 进大厅强制弹窗。
- 广告激励领补签卡（按钮可占位隐藏）。
- 精修日历美术与正式签到图标绘制。

## 云端接口

| action | 参数 | 行为 |
|--------|------|------|
| `GET_STATE` | — | 换月重置后返回状态、月历奖励预览、今日可否签、可领里程碑、补签卡数 |
| `SIGN_TODAY` | — | 签今日并入账每日奖 |
| `MAKEUP` | `day: number` | 扣 1 卡并补签指定日 |
| `CLAIM_MILESTONE` | `days: 1\|3\|7\|15\|20` | 领取对应累计档 |

成功响应至少包含：最新 check-in 状态、获得列表、`gold` / `materials` / `makeupCards`（便于客户端局部刷新）。

### 错误码

| 码 | 含义 |
|----|------|
| `PVE_CHECKIN_ALREADY_SIGNED` | 今日已签 / 目标日已签 |
| `PVE_CHECKIN_INVALID_DAY` | 非法 day、未来日、非本月过去日 |
| `PVE_MAKEUP_CARD_NOT_ENOUGH` | 补签卡不足 |
| `PVE_MILESTONE_NOT_REACHED` | 累计天数未达标 |
| `PVE_MILESTONE_ALREADY_CLAIMED` | 该档本月已领 |

客户端操作使用 `_busy` 防连点。

## 验收口径

1. 签今日成功入账对应循环奖励；重复签失败且不双发。
2. 换月清空 `signedDays` / `claimedMilestones`，`makeupCards` 保留。
3. 补签扣 1 卡并发该日奖；卡不足状态不变。
4. 累计未达标不可领；达标可领一次；7 天档含补签卡 +1。
5. 第 7 / 14 / 21 / 28 日每日奖含虚空革 1。
6. 大厅入口红点在「未签」或「有可领累计」时可见；领完且已签后消失。
