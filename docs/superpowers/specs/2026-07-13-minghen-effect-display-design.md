# 命痕名称与效果展示设计

## 目标

玩家在楼层首通选择命痕时，必须在确认前看懂每个候选命痕的名称与实际效果；营地命痕台和战斗角色面板必须复用同一份文案，不能继续显示内部 ID 或升格试炼来代替效果。

## 单一数据源

- `MinghenCatalog` 继续作为24枚命痕的唯一权威目录。
- 每枚命痕补充 I、II、III 三级正式效果文案；文案必须与 `MinghenEffects` 的实际条件、数值、次数限制和 Boss 特例一致。
- 所有 UI 通过一个公共格式化入口读取名称、等级效果、标签与试炼，不在控制器或视图内维护第二份 ID→文案表。
- 修改命痕机制或数值时，必须同时更新目录效果文案及对应测试。

## 首通选择弹窗

- 标题保持“选择本层主题命痕”，明确这是楼层首通奖励，不是祭坛或其他交互物奖励。
- 每个候选项至少显示两行：
  - 第一行：`命痕名称（ID）`
  - 第二行：本次获得后可生效的等级效果摘要。
- 尚未拥有时展示 I 级效果。
- 已拥有时展示当前等级、副本进度，并按获得一份后的预计等级选择效果文案；未达到升级门槛则仍显示当前等级效果。
- 文案使用玩家语言描述，不显示事件钩子、数组数值或内部枚举。
- 第1–6层首次进度通关显示命痕选择；第7层只显示 Boss 装备选择，不额外弹出命痕选择。

## 营地与战斗角色面板

- 营地命痕台显示：名称、等级、副本进度、当前等级实际效果、升格试炼。
- 战斗角色面板只读显示已装配命痕：名称、等级与当前等级实际效果；点击后可查看完整效果和试炼条件。
- 两处均调用公共格式化入口，不直接拼接 `definition.trial` 充当命痕效果。

## 兼容与错误处理

- 未知命痕 ID 维持现有 `UNKNOWN_MINGHEN` 保护，不静默显示错误效果。
- 旧档案没有新增展示字段也可正常读取，因为效果文案属于静态目录而非存档。
- UI 文案过长时使用简短摘要作为按钮文字，详情层显示完整文本；不得通过缩到不可读字号解决溢出。

## 验收

- 第一章每层候选项不再出现单独的“命痕 M03”式内部名称。
- M03 首次获得时能看到“余烬”及 I 级高 AP 攻击施加灼烧的效果。
- 同一命痕在首通弹窗、营地和角色面板显示的等级效果一致。
- 重复命痕达到升级门槛时，选择弹窗预览获得后的等级效果。
- 第7层通关不出现命痕选择，只出现 Boss 装备选择。
- 24枚命痕的 I/II/III 文案均非空，并由测试校验目录完整性。
