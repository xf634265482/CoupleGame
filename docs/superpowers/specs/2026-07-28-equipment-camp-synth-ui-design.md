# 装备台合成区 — 设计

日期：2026-07-28  
范围：营地「装备台」增加与命痕台同构的显式合成区（3 材料 + 1 结果）；规则沿用既有三合一升品。

相关文档：

- `specs/260608-pve-destiny-expedition/design.md`（三合一升品权威口径）
- `docs/superpowers/plans/2026-07-18-ch2-armor-softland-craft-v1.md`（既有 SYNTHESIZE 实现）
- 对照 UI：`docs/superpowers/specs/2026-07-28-minghen-camp-synth-ui-design.md`

---

## 1. 目标

1. 装备台整页可上下滑动：摘要 → 已穿戴 → 永久背包 → **装备合成**。
2. 合成区：上 1 结果格，下 3 材料格，斜线连接成「倒三角/扇形」关系，便于理解 3 合 1。
3. 未穿戴装备详情增加「投入合成」；点材料格可卸下。
4. 去掉背包详情里原来的一键「合成」按钮（避免双入口）；合成只走合成台。
5. 玩法数值/校验不变：仍走云端 `manageCamp` `EQUIPMENT` + `SYNTHESIZE`。

非目标：

- 改品质链、星尘价、传奇不可合等规则。
- 异名合成或其它配方。
- 已穿戴装备可投入（仍须卸下/用背包副本）。

---

## 2. 页面结构

外层营地面板高度保持现有量级；**装备台 Body 整页 ScrollView**。「返回大厅」钉在面板底，不随内容滚。

自上而下：

1. 摘要：永久背包数量 / 星尘  
2. 已穿戴装备（5 槽，行为不变）  
3. 永久背包（图标格；可随数量增高，由整页滚动承载；不再单独嵌套矮滚动窗，或嵌套滚动仅作次要，优先整页滚）  
4. 装备合成（结果 + 3 材料 + 合成按钮）

---

## 3. 合成台交互

### 3.1 详情按钮（未穿戴）

`装备` · `投入合成` · `锁定/解锁` · `出售` · `关闭`

已穿戴：保持 `卸下` · `强化` · `锁定` · `出售`（无投入合成、无合成）。

### 3.2 投入规则

- 仅 **未穿戴、未锁定** 的背包实例可投入。
- 「投入合成」填入下一个空材料格；三格已满则提示先清空。
- 三格最终必须 **同 definitionId + 同 quality** 才能点合成；投入时若与已入槽冲突，可拒绝并提示「须同名同品质」。
- 同一 `instanceId` 不可重复入槽。
- 点击材料格卸下该格。

### 3.3 结果预览

| 材料格状态 | 结果格 |
|---|---|
| 三格均填且同名同品质，且存在下一品质，星尘足够 | 预览：名称 + 下一品质 + 费用 |
| 三格齐但传奇 / 无下一品质 | 「满品不可合成」 |
| 其它 | 空，或「需同名同品质×3」 |

### 3.4 合成按钮

- 仅预览合法且星尘足够时可点。
- 成功：调用现有 `SYNTHESIZE`，`instanceIds` 为三格 id（顺序不限）→ 清空材料格 → 刷新列表。
- 失败：弹窗错误文案；材料格可保留便于重试。

---

## 4. 规则（不变，重申）

| 项 | 口径 |
|---|---|
| 材料 | 3 件不同 instance、同名同品质、未锁未穿 |
| 产出 | 高一阶品质一件；`enhanceLevel=0`；`baseStat=round(avg)` |
| 费用 | COMMON 15 / FINE 30 / RARE 60 / EPIC 120 星尘 |
| 上限 | LEGENDARY 不可再合成 |
| 权威 | `cloudfunctions/common/pve/PveCamp.js` `synthesizeEquipment` |

客户端本地只做槽位暂存与预览；写档以云端为准。

---

## 5. 实现分期

| 阶段 | 内容 |
|---|---|
| Phase 1 | 装备台整页滚动 + 合成区 UI + 投入/卸下/预览/按钮态；去掉详情一键合成 |
| Phase 2 | 合成按钮传入三格 `instanceIds` 接通既有 `CampController._synthesizeEquipment`（改为接受显式 ids，或新增 `_synthesizeEquipmentFromSlots`） |

无需改云端公式；若 Controller 目前「自动 pick 另外两件」，改为「仅使用槽位三 id」。

---

## 6. 验收

1. 装备台可滑到合成区；上 1 下 3 + 连线可读。  
2. 未穿戴详情有「投入合成」；无旧一键合成。  
3. 三格同名同品质可合成；冲突/锁定/已穿/满品/星尘不足有提示。  
4. 成功后材料清空，新装备进背包，星尘正确扣减。  
5. 已穿戴强化/锁定/出售行为不变。
