# 职业叫法统一 · 机制 HUD · 战士蓄力撞碎

> 日期：2026-07-16
> 状态：已确认并实施（2026-07-16）
> 权威玩法同步目标：`specs/260712-pve-persistent-floor-progression/profession-progression.md`、`design.md`、`chapter-1-content.md`

## 1. 目标

1. **叫法统一**：玩家可见名称固定为 **战士 / 游侠 / 潜行者**（内部 ID 不变）。
2. **职业机制常驻按钮**：远征操作面板按职业显示不同机制控件；被动资源可读，主动兑现可点。
3. **战士蓄力重做**：伤害持平略优于「同总 AP 两次普攻」，并加入按蓄力阶梯的 **撞碎**；不附带穿透（穿透留给灵气爆发「破阵」）。
4. **平衡口径**：不削战士；通过把游侠/潜行者特色做可见、可兑现，保证关卡可选而非唯一解。

## 2. 非目标

- 不改内部 ID：`WARRIOR` / `ARCHER` / `RANGER`（战斗映射仍可为 `BERSERKER` / `ARCHER` / `ROGUE`）。
- 本次不重做完整「攻击确认页选战技/射术」大 UI；游侠射术选择可后续迭代，但瞄准等级必须可见。
- 不把旧灵气三选一 magically 复活。

## 4. 职业机制常驻按钮

操作面板同一槽位（现战士「蓄力」位置）按职业切换：

| 职业 | 按钮文案 | 交互 |
|---|---|---|
| 战士 | `蓄力 N AP` | 主动循环 0→1→2→3→0（保持现状逻辑，数值按 §5 更新） |
| 游侠 | `瞄准 N` | 点击打开只读说明弹窗；展示当前等级、升降规则、满层穿透/射程卖点 |
| 潜行者 | `连击 N` | 连击 &lt; 3：点击打开说明弹窗；连击 ≥ 3：按钮可主动触发 **基础收招**（见下） |

### 4.1 游侠弹窗要点

- 回合结束未移动：瞄准 +1（最高 3）
- 主动移动：瞄准 -1（最低 0）；强制位移不降
- 攻击不消耗瞄准
- 满层（3）：最终伤害 +30%、护甲穿透 +20%、最大射程 +1
  → 明确对位战士「常驻蓄力不给穿透」

### 4.2 潜行者收招（基础兑现，必须可点）

达到 **3 连击** 时，机制按钮进入可执行态（高亮/文案如 `收招`）：

- 点击后弹出二选一（与设计文档基础收招一致）：
  1. **疾收·伤**：下一次主动攻击最终伤害 +25%（回合结束未用则消失）
  2. **疾收·步**：立即免费主动移动最多 1 格（不耗 AP、不增加新连击）
- 消耗全部连击；收招本身不耗武器 AP
- 更高阶收招（绝影/回旋/无踪）若熟练度未解锁，本版可不进按钮，但基础收招必须可用

### 4.3 刷新

- 每回合、`refresh` / `_refreshPersistentHud` 同步 N
- 切换职业进入挑战时按钮形态必须不同，禁止三职共用「蓄力」皮

## 5. 战士蓄力重做

### 5.1 伤害倍率（相对不蓄力单次）

| 额外 AP | 倍率 | 设计意图 |
|---:|---|---|
| 0 | ×1.00 | 普攻 |
| 1 | ×1.40 | 小额投入 |
| 2 | ×1.75 | 接近两刀 |
| 3 | ×2.10 | **略优于** 同总 AP 打两刀 |

- **不附带护甲穿透**（穿透仅灵气爆发「破阵」）
- 实现位置：`WarriorSystem.ts` 的 `CHARGE_BONUS`（及一切镜像常量/测试）

### 5.2 撞碎（按蓄力阶梯）

| 额外 AP | 击退格数 | 碰撞伤（相对本次主动最终伤害） |
|---:|---:|---|
| 0 | 0 | 无 |
| 1 | 1 | 撞到墙/石/敌人 → **25%** |
| 2 | 1 | → **40%** |
| 3 | 2 | → **55%** |

规则：

1. 沿攻击方向击退；路径上撞到 **地图边界墙、石块（ROCK）、或其他存活敌人** 时停止在撞前一格，并结算碰撞伤。
2. 撞到另一敌人：主目标吃满额碰撞伤；被撞目标吃主目标碰撞伤的 **70%**。
3. 与武器自带击退 **相加**，总击退上限 **3**（破阵震退式仍可按原设计抬到 4）。
4. **Boss 不位移**：改为直接追加同阶碰撞伤（震击），避免机制空转。
5. 碰撞伤视为次生伤害：不触发「主动攻击命中」类命痕/灵气（与 `profession-progression.md` §7.2 一致）。

### 5.3 表现与战报

- 撞碎需有可感知反馈（短震/闪白或战报一句即可）
- 战报示例：`蓄力撞击！对石墙造成 XX` / `砸中另一敌人`

## 6. 平衡口径（不削战士，突出另两职）

### 6.1 三角定位

| | 战士 | 游侠 | 潜行者 |
|--|------|------|--------|
| 核心 | 一刀重蓄 + 撞碎 | 站桩叠瞄准 + 远程/穿透 | 走打节奏 + 收招经济 |
| 强势场景 | 墙角、石块、近战斩杀 | 追逃、开阔、隔障 | 波次、侧翼、需要位移 |
| 短板 | 空地撞碎吃不满；追逃弱 | 频繁移动掉瞄准 | 站桩纯爆发不如满蓄 |

### 6.2 护栏

- 满蓄伤害只略优两刀（×2.10），不上 ×2.5
- 碰撞是条件收益；空地不应稳定大幅碾压两刀
- 常驻蓄力无穿透；破阵保留穿透身份
- 验收：同一关卡三职均可通关；差距体现在手感/耗时，不是唯一可过
- 若日后战士仍偏强，优先调 **碰撞比例**，不把蓄力伤害打回鸡肋

### 6.3 为何另两职不会被架空

- **游侠**：跨回合叠层 + 满层穿透/射程，对位战士「花整轮 AP 换一刀且无穿透」
- **潜行者**：移动即资源 + 免费收招，对位战士「行动经济差」
- 本次必须让这两点 **HUD 可见且（潜行者）可点**，否则体感仍会一边倒选战士
