# 营地装备台 UI 调整

日期：2026-07-16  
范围：仅 `CampView` 营地装备台表现；不改掉落/品质波动规则。

## 背景

1. 装备详情文案左侧被裁切，且信息过杂。  
2. 已穿戴槽为扁长矩形，标题与「未穿戴」挤在格内。  
3. 永久背包首列偶发左侧裁切。

掉落已在 `[baseStatMin, baseStatMax]` 内 roll，并保留 `baseStat`；高品质相对波动更小（池表设计）。本轮只展示，不重做规则。

## 方案（已确认）

### 已穿戴

- 槽位名在正方形**正上方**。  
- 下方为正方形；有装备时图标铺满，格内无其它文字。  
- 空槽：空框；有装备时点击打开详情。

### 装备详情

- 修复左侧裁切（正文左对齐并留足内边距；短文案可不用易错位的 scroll）。  
- 文案：
  - 名称
  - 主属性 `当前/上限`（来自实例 `baseStat` 与模板 `baseStatMax`；缺省用区间中值）
    - 武器→攻击；护甲→护甲；头盔/饰品→生命；鞋子→档位（与现有槽语义一致）
  - 武器另附：攻击范围 `min-max`
  - 品质、强化等级

### 永久背包

- 保持列表卡样式；收紧网格宽度/边距，避免左侧裁切。

## 非目标

- 不改 `rollClassicEquipment` / 品质池 / 强化公式。  
- 不把背包改成纯图标格。

## 验收

- 穿戴槽：标题在上、正方形、图标铺满、无格内杂字。  
- 详情：全文在面板内可见；显示 `当前/上限` + 范围(武器) + 品质 + 强化。  
- 背包卡片不被面板左缘裁切。  
- 同名装备不同 `baseStat` 时详情分子不同（波动仍在）。
