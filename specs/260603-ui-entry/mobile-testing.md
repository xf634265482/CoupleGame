# 外出联测：不用电脑上的「预览二维码」

开发者工具里的 **预览 / 真机调试** 二维码有效期很短（通常约 30 分钟量级），且往往要求本机开发者工具保持运行，不适合出门让别人扫。

推荐改用微信官方的 **体验版**：在电脑上 **上传一次** 代码后，体验成员可在手机微信里直接打开小游戏，无需你现场开开发者工具。

---

## 方案对比

| 方式 | 是否需要电脑在线 | 谁能玩 | 码 / 入口有效期 |
|------|------------------|--------|-----------------|
| 开发者工具「预览」 | 是（工具要开着） | 管理员 + 已绑定的体验者 | 很短 |
| 开发者工具「真机调试」 | 是 |  mainly 开发者本人 | 很短 |
| **体验版（推荐）** | 上传后不需要 | 公众平台登记的 **体验成员** | 较长，版本在后台保留 |
| 正式版 | 否 | 全体用户 | 需审核发布 |

## 一次性准备（在出门前完成）

### 1. 构建并 patch

```bash
# Cocos 构建 wechatgame 后
node scripts/patch-wechatgame-config.js
```

确认 `build/wechatgame/.patch-last-run.json` 时间为最新（若启用了 `wechatgame-post-patch` 扩展，构建成功后会自动生成）。

### 2. 上传体验版

1. 微信开发者工具打开 **`build/wechatgame`**
2. 右上角 **上传**（不是预览）
3. 填写版本号、备注（如 `ui-0.1.3`）→ 上传成功

### 3. 在公众平台设为体验版

1. 浏览器打开 [微信公众平台](https://mp.weixin.qq.com/) → 登录你的小游戏账号
2. **管理** → **版本管理**（或「开发管理」→「开发版本」）
3. 在 **开发版本** 列表找到刚上传的版本 → **选为体验版**

### 4. 添加体验成员（可一起测试的好友）

1. 公众平台 → **管理** → **成员管理** → **体验成员**
2. 添加对方的 **微信号**（对方需在邀请里确认；人数上限以平台为准，一般足够小团队测试）

对方**不需要**安装开发者工具，也**不需要**扫你电脑上的预览码。

## 出门后：你和好友怎么进游戏

### 方式 A：手机「小程序助手」（推荐）

1. 好友与自己的手机安装 **微信小程序助手**（微信官方 App）
2. 管理员账号登录 → 选择你的小游戏
3. **版本管理** → **体验版** → 获取 **体验版二维码** 或转发给体验成员

体验成员用微信扫码即可进入（码随体验版版本更新，比开发者工具预览码持久得多）。

### 方式 B：公众平台网页

1. [mp.weixin.qq.com](https://mp.weixin.qq.com/) → 版本管理 → 体验版
2. 下载 / 展示 **体验版二维码**，发到微信群，体验成员扫码

### 方式 C：微信内搜索（已配置名称时）

体验成员在微信 **发现 → 游戏** 或搜索 **小游戏名称**（需小游戏已发布过体验版且对方为体验成员），可直接打开最近体验版。

## 联机测试注意

- 体验版与预览版一样走 **正式 AppID + 云开发环境**，请确认 `config/wechat.local.json` / `Constants.ts` 的 **cloudEnvId** 与上传前一致。
- 修改云函数后仍需在开发者工具 **上传并部署** 云函数（可出门前部署好）。
- 两人联机步骤仍可参考 [`../260529-combat-board-game-rework/dual-device-debug.md`](../260529-combat-board-game-rework/dual-device-debug.md)，只是把「两个开发者工具」换成「两个手机体验版 + 两台真机」。

## 常见问题

| 问题 | 处理 |
|------|------|
| 好友扫体验码提示无权限 | 未加入 **体验成员**，或体验版未设置 |
| 大厅黑屏、无背景 | 上传前未执行 patch；重新构建 + patch 再上传体验版 |
| 还是只能预览 | 区分 **上传 → 体验版**，不要用工具「预览」码 |
| 想完全不用电脑 | 体验版仍需至少一次上传；之后可只用 **小程序助手** 管理版本与二维码 |
| 自动上传 | 可用 [miniprogram-ci](https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html) 配置密钥，在任意机器 `upload`（进阶，需先配置私钥） |
