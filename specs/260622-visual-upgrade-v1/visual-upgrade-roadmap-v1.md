# Visual Upgrade Roadmap V1

## Purpose

按照 VSS v2.0，将现有 PVE 视觉逐步升级为统一、明亮、易读的天空塔庭轻奇幻风格。

## Phase 0 · 基线冻结

- 建立 Visual Audit V1。
- 建立 Gold Standard 资产清单。
- 建立旧资产处置清单。
- 冻结旧锚图和旧 Prompt。
- 固定真机截图场景与验收方式。

完成条件：审计、资产清单、处置策略和证据路径完整。

## Phase 1 · Gold Standard 战场骨架

制作并确认：

1. 第一章云暮塔庭背景。
2. 连续半透明战场平面。
3. 普通代码格线视觉参数。
4. 高遮蔽度星雾。
5. 选中、移动、攻击和危险状态。

先做原因：战场是所有角色、交互物与 UI 的真实承载环境。没有稳定环境，无法正确评价主体尺寸、轮廓和对比度。

## Phase 2 · Gold Standard 玩家

- 棕发蓝金冒险者。
- 青色命运晶体或围巾。
- 约 1.9 头身，头部约占可见总高一半。
- 默认手持短剑，64 px 下脸与剑同时清楚。
- 自然探索待机姿态。
- 占格 75%~82%。
- 青色命运环基础与增强状态。
- 64/96/128 px 对照。

## Phase 3 · Gold Standard 交互物

- 宝箱。
- 钥匙。
- 普通出口。
- Boss 传送门。
- 一件功能设施样板。

## Phase 4 · Gold Standard 怪物与 Boss

- 第一章普通怪。
- 第一章 Elite。
- 哥布林酋长。

## Phase 5 · Gold Standard UI Kit

- HUD 面板。
- 怪物卡。
- 玩家状态卡。
- 战报面板。
- 主、次、结束回合按钮。
- 方向键。
- 通用弹窗。
- 图标承载框。
- 字体与字号样张。

## Phase 6 · 新唯一锚图

将 Phase 1~5 的批准资产组合为 Gold Standard Sheet，完成评分、真机验证和用户批准后：

- 取代旧锚图的权威地位。
- 启用 `fate-tower-sky-fantasy-v2`。
- 重建 Prompt、Negative、机器配置与示例。

## Phase 7 · 第一章完整落地

扩展至第一章全部怪物、交互物、弹窗、HUD 和状态，并完成顶部/中部/底部地图位置回归。

## Phase 8 · 章节推广

1. 第二章：日照秘境沙海。
2. 第三章：晨辉冰晶回廊。
3. 第四章：星火熔岩峡谷。
4. 第五章：黎明命运终塔。

## Phase 9 · 职业与外围页面

- 射手、狂战士、刺客。
- 角色面板、进阶卡和技能图标。
- 命运树、营地、商店、铁匠。
- 结算、排行榜和大厅。

## Global Acceptance

- 通用资产 ≥ 80；核心资产和 Gold Standard ≥ 85。
- 玩家和单位通过 64/96/128 px。
- 图标通过 32/48 px。
- 文字在正常握持距离轻松阅读。
- 玩家身份、文字、交互物或危险预警不清楚时直接否决。
- 每次重大更新保存真机证据。
