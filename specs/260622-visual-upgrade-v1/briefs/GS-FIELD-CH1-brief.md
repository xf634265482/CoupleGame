## 玩法用途

此图铺在战场底层，用代码 Grid 线叠在上面再放置单位。
它的唯一任务：**给棋盘一个"人站在真实地面上"的质感锚点**，自身不得抢戏。

- 真机目标尺寸：适配 720×1280 战场区域内的地面可视范围；中央有效战场约 `640×720 px`。
- 源文件推荐：`1024×1024`（正方形，可在引擎侧拉伸/适配到战场宽高比）。
- 输出：**无背景透明 PNG**；保留轻微 alpha 渐变在四周（约 8%~12% 边距），使地面与背景/迷雾融合自然。

## 必须表达

### 统一世界身份
- 暖砂岩质感石面，局部有柔和草绿苔迹。
- 极细弱的青色命运痕迹（裂缝中或石缝间微光，不突出）。
- 整体氛围：云暮夕照下的古老塔庭石地，已久经踩踏但仍坚实。

### 本章内容身份（哥布林占领痕迹）
仅限出现在**地面边缘区域**，中央绝对保持干净：
- 浅浅的脚印纹（粗短趾，哥布林体型）埋入石面，不用高对比。
- 零星浅划痕，如临时标记石墙习惯留在地面。
- 极低调补给碎屑痕（粗麻绳压痕 / 残木纹），暗示这里被短暂占用。
- **禁止** 骷髅图案、文字、明确的血迹、武器轮廓。

## 构图

| 项 | 要求 |
|----|------|
| 视角 | 略俯视 3/4（与背景一致），地面向远端轻微透视收敛 |
| 中央安全区（约 60%） | **极低细节，纯净可行走面**，没有装饰，没有痕迹，没有高对比纹 |
| 边缘叙事区（外 20%） | 可有轻微哥布林活动印记和苔痕；强度 ≤ 地面主色的 15% 对比度 |
| 接缝 | 四边需要能与背景 / 迷雾柔和融合（alpha 渐出，无硬边） |
| 透明边 | 四周 10% 区域 alpha 渐变至 0，让地面与背景层自然叠合 |

## 颜色

| 角色 | HEX | 用途 |
|------|-----|------|
| 主色（60%） | `#D7A85B` Warm Sandstone | 地面石面主体 |
| 辅色（30%） | `#78A86B` Soft Grass Green | 石缝苔迹、边缘草色 |
| 点缀（8%） | `#5FB8C8` Cyan Magic（极弱，≤ 20% 不透明） | 命运裂痕微光、石缝底光 |
| 阴影色 | `#A57A3A`（主色降明度 30%，轻偏冷） | 凹陷、痕迹内壁 |
| 描边 / 内分界 | **无**（EV3：Tile 无内描边） |

**色彩硬约束：**
- 饱和度全图 HSV S ≤ 65%（第 1 章上限）。
- 点缀青色不得成为显眼色块；远看看不出，近看隐约可辨即满足要求。
- 禁止纯白高光、霓虹发光、描边线条。

## 光照

- 主光：左上 45° 柔和暖光（`#FFF6E5`，约 5000K），石面左侧 / 上部有轻微斜面高光。
- 右下弱冷填充：`#5FB8C8` 的 20~25% 强度，给石面暗侧轻微冷反光。
- 整体亮度：**略低于角色层**（符合 EV1：场景比角色暗 / 低饱和）。
- 不使用 HDR 爆白、镜面反射或塑料光泽。
