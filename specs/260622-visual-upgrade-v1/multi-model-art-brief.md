# Multi-Model Art Brief

## Purpose

这是发给 ChatGPT、GPT Image、Gemini、Midjourney、Flux、Stable Diffusion、ComfyUI 或其他绘图模型的统一视觉 Brief。

任何模型都必须先阅读本文件，再领取一个具体资产任务。不要让模型一次画完整项目。

## 1. Project Identity

项目：《命运之塔》

风格家族：`fate-tower-sky-fantasy-v2`

视觉定位：

- 明亮、温暖、通透的天空塔庭轻奇幻。
- 精修 Q 版。
- 半厚涂软斜面。
- 深海军蓝炭色轮廓家族，基准 `#17243A`。
- 角色和地图实体必须具有真实、连续的外描边，不能只靠边缘阴影假装描边。
- 运行图标准：256 px 角色外描边约 5 px；84 px 地图实体外描边约 2 px。
- 若绘图模型输出描边过淡，技术处理阶段只在透明轮廓外扩 `#17243A`，不得重画或改变内部像素。
- 左上柔和暖主光，右下弱冷填充。
- 青色命运晶体与柔金纹章是跨页面品牌符号。
- 手机优先可读，玩法信息高于装饰。

禁止：

- 灰黑压抑地牢。
- 写实、恐怖、血腥、猎奇。
- 塑料 3D、镜面金属、真实玻璃。
- 硬赛璐璐、现代扁平、iOS Glass、Material Design。
- 霓虹、紫色主导、纯黑大面积。
- 外部艺术家名和知名 IP 风格。

## 2. Mandatory Chapter Identity Rule

每个章节背景必须同时表达：

1. 统一天空塔庭世界身份。
2. 当前章节的敌人、Boss、玩法机制或环境危险身份。

不能只换颜色。

章节关联通过环境叙事表达，不把具体角色、怪物、交互物、格线或技能预警烘焙进背景。

### Chapter 1 · 云暮哥布林前哨庭

- 统一世界：浮岛遗迹、云海、象牙塔庭、青色命运晶体、桃金夕照。
- 章节内容：哥布林临时占领痕迹。
- 可用元素：粗制木栅栏、破旧赭红旗、号角架、绳索、补给箱、麻袋、简陋瞭望台。
- 普通楼层方向参考：
  `references/gs-bg-ch1-goblin-outpost-selected-a.png`
- 参考图只用于构图与章节叙事；不得复制其中的骷髅旗帜和中央强高光。
- 旗帜统一改用抽象爪痕、折线或简化角形符号，不使用骷髅、骨头或文字。
- 中央区域必须保持低细节连续战场。

### Chapter 2 · 日照秘境沙海

- 暖金沙、象牙遗迹、青绿绿洲、青色晶体。
- 沙漠劫掠、流沙、沙暴防护和巨蝎领地痕迹。
- 禁止熔岩、岩浆、火山和焦黑火系主题。

### Chapter 3 · 晨辉冰晶回廊

- 冰蓝、银白、冷雾、通透冰晶和暖金生命灯。
- 冻结设施、破碎冰障、巨人活动和寒气侵蚀痕迹。

### Chapter 4 · 星火熔岩峡谷

- 深蓝岩灰、焦褐、柔金火光、少量青色晶体。
- 火山工事、熔岩潮汐、锁链和熔火领地痕迹。
- 火橙集中服务危险信息，不能铺满棋盘。

### Chapter 5 · 黎明命运终塔

- 皇家蓝星空向象牙晨光过渡。
- 柔金建筑、青色星光、受控命运紫。
- 预言纹、镜像结构、审判仪式与终塔领地痕迹。

## 3. Player Standard

- 棕发。
- 蓝金轻装。
- 固定青色命运晶体或围巾。
- 约 1.9 头身，允许范围 1.8~2.0。
- 头部约占可见总高 48%~52%，脸是绝对第一焦点。
- 自然探索待机姿态，默认手持轮廓清楚的短剑。
- 默认不持盾，避免遮挡脸部与身体。
- 地图上占格 75%~82%。
- 真机显示高度原则上不低于约 64 px。
- 必须是第一识别焦点之一。

职业变体必须保留脸型、棕发、蓝金家族、青色命运标志和约 1.9 头身。

## 4. Monsters And Bosses

- 普通怪：占格 62%~72%，卡通威胁。
- Elite：82%~92%，轮廓比普通怪加粗约 10%。
- Boss：105%~125%，视觉体量为玩家约 1.5~2.5 倍。
- Boss 至少两个剪影记忆点和一个章节机制标志。
- 威胁通过体型、姿态、武器、剪影和集中危险色表达。
- 禁止多眼、多嘴、断肢、流血和恐怖畸形。

## 5. Battlefield

- 不制作逐格完整实心地砖。
- 使用连续半透明战场平面。
- 普通格线由代码绘制。
- 背景中央 55% 左右为低细节、可行走、落地明确的安全区域。
- 外缘可以有章节叙事，不能侵入棋盘。
- 迷雾中心遮蔽 90%~100%，低饱和深蓝、柔边、少量蓝紫星点。

## 6. UI

- 深海蓝绘制式幻想面板。
- 青色魔法内光。
- 柔金关键边饰。
- `#17243A` 家族轮廓。
- 阅读区不透明度 88%~95%。
- 弹窗主体 92%~98%。
- 装饰区 65%~80%。
- 不是毛玻璃，不使用真实背景模糊。
- 阅读区保持安静，装饰集中在四角和标题节点。

字号：

- 核心按钮/关键数值：24~28。
- 卡片标题：22~24。
- 正文：20~22。
- 辅助信息：18~20，不得更小。

## 7. Icons And Interactables

- 单一主体，最多三组主色。
- 32 px 可辨大类，48 px 可辨具体功能。
- 宝箱：暖金奖励感。
- 钥匙：柔金主体 + 青色晶体。
- 普通出口与 Boss 传送门：直接复用当前工程青色石拱门，不再向绘图模型派发新门素材；两者以显示尺寸、生成时机和玩法状态区分。
- 数字和文字由代码叠加，不画进图片。

## 8. Output Requirements

### Background

- 竖屏 9:16，目标构图参考 720×1280。
- 中央安全区不可裁切。
- 四周预留可裁切扩展。
- 环境中不得出现真实文字、角色或怪物。

### Character / Monster / Boss

- 源图 1024×1024。
- 透明背景。
- 角色约 10% 透明边，Boss 约 12%。
- 不画地面、基座和投影。

### Icon / Interactable

- 源图 512×512；小状态图标可 256×256。
- 透明背景。
- 10%~12% 透明边。

### UI

- 按真实槽位尺寸绘制。
- 9-slice 中心干净可拉伸。
- 不烘焙文字。
