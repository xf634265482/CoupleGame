# Lobby Top Asset Strip Design

## Metadata

- Date: 2026-06-24
- Scope: PVE 大厅右上角顶部资产条
- Related scene: `assets/scripts/lobby/PveLobbyController.ts`
- Status: Approved in terminal discussion, pending implementation

## Problem

当前大厅顶部资产区存在以下问题：

- 资产图标与数字更像简单并排摆放，缺少统一组件感
- 纯黑胶囊底和天空大厅主视觉不在同一气质体系内，显得偏硬、偏廉价
- 三个资源图标风格不统一，像来自不同素材来源
- 两个远征资源缺少“同体系”的视觉关系，体力与货币的语义层级也不够清晰

## Goal

在不改变“三种资源同级并排”信息结构的前提下，升级顶部资产条的质感与可读性：

- 保持微信小游戏顶部常驻信息的清晰读取
- 让组件看起来更完整、更轻盈，而不是素材拼贴
- 让两个远征资源形成同家族识别
- 让体力继续保持独立的状态资源语义

## Approved Direction

采用 `微信原生友好` 为主、带一点 `简洁高级` 的方向。

核心结论：

- 保留三种资源同级并排，不折叠、不收二级
- 使用三颗独立横排胶囊，而不是整条大底座
- 胶囊采用深蓝半透明底，不使用当前的纯黑硬底
- 体力与另外两个远征资源继续区分语义
- 两个远征资源使用“同家族、不同资源”的图标系统
- 三个图标整体改为更 Q、更圆润、更饱满的版本，但避免幼态化

## Visual Structure

### Layout

右上角资产区由三颗独立胶囊横向排列组成：

1. 远征资源 A
2. 远征资源 B
3. 体力

每颗胶囊都遵循统一结构：

- 左侧为图标
- 右侧为数字
- 图标略微压入胶囊左缘，形成轻微徽章感
- 数字视觉居中偏右，保证读数稳定

不采用整条共底座方案，原因如下：

- 独立胶囊更符合微信小游戏顶部状态信息的常见阅读习惯
- 在窄顶部区域中更灵活，不容易显得像系统插件
- 三项资源边界更清晰，用户扫读速度更快

## Style Specification

### Capsule

- 底色：深海军蓝半透明
- 轮廓：极轻冷白描边
- 阴影：仅整颗胶囊保留一层柔和投影
- 圆角：接近半高的短胶囊
- 禁止使用重金边、重发光、重描边

### Icon Placement

- 图标不完全塞进胶囊内部
- 建议约 40% 外探、60% 内嵌
- 图标与数字不是平铺并排，而是形成一个整体组件

### Typography

- 数字使用清晰、偏圆、偏中黑的字重
- 颜色以高对比白字为主
- 体力 `60/60` 中主值优先，分隔后的上限值可轻微降对比
- 不采用过细字体、拉伸字体或强装饰字体

## Size And Spacing

采用偏紧凑的小型常驻条规格，不做成功能按钮：

- 胶囊视觉高度：约 28 到 32 px
- 图标视觉高度：约为胶囊高度的 75% 到 85%
- 三颗胶囊高度、圆角、内边距统一
- 宽度可随数字长度轻微变化，但不允许高低和结构变化
- 胶囊间距略大于单颗胶囊内部图标与数字间距

设计原则：

- 组件之间要分得开
- 组件内部要显得紧凑
- 真机上优先保证扫读速度，而不是装饰层次

## Icon System

### General Direction

三枚图标都改为更 Q 的版本，但维持清楚的功能语义：

- 轮廓更圆润
- 体块更饱满
- 尖刺减少
- 切面简化
- 高光集中在上半部
- 小尺寸下优先保轮廓，不堆细碎纹理

### Resource Semantics

#### 体力

- 图标：圆润的能量闪电
- 语义：状态资源
- 色相：偏青黄暖色

不与远征货币做同家族处理，确保玩家一眼理解它是“消耗与恢复”的状态条目。

#### 远征资源 A

- 图标：Q 弹的紫色晶簇 / 原生结晶
- 语义：偏原生、偏探索来源的远征资源

#### 远征资源 B

- 图标：Q 弹的蓝色晶核 / 精炼单晶
- 语义：偏精炼、偏通用货币的远征资源

### Family Rule

两个远征资源必须满足以下约束：

- 同一晶体家族
- 同一轮廓语言
- 同一高光与上色体系
- 通过形态和颜色区分具体资源

禁止只用“同一图标换颜色”的方案，因为在顶部小尺寸场景中容易混淆。

## Color Strategy

整体策略为 `克制的深蓝胶囊 + 明亮的功能色图标`。

- 胶囊本身不抢主视觉
- 识别依赖图标颜色、轮廓与数字对比
- 不给三颗胶囊分别套上高饱和底色

建议色相分工：

- 远征资源 A：紫
- 远征资源 B：蓝
- 体力：黄

## Interaction Expectations

本次升级仅针对视觉与信息承载，不改变交互语义：

- 点击区域继续覆盖整颗胶囊
- 不额外新增动画需求
- 若需要动效，仅允许非常轻的点击压感或数字刷新反馈

## Acceptance Criteria

- 三颗资源在真机顶部可被一眼分为三个独立组件
- 数字读取速度明显优于当前版本
- 胶囊底与大厅天空背景能够自然融合，不再出现纯黑贴片感
- 两个远征资源一眼可见“同体系”，但不会被误读为同一种货币
- 体力仍保持与远征货币不同的状态资源语义
- 三枚图标在小尺寸下依然清楚、Q 弹、不过幼

## Out Of Scope

本设计不包含以下内容：

- 顶部左侧玩家卡整体改版
- 大厅主标题改版
- 顶部资源的数值规则、产出规则与文案命名变更
- 新的二级资产弹窗或说明层

## Implementation Notes

- 若后续替换图标资源，需要优先复用现有 PVE 大厅结构，尽量只替换视觉参数与资源引用
- 若实现中涉及大厅布局调整，应同步记录到对应 UI 视觉 spec 中
- 若最终实现影响到 PVE 大厅整体构图，应补充真机截图验证顶部安全区表现
