# Phase 3 · Gold Standard 交互物设计

状态：待用户书面复核  
日期：2026-06-23  
适用范围：PVE「命运远征」全部章节

## 1. 目标

建立一套全章节共用的 Gold Standard 交互物家族，确保玩家在手机真机的小尺寸战场中无需阅读文字，也能迅速识别宝箱、钥匙、普通出口、Boss 传送门和功能设施。

本阶段只定义和制作交互物，不修改玩家、怪物、章节背景或 UI Kit。

## 2. 已确认的总规则

- 五章共用同一套交互物，不随章节换皮。
- 交互物属于命运之塔的标准设施，而不是章节环境装饰。
- 采用「简化塔庭圣器」路线。
- 保留深海蓝、柔金和青色命运晶体，但每件资产只保留一个一级轮廓和一个核心功能符号。
- 玩家始终是战场第一视觉焦点。
- 数字、文字和状态说明由代码叠加，不烘焙进图片。

## 3. 视觉层级

| 对象 | 相对视觉权重 |
|---|---:|
| 玩家 | 100 |
| Boss 传送门 | 90 |
| 普通出口 | 76 |
| 功能设施 | 68 |
| 宝箱 | 62 |
| 钥匙 | 56 |

Boss 门可以拥有最高的环境警示权重，但不得遮盖或压制玩家的脸、短剑和身份轮廓。

## 4. 核心资产定义

### GS-CHEST · 宝箱

- 大块深海蓝箱体，柔金包边。
- 中央只保留一枚大型青晶菱形锁芯。
- 表达温暖、明确的奖励感，但视觉权重低于玩家和出口。
- 禁止密集铆钉、细小金线、复杂浮雕和整箱强光。

### GS-KEY · 钥匙

- 柔金主体，粗壮、短柄、轮廓优先。
- 钥匙环嵌入与宝箱相同的青晶菱形锁芯。
- 与宝箱形成明确的「锁具家族」。
- 禁止纤细写实钥匙、复杂齿形和多枚碎晶。

### GS-EXIT · 普通出口

- 使用当前工程中的青色石拱门，与 Boss 传送门共用同一套美术。
- 普通出口与 Boss 传送门通过生成时机、地图状态和显示尺寸区分，不再依赖不同轮廓。
- 普通出口使用 84×84 运行版和较低格内缩放。

### GS-BOSS-PORTAL · Boss 传送门

- 使用当前工程中的青色石拱门 128×128 源图。
- Boss 传送门使用更高格内缩放，并由 Boss 流程和出现时机传达危险身份。
- 不再制作赤金冠刺新版本。

### GS-FACILITY-HOT-SPRING · 恢复温泉样板

- 作为后续神像、祭坛、铁匠等中立设施的设计母样板。
- 一个明确功能轮廓、一个动态提示和一个青晶/柔金品牌点。
- 青色水面表达恢复功能，最多两缕慢速蒸汽。
- 静态帧不依赖蒸汽也必须能识别为恢复设施。
- 用户已批准圆形青水泉池、柔金十字与两缕暖白蒸汽版本。

## 5. 尺寸与输出规格

当前战场格边长约为 100 px，代码负责最终格内缩放。

| 资产 | 格内可视高度 | 源图 | 缩略验收 |
|---|---:|---:|---|
| 宝箱 | 58%–64% | 512×512 RGBA | 32 / 48 / 64 px |
| 钥匙 | 48%–56% | 512×512 RGBA | 32 / 48 / 64 px |
| 普通出口 | 72%–78% | 共用石拱门，84×84 运行版 | 32 / 48 / 64 px |
| Boss 传送门 | 88%–96% | 共用石拱门，128×128 源图 | 48 / 64 / 96 px |
| 恢复温泉 | 66%–72% | 512×512 RGBA | 32 / 48 / 64 px |

技术要求：

- 透明背景。
- 84 px 地图交互物必须具有约 2 px、颜色为 `#17243A` 的连续外描边；描边缺失时在技术处理阶段仅向透明区外扩。
- 普通交互物四周保留约 10% 透明边；Boss 门约 8%。
- 不绘制地砖、场景背景或烘焙投影。
- 接地阴影由代码统一绘制。
- 最多三组主色。
- 青色功能光面积不超过主体约 22%。

## 6. 状态与动态

- 可开启宝箱：柔金锁芯或边缘进行约 2 秒的低频呼吸，不整件闪烁。
- 普通出口与 Boss 门共用稳定青蓝门心；如需状态差异，由代码控制缩放、出现时机或外围提示。
- 恢复温泉：最多两缕慢速循环蒸汽。
- 所有资产的静态首帧必须独立传达类别和功能。

## 7. 制作顺序

1. 宝箱与钥匙成套制作，先锁定材质、边线和青晶锁芯语言。
2. 普通出口与 Boss 传送门复用当前石拱门并完成尺寸校验。
4. 恢复温泉，验证中立功能设施的扩展规则。

每件资产最多生成 2–3 个候选。候选只进入候选目录；用户选择、技术处理、缩略验证和真实战场合成全部通过后，才允许接入正式资源。

## 8. 真机验收

必须同时满足：

1. 不看文字时，玩家能在 1 秒内区分五类交互物。
2. 玩家与交互物同格时，玩家的脸、短剑和轮廓仍清楚。
3. 普通出口与 Boss 传送门虽然共用美术，但在各自玩法流程中不能造成操作目标误判。
4. 宝箱与钥匙能看出配套关系，但不会成为战场第一焦点。
5. 暗底、亮底和迷雾边缘三种场景均保持清晰轮廓。
6. 窄屏、标准屏和长屏均保存等比例或真机截图。

以下任一情况直接否决：

- 32 px 下无法判断资产类别。
- 功能只能依靠发光识别。
- 与玩家同格时遮挡玩家脸部或短剑。
- 共用门在同一操作阶段同时出现，导致目标误判。
- 缩小后细节形成噪点。
- 出现文字、Logo 或章节专属换皮。
- 紫色主导、写实金属、塑料 3D、镜面材质或大面积纯黑。

## 9. 与现有规范的关系

- 延续 VSS v2.0 的明亮天空塔庭、深海蓝轮廓、柔金和青晶品牌语言。
- 遵守玩家身份优先和小尺寸可读性硬规则。
- 2026-06-23 用户最终裁决：普通出口与 Boss 传送门共用当前青色石拱门；此前「青晶上行阶梯」与「赤金冠刺 Boss 门」规则废止。
- Phase 3 不改变章节背景规则；章节身份仍由背景、敌人、Boss 和环境机制表达。
- 本文通过后，`asset-task-board-v1.md` 中 Phase 3 的四项阻塞解除，可进入候选制作。

## 10. 完成定义

Phase 3 只有在五件资产均完成用户选择、技术规格、缩略对照、真实战场合成、真机验收、版本化接入和任务板更新后才算完成。
