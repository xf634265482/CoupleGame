## 1. 改造范式（从第 1–2 章抽出）

永久逐层改造把「每章连续爬塔找钥匙」改成「每章 7 个独立挑战层」：

| 原则 | 含义 |
|------|------|
| 一章七层 | 全局层连续编号；章内层 1–7；第 7 层 Boss |
| 一层一主目标 | `objectiveKind` 决定通关条件，不再默认「钥匙 → 出口」 |
| 每层一个新概念 | 先教再复用；不在同一层堆多套规则 |
| 半固定骨架 | Catalog 固定出生点 / 目标区 / 关键通路；局部怪、宝箱、障碍可按 seed 变 |
| 镜像 + 章特色 | 第 2 章镜像第 1 章层型，但用沙漠机制做出差异（约 3 层专属新玩法） |
| 结算口径 | 首通固定金币 + 命痕三选一；装备主要靠击杀掉落；死亡/撤离不丢永久资产 |

### 1.1 层型骨架（改造后标准）

| 章内层 | 层型 | 第 1 章落地 | 第 2 章落地 | 设计职责 |
|--------|------|------------|------------|----------|
| 1 | 探索 | 钥匙探索 | 钥匙探索 + 沙坑教学 | 移动 / 迷雾 / 通关交互 |
| 2 | 精英猎杀 | 双生精英 | 毒蝎精英 | 指定目标，不清图 |
| 3 | 清指挥源 | 关号角祭坛 | 清沙暴警戒者 | 优先击杀「压力源」 |
| 4 | 追击 | 哨兵逃离 | 沙漠逃离目标 | 路径规划 vs 时限压力 |
| 5 | 突围 / 机关 | 火药爆破封锁 | 限回合走廊突围 | 机关 + 追兵或时限 |
| 6 | 波次生存 | 五波夜袭 | 四波潮汐 + 沙坑扩张 | 高压生存，预演 Boss |
| 7 | Boss | 哥布林酋长 | 流沙巨蝎 | 章主题综合考核 |

写 3–5 章改造时，建议**先决定每层挂哪种层型与通关条件**，再把本章地形 / 怪 / Boss 预演塞进对应层，而不是先堆怪再想目标。

### 1.2 通关结算共性（第 1–2 章已落地）

| 规则 | 口径 |
|------|------|
| 目标完成 | 主目标 `COMPLETE` 后生成**通关传送门**（位置按层规则：钥匙格 / 击杀点 / 中央等） |
| 真正结算 | 玩家走到传送门并**交互**后才 `FLOOR_CLEARED`；不因目标完成强制结束 |
| 不清图 | 除非该层目标写明，否则**不要求**清空全部普通怪 |
| 失败 | 玩家死亡、撤离，或该层专属失败（逃离成功 / 回合用尽等）→ 无通关奖，不丢永久资产 |
| UI | 进层自动弹一次通关条件；HUD「目标」可再开；文案来自 `Chapter1Objectives` / `Chapter2Objectives` |

#### 2.1.1 第 1 章逐层通关设计

| 层 | 通关怎么做 | 失败条件 | 刷门 / 出口 | 不必做的事 |
|----|------------|----------|-------------|------------|

| **4 夺令追逃** | 在哨兵抵达逃离点前**击杀目标哨兵**（`GOBLIN_SENTINEL`） | ① 玩家死亡；② 哨兵抵达闪烁逃离格（`TARGET_ESCAPED`） | 击杀位置刷**唯一**传送门；开局无出口 | 不必清光守卫；不必站上逃离格 |
| **5 火药封锁** | 两步：① 交互激活火药桶；② 再在 **7** 回合内抵达爆破点引爆 | 玩家死亡 / 引爆超时 | 引爆完成后刷传送门 | 激活后狂暴冲锋是压力；超时未引爆即失败 |
| **6 夜袭固守** | 在中央防区**清空连续 5 波**敌人并存活 | 玩家死亡 | 第 5 波清空后中央刷传送门 | 四角刷怪点不可交互；波次怪统一结算，不掉独立永久奖 |
| **7 酋长大营** | **击败哥布林酋长**（`GOBLIN_CHIEF`） | 玩家死亡 | Boss 死亡即目标完成并刷门；**无需钥匙** | 不必清光号角增援怪 |

**第 3 层补充**：通道守卫未清完前祭坛不可关；关坛后须处理场上残留召唤物才算通关。  
**第 4 层补充**：地图 **11×11**；哨兵 0 攻不普攻；被命中会立刻逃 1 格，怪物回合再向逃离点移 2 格；错口石墙拉长战线（无阻挡约 9 怪回合）；守卫阻挠玩家追击；抵达逃离点即失败。HUD 显示「逃离约 N 回合」。  
**第 5 层补充**：顺序固定「先桶后爆」；只激活不引爆不算通关；点桶后 **7** 个玩家回合内必须引爆，超时失败。  
**第 6 层补充**：每波整波刷出后立刻向玩家 rush；第 3–4 波若 4 回合未清完则强制刷下一波；清波后立刻预警并刷下一波。

## 4. 第 3 章 · 冰原要塞（原设计）

**全局层**：15–21（未开放）  
**主题名**：冰原要塞  
**体验意图**：控场与走位——冰墙封路、冰面滑行打断风筝；玩家要学会「拆墙换资源 / 借滑行或避滑行」。

### 4.1 章节背景与美术

| 项 | 路径 / 说明 |
|----|-------------|
| 远征背景图 | `assets/chapter_backgrounds/chapter_3/bg_pve_ch3.jpg`（竖图 720×1280 量级） |

视觉气质：冷色冰原、可破坏冰墙、滑行冰面、冻结墙与碎冰残迹。相对第 2 章「沙黄」，本章应一眼可辨「白蓝 + 墙体阻挡」。

### 4.2 地形调色板

| 类型 | 作用 | 危险度 | 挡视线 |
|------|------|--------|--------|
| `ICE_WALL` | 可破坏阻挡（HP 可打掉，掉少量灵气） | 无伤 | 是 |
| `ICE_TILE` | 踩入触发滑行，打断精确站位 | 无伤（滑行可带额外伤在 Boss 技里） | 否 |
| `FREEZE_WALL` | Boss / 冻结技生成的临时墙 | 视机制 | 是 |
| `SHATTERED_ICE` | 墙被击碎后的残迹 | 可带踩伤（Boss 相关） | 否 |

### 4.3 怪物与灵气怪（设计意图）
