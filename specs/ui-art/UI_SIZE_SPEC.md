# UI 尺寸规范（UI_SIZE_SPEC）

> 生成日期：2026-06-16  
> 设计坐标系：**720 × 1280**（竖屏，FIXED_WIDTH，超长屏向下扩展）  
> 出图规格：**2×**（设计稿尺寸 ×2 = 实际出图像素）  
> 如无特殊说明，下表所有尺寸均为**设计坐标系单位（等价于 1× 像素）**

---

## 全局规格

| 项目 | 数值 |
|------|------|
| 画布宽度（固定） | 720 |
| 画布高度（基准） | 1280 |
| 出图倍率 | ×2（即 1440×2560 基准） |
| 主包 4MB 红线 | 单张不超过 256KB（压缩后） |
| 超长屏适配 | 竖向扩展，宽度永远720 |
| 字体基础大小 | 正文 20sp，标题 28-32sp |

### ⚠️ Safe Area（刘海屏/全面屏必读）

微信小游戏在 iPhone X 及以后机型（包括所有 iPhone Pro）和安卓全面屏上存在系统安全区域，  
UI 元素放置在安全区之外会被遮挡或与系统手势冲突。

| 区域 | iPhone X+ 刘海屏 | 安卓全面屏（参考值） | 设计坐标换算（720宽基准） |
|------|-----------------|-------------------|------------------------|
| 顶部状态栏 | 44pt | 24-40dp | 约 **40-50px** 避让 |
| 底部 Home 条 | 34pt | 0-20dp | 约 **30-45px** 避让 |

**规则：**
- 所有顶部 HUD 信息条：上边缘距屏顶 ≥ **50px**（设计坐标）
- 所有底部按钮（方向键、动作按钮）：下边缘距屏底 ≥ **50px**（设计坐标）
- 当前代码 `cy = -screenH/2 + 105` 约为距屏底 105px，**已满足**底部安全区，但需在实机确认
- 美术出图不需要留安全区白边，由代码 `SafeArea` API 在运行时调整位置
