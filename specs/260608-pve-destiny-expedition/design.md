# PVE「命运远征」玩法设计文档

> 本文件是 **PVE 模块玩法规则的唯一主文档**（single source of truth）。
> 任何 PVE 玩法规则、数值、流程、地图实体、怪物 AI、掉落、灵气/职业/词条/装备、Boss 机制或验收口径修改，必须同步本文件。约束见 `.cursor/rules/pve-module.mdc`。
> PVE 与 PVP（`specs/260529-combat-board-game-rework/design.md`）**完全独立**，两套规则互不覆盖。

## 1. 模式定位

- **模式名称**：命运远征
- **核心玩法**：迷雾探索 + Roguelike 成长 + 爬塔挑战
- **目标体验**：玩家进入命运之塔，通过探索地图、击败怪物、获取装备、职业进阶与词条强化，逐步构筑流派，挑战更高层数。
- **单层节奏**：3~5 分钟，适配微信小游戏碎片化游玩。

### 1.1 与 PVP 的区别

| | PVP（联机派对棋） | PVE（命运远征） |
|---|---|---|
| 核心 | 骰子对战、玩家竞争、生存淘汰 | 地图探索、Build 构筑、职业成长、Boss 挑战、无限爬塔 |
| 人数 | 2~4 人联机 | 单人 |
| 地图 | 环形赛道 75 格 | 迷雾网格 8×8 / 9×9 / 10×10 |
| 权威 | 服务端权威，watch 实时同步 | 客户端模拟，云端仅存档 + 奖励边界校验 |

## 2. 远征机制

| 项 | 规则 |
|----|------|
| 起始 | 第 1 层开始，初始职业「冒险者」 |
| 自动存档 | 每完成一层自动存档：当前层数、HP、金币、装备、职业、职业词条 |
| 返回大厅 | 每层结算后可选「继续远征」或「返回大厅」 |
| 继续远征 | 再次进入从**下一层**开始（完成第 7 层 → 下次从第 8 层） |
| 死亡 | 角色死亡 → 本次远征结束 |

### 2.1 死亡结算

- **获得**：金币、钻石、命运碎片（结算奖励）。
- **清空**（局内）：装备、职业、职业词条、当前金币、当前灵气。
- **保留**（局外）：成就、图鉴、钻石、命运碎片。

> 钻石为账户资产，PVE 与 PVP 共享 `users.diamond`；命运碎片为 PVE 专属局外资产 `users.destinyShards`。

## 3. 章节结构

每 5 层一个章节，章节末为 Boss 层；击败章节 Boss 进入营地。

| 章节 | 层数 | Boss | 地图尺寸 |
|------|------|------|----------|
| 第一章 | 1~5 | 哥布林酋长 | 普通层 8×8，Boss 层 10×10 |
| 第二章 | 6~10 | 沙虫女王 | 普通/高层 8×8~9×9，Boss 层 10×10 |
| 第三章 | 11~15 | 冰霜巨人 | 9×9，Boss 层 10×10 |
| 第四章 | 16~20 | 熔岩领主 | 9×9，Boss 层 10×10 |
| 第五章 | 21~25 | 命运守卫 | 9×9，Boss 层 10×10 |

> 地图尺寸：普通层 8×8（64 格），高层 9×9（81 格），Boss 层 10×10（100 格）。具体每层尺寸以 `PveConstants` 配置为准。

### 3.1 营地

每击败章节 Boss 进入营地，功能：商店、装备整理、返回大厅、继续远征。

## 4. 行动点系统（AP）

| 项 | 规则 |
|----|------|
| AP 公式 | `AP = 8 + 骰子点数`，骰子 1~6 → 每回合 9~14 AP |
| 移动 1 格 | 2 AP |
| 普通攻击 | 2 AP（玩测后调高，增加走位策略空间） |
| 开启宝箱 | 1 AP |
| 开启出口门 | 1 AP |
| 使用神像 | 1 AP |
| 使用祭坛 | 1 AP |
| 回合结束 | 玩家可主动结束；AP 耗尽自动结束 |

## 5. 地图系统

| 项 | 规则 |
|----|------|
| 类型 | 迷雾探索网格地图 |
| 战争迷雾 | 地图初始全部隐藏，仅显示玩家附近区域；移动后逐步揭开 |
| 实体存在 | 所有内容以实体形式真实存在于地图，被迷雾遮挡；探索后显示真实内容 |
| 设计目的 | 增强探索感、路线规划、资源争夺感 |

### 5.1 地图实体

| 实体 | 类型 |
|------|------|
| 玩家 | 玩家角色 |
| 普通怪 / 灵气怪 / 精英怪 / Boss | 移动单位 |
| 宝箱 / 铁匠 / 神像 / 温泉 / 祭坛 / 钥匙 / 出口门 | 固定实体 |

## 6. 怪物系统

| 怪物 | 行为 | 掉落 |
|------|------|------|
| 普通怪 | 发现玩家后追击，进范围攻击 | 50% 少量金币 / 25% 少量灵气 / 25% 金币+灵气 |
| 灵气怪 | 发现玩家后逃跑（形成追逐玩法） | 100% 大量灵气 |
| 精英怪 | 巡逻 → 发现玩家 → 主动追击 | 40% 中量金币 / 30% 中量金币+灵气 / 15% 大量金币 / 10% 装备 / 5% 进阶卡 |
| Boss | 章节最终挑战，拥有专属机制 | 必掉装备 |

## 7. 战斗系统

- **地图即时战斗**：不进入独立战斗场景，玩家与怪物共存于同一地图。
- 玩家用 AP 进行移动、攻击、走位；怪物按 AI 行动。
- 循环：探索 → 发现敌人 → 走位 → 战斗 → 获取奖励。

## 8. 职业系统

| 职业 | 加成 | 说明 |
|------|------|------|
| 冒险者 | 初始职业 | 无特殊加成 |
| 狂战士 | 攻击 +1.5 | 立即损失 2 HP |
| 射手 | 攻击 +0.5，攻击距离 +2 | |
| 隐匿者 | 攻击 +1，移动距离 +1 | |

- **职业碎片**：每层随机生成 2 个职业的碎片；集齐 3 个同职业碎片可选择进阶改职业。

## 9. 灵气系统

- **获取**：灵气怪、精英怪、神像、祭坛、奖励掉落。
- **强化规则**：每累计达到当前阈值灵气自动触发强化选择，从 3 个强化词条中选 1 个。
- **阈值递增**：初始阈值 100，每次触发后 × 1.5（取整）：100 → 150 → 225 → 338 → …，越往后强化越难触发，形成成长曲线压力。

## 10. 职业词条系统（V1，共 19 个）

### 冒险者词条（强化词条，每次灵气满触发 3 选 1，可叠加进度）
| 词条 | 效果 |
|------|------|
| 强化 HP | 选中时立即 最大HP +4 / 当前HP +4 |
| 强化攻击 | 普通攻击伤害永久 +1 |
| 强化 AP | 每回合 AP 上限永久 +1 |
| 淘金 | 拾取金币永久 +20% |

### 狂战士词条
| 词条 | 效果 |
|------|------|
| 吸血 | 每次攻击回复 1 HP |
| 狂暴 | HP ≤ 50% 时攻击 +1 |
| 血怒 | 击杀时回复 2 HP |
| 不屈 | 致死伤害保留 1 HP，每层触发一次 |
| 反击 | 受到攻击时对攻击者造成 1 伤害 |

### 射手词条
| 词条 | 效果 |
|------|------|
| 鹰眼 | 攻击距离 +1 |
| 射手精通 | 攻击 +0.5（向上取整计入伤害） |
| 连射 | 30% 概率对同一目标再射一箭 |
| 穿透 | 无视护甲减伤 |
| 暴击 | 20% 概率三倍伤害 |

### 隐匿者词条
| 词条 | 效果 |
|------|------|
| 疾步 | 移动消耗 AP -1 |
| 背刺 | 本回合有移动时首次攻击双倍伤害 |
| 潜行 | 怪物警戒范围 -2 |
| 残影 | 每层首次受击时闪避 |
| 刺客之心 | 对非追击状态敌人伤害 +2 |

## 11. 装备系统

### 11.1 装备栏（5 个槽位）
| 槽位 | 作用 |
|------|------|
| 武器 | 提升攻击 |
| 头盔 | 提升 HP |
| 护甲 | 提升防御 |
| 鞋子 | 提升移动能力 |
| 饰品 | 特殊效果 |

### 11.2 品质（5 级）
普通（白）→ 精良（绿）→ 稀有（蓝）→ 史诗（紫）→ 传奇（橙）

### 11.3 结构与来源
- 每件装备 = 基础属性 + 随机词条（例：嗜血战斧 攻击+3，词条「攻击时回复 1HP」）。
- 来源：普通怪极低概率、精英怪中概率、Boss 必掉、宝箱概率掉落。

## 11b. Boss 专属机制

每个章节 Boss 除基础追击攻击外，拥有专属机制。数值以 `PveConstants`/各 Boss 文件为准。

### 哥布林酋长（第 1 章，第 5 层）
- **蓄力重击**：每 3 个怪物回合触发一次，伤害 × 2。

### 沙虫女王（第 2 章，第 10 层）
- **地洞突袭**：每 4 个怪物回合触发一次——消失，下一回合在玩家曼哈顿距离 ≤ 1 的随机空格重现，并立即造成 × 2 倍伤害；传送期间（status = `BURROWED`）免疫攻击。
- **流沙扩张**（反风筝，2026-06-14）：每次潜地在 boss 身侧翻起 2 个动态沙坑（存续 5 回合后消失）；踩入沙坑移动 AP +2（由 +1 上调）；Boss 房静态沙坑由 4 → 5。逐步压缩风筝走廊。

### 冰霜巨人（第 3 章，第 15 层）
- **冰面滑行**（反风筝，2026-06-14 由「冰冻 AP-4」重做）：每 4 个怪物回合的近战命中后，以玩家当前格为中心铺一片冰面（曼哈顿 ≤1，存续 2 回合）。玩家站在冰面上移动时沿方向**连续滑行**到第一个非冰格/障碍前，丢失「精确后撤 1 格」的走位控制 → 打断风筝。冰面不造成伤害，纯改变移动。

### 熔岩领主（第 4 章，第 20 层）
- **灼烧印记**：每次近身攻击附带灼烧，玩家在接下来 3 个回合每回合开始时额外扣 1 HP（可叠加层数，层数 × 1 HP/回合）。
- **熔岩潮汐**：二阶段每批焰格由 3 → 6（2026-06-14），加大安全区压缩。

### 命运守卫（第 5 章，第 25 层）
- **高血压制**：玩家当前 HP > 50% 最大 HP 时，守卫造成的伤害 × 2（保留）。
- **命运预言**（反风筝，2026-06-14 由「40% 随机闪避」重做）：每 3 个怪物回合标记玩家当前格，**下个**回合该 3×3 区域爆炸（伤害 = 攻击 × 1），逼玩家走位；站桩苟血风筝者必吃。随机闪避整套删除。
- **命运镜像**：HP ≤ 33% 时在相邻空格生成攻击力 × 0.5 的镜像（保留）。

## 12. 楼层通关规则

| 层类型 | 生成 | 流程 |
|--------|------|------|
| 普通层 | 钥匙 ×1、出口门 ×1 | 找到钥匙 → 找到出口门 → 进入下一层 |
| Boss 层 | 钥匙 ×1、Boss ×1 | 找到钥匙 → 击败 Boss → Boss 位置生成传送门 → 进入下一层 |

## 13. V1 版本开发范围

职业 3 个、Boss 5 个、职业词条 15 个、装备位 5 个、装备品质 5 级、普通怪 4 种、精英怪 4 种；地图实体：宝箱、钥匙、出口门、神像、铁匠、祭坛、温泉、怪物、Boss。目标：优先完成可玩版本，单层 3~5 分钟。

## 14. 技术权威与存档（架构约束）

| 项 | 规则 |
|----|------|
| 权威模型 | 局内玩法在客户端 `assets/scripts/pve/core` 即时模拟；核心逻辑零框架依赖、确定性、种子化 RNG |
| 云端职责 | `pve` 云函数仅负责每层存档（`pve_saves`）与对元货币奖励（钻石/命运碎片）做边界校验后入账 |
| 存档 | 每层完成自动存档，含 RNG 种子，可断点续玩与云端复算 |
| 防作弊 | 奖励入账由云函数按单层上限/层数连续性/种子复算校验，不无条件信任客户端 |

## 15. 里程碑

- **M1（垂直切片）**：第一章（1~5 层）核心循环端到端：迷雾 8×8、AP、移动/普攻、1~2 种普通怪、宝箱/钥匙/出口门、灵气强化（简版）、Boss 哥布林酋长、自动存档、返回大厅续玩。
- **M2+**：章节 2~5、完整职业/词条/装备/灵气、灵气怪/精英怪、营地、成就/图鉴/命运碎片元进度。
