# 命运远征验收清单

- [ ] 大厅能读取资料并选择 1–14 层中已解锁楼层。
- [ ] 首次教程楼层不扣体力；之后每次创建楼层挑战扣 5 点。
- [ ] 体力不足时云端拒绝创建挑战，客户端给出明确提示。
- [ ] 1–14 层均能进入、行动、保存、恢复、通关或死亡结算并返回大厅。
- [ ] 第一章与第二章目标、怪物、Boss、资源和 UI 完整。
- [ ] 同一 seed 与输入序列得到相同结果。
- [ ] 85 件固定装备能被目录解析，掉落和营地库存引用同一 `definitionId`。
- [ ] 战士、射手、游侠的基础面板、职业动作、熟练度和灵气爆发可用。
- [ ] 命痕收集、装配、方案、追踪、试炼和战斗效果可用。
- [ ] 云端开始、保存、结算接口幂等，重复请求不重复扣费或发奖。
- [ ] GM 仅能调整钻石、体力、当前资料重置和当前数值配置。
- [ ] 第三至第五章不能从当前大厅流程进入。
- [ ] `npm run typecheck:game` 通过。
- [ ] `npm run test:pve -- --runInBand` 通过。
- [ ] `cloudfunctions/common` 测试通过。
- [ ] `gm-web` 构建通过。
