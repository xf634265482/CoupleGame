# Visual_Style_Baseline — 项目唯一视觉基准

## Purpose

锁定《命运之塔》唯一视觉方向，并作为角色、怪物、Boss、UI、图标、场景、特效和 AI 生成的最高视觉基准。

本版本记录 2026-06-22 完成的全量视觉冲突裁决。旧“蓝发剑士 + 苔藓灰石格”基线自本版本起降级为历史参考，不再决定新资产方向。

---

## Standards

### 1. 当前权威状态

| 项 | 状态 |
|----|------|
| 文字规则 | 本文件与 VSS 其它文件为当前权威 |
| 旧锚图 `art_pipeline/references/pve-style-reference.png` | 历史参考，不再用于新资产最终裁决 |
| 新 Gold Standard 锚图 | 待制作、真机验证和用户批准 |
| 现有云暮概念稿 | 方向参考，不等同最终锚图 |
| 旧 Prompt 与机器 Style Anchor | 暂停用于生成新资产，待新锚图批准后统一重建 |

新锚图批准前，不允许删除旧锚图，也不允许把任何概念稿直接宣布为唯一锚图。

### 2. 世界主题

全局主题为：

> 明亮、温暖、通透的天空塔庭轻奇幻。世界由云海、浮岛、遗迹、晶体、晨昏天光与命运符号构成；危险通过章节环境和玩法信息表达，不通过灰黑压抑、血腥或恐怖表达。

控制原则：

- 背景负责建立世界，玩法区域负责承载信息。
- 画面外缘可以精彩，中部棋盘必须安静。
- 灰青石、苔绿、旧木、哑金不再是全局主色，只能作为局部材质。
- 全局跨页面基础色为晴空蓝、象牙白。
- 品牌强调色为青色命运光与柔金。
- 章节拥有独立调色板，但共享统一画法、光照、轮廓与可读性标准。

### 3. 唯一玩家身份

默认玩家锁定为：

- 棕发。
- 蓝金轻装。
- 青色命运晶体或围巾作为固定身份标志。
- 约 1.9 头身，允许范围 1.8~2.0；头部约占可见总高 48%~52%。
- 大头、短躯干、短四肢，脸部是绝对第一焦点。
- 自然探索待机姿态，默认手持轮廓清楚的短剑；不默认持盾。
- 精修 Q 版、半厚涂软斜面、深色清晰外轮廓。

地图中的玩家必须始终是第一识别焦点之一。玩家真机清晰可辨高于“整张地图同时完整可见”；禁止为了塞入全图而无限缩小玩家。

职业变体必须保留棕发、蓝金家族、青色命运标志、约 1.9 头身和基础脸型。职业差异通过武器、肩部、披风、体态和职业点缀色表达。

### 4. 统一画法

```
Style Family ID: fate-tower-sky-fantasy-v2
Style Class: Polished Chibi Fantasy · Semi-Painterly · Outlined
World Theme: Bright sky tower fantasy · floating ruins · destiny crystals
Character DNA: 1.9-head face-first hero · compact readable silhouette · oversized hands and feet
Rendering DNA: softly beveled painted surfaces · restrained highlights · no plastic rendering
Outline DNA: deep navy charcoal family · strong complete outer contour
Lighting DNA: warm upper-left key · faint cool lower-right fill
Readability DNA: phone-first · effortless reading · gameplay information above decoration
```

所有角色、怪物、Boss、NPC、道具与 UI 必须像同一团队绘制。禁止写实解剖、恐怖猎奇、塑料 3D、硬赛璐璐、扁平矢量或现代应用 UI 混入。

### 5. 深色轮廓家族

- 基准轮廓：Deep Navy Charcoal `#17243A`。
- 暖色资产可轻微偏向深褐蓝，但不得形成彩色描边。
- 玩家、怪物、交互物、图标使用完整强轮廓。
- Elite 比普通怪加粗约 10%。
- Boss 加粗约 15%~20%。
- 场景装饰轮廓显著减弱。
- 连续棋盘地面和普通格线不使用实体粗描边。
- 禁止纯黑、双描边、渐变描边、发光描边和局部消失。

### 6. 固定光照

- 主光固定为左上方柔和暖光，约 5000K。
- 右下保留弱冷色填充。
- 章节只能增加低强度环境色、边缘光和局部反射，不得反转主光。
- 高光只集中于眼睛、晶体和少量金属。
- 不使用镜面反射、塑料高光和大面积纯白。

### 7. 明亮手绘材质

- 统一采用半厚涂软斜面与克制高光。
- 石材按章节使用暖砂岩、象牙石、冰蓝石、深蓝火山岩等，不默认灰黑。
- 木材使用温暖风化木，不使用脏黑腐木。
- 金属使用柔金、浅铜、哑光银，不使用镜面金属。
- 晶体以分层色块表达通透，不使用真实玻璃透明。
- 布料柔软清楚，避免复杂微纹理。
- 单资产主要材质不超过五种。

### 8. 章节主题

| 章节 | 视觉主题 | 主体 | 危险表达 |
|------|----------|------|----------|
| 第 1 章 | 云暮塔庭 | 暖砂岩、柔和草绿、晴空蓝、桃金夕照 | 蓝紫远景云雾、局部危险色 |
| 第 2 章 | 日照秘境沙海 | 暖金沙、象牙遗迹、青绿绿洲、青色晶体 | 低饱和紫灰/玫瑰灰沙暴、流沙、毒色 |
| 第 3 章 | 晨辉冰晶回廊 | 冰蓝、银白、冷雾、通透冰晶、暖金生命灯 | 碎冰、冻结纹、寒气 |
| 第 4 章 | 星火熔岩峡谷 | 深蓝岩灰、焦褐、柔金火光、少量青色晶体 | 集中的火橙熔岩、危险红、紫灰热浪 |
| 第 5 章 | 黎明命运终塔 | 皇家蓝星空、象牙白晨光、柔金建筑、青色星光 | 受控命运紫、预言纹与 Boss 机制 |

第二章禁止熔岩、岩浆、火山和焦黑火系章节身份；第四章才是熔岩章节。

#### 8.1 章节内容关联硬规则

每个章节背景必须同时表达两层身份：

1. **统一世界身份**：天空塔庭、浮岛遗迹、命运晶体、柔金纹章与统一绘制语言。
2. **本章内容身份**：本章敌人族群、Boss 领地、核心玩法机制、探索目标或环境危险留下的可读痕迹。

禁止只通过换色表达章节。章节背景必须让玩家在不看文字时，也能推断“这里属于哪一章、可能面对什么”。

内容关联必须通过环境叙事表达：

- 敌人活动痕迹、建筑改造、营地结构、工具、旗帜、图腾、运输方式。
- Boss 领地特征与机制暗示。
- 本章关键地形、资源和危险的视觉预告。

但不得：

- 把具体怪物或角色直接烘焙进背景。
- 把玩法预警、可交互目标或真实格线画进背景。
- 让叙事装饰侵入中央棋盘安全区。
- 为了章节关联破坏明亮、易读与统一世界语言。

第一章背景正式定义为“云暮哥布林前哨庭”：天空塔庭遗迹被哥布林临时占领，外缘可出现粗制木栅栏、破旧旗帜、号角架、小型补给箱、绳索和简陋瞭望台；中央仍保持安静的暖砂岩连续战场。

### 9. 连续棋盘

- 不再制作或使用逐格完整实心地砖作为主棋盘表现。
- 棋盘由连续半透明战场平面、代码格线和独立状态覆盖层构成。
- 棋盘必须有明确落地感，不能完全透明。
- 普通格线低对比但清楚可见。
- 章节背景的棋盘中部必须是低细节可行走平台。
- 浮岛、云海、遗迹、晶体与强光集中在棋盘外缘和远景。
- 选中、移动、攻击和危险范围拥有高于普通格线的层级。

### 10. 战争迷雾

- 中心遮蔽度 90%~100%，边缘柔化。
- 主体为低饱和深蓝，少量蓝紫星点和云纹。
- 迷雾必须安静，不得比单位、交互物或预警更鲜艳。
- 探索时约 0.3 秒柔和淡出，结束后不残留遮罩。

### 11. 地图单位尺寸

| 单位 | 建议占格比例 |
|------|--------------|
| 玩家 | 75%~82% |
| 普通怪 | 62%~72% |
| Elite | 82%~92% |
| Boss | 105%~125%，可适度跨格显示 |

- 玩家主体真机显示高度原则上不得低于约 64 px。
- Boss 视觉体量通常为玩家 1.5~2.5 倍；终章 Boss 可更大。
- Boss 落脚点和逻辑格必须清楚。
- 固定战场窗口优先；地图内容只在窗口内部移动。

### 12. 玩家焦点

- 玩家保持最高局部清晰度、完整轮廓和明确蓝金/青色身份。
- 脚下低强度青色命运环柔和常亮。
- 移动、选中、回合开始时短暂增强。
- 危险预警出现时玩家光环降亮，让位于危险信息。
- 禁止持续粒子喷发、巨大光柱和高频闪烁。

### 13. UI 视觉基线

UI 使用深海蓝绘制式幻想面板：

- 半厚涂软斜面。
- 深海军蓝主体。
- Deep Navy Charcoal 外轮廓。
- 青色魔法内光。
- 柔金关键边饰。
- 不是毛玻璃，不使用真实背景模糊。
- 不使用厚重 MMORPG 石框。
- 不使用现代扁平、Material Design 或 iOS Glass。

透明度按功能分级：

| 区域 | 不透明度 |
|------|----------|
| HUD、战报、持续阅读区 | 88%~95% |
| 弹窗主体 | 92%~98% |
| 装饰条、非阅读区 | 65%~80% |
| 按钮主体 | 接近不透明 |

所有文字必须位于安静底色上。美观、通透与阅读性冲突时，无条件优先阅读性。

### 14. 字体与按钮

- 正文、数值、按钮：清晰中粗圆角无衬线中文字体。
- 短标题、章节名、Boss 名：可用轻度奇幻展示字体。
- 展示字体不得进入正文、战报、数值和按钮。
- 字体必须允许商业游戏内嵌与微信小游戏使用。
- 长文本通过精简、换行或滚动处理，禁止缩字硬塞。

| 内容 | 设计字号 |
|------|----------|
| 核心按钮、HP/AP、关键数值 | 24~28，加粗 |
| 卡片标题、怪物名称 | 22~24，加粗 |
| 战报正文、常规资源 | 20~22，中粗 |
| 辅助信息 | 18~20，不得更小 |

- 可点击区域不得小于约 76×76 设计像素。
- 次级按钮只降低视觉重量，不能小到难点或淡到难看。

### 15. 图标与功能色

- HUD/状态图标位于安静面板时不重复套厚框。
- 道具、装备、技能使用统一圆角承载框。
- 按钮图标与按钮一体，不再套第二层框。
- 单图标只表达一个概念，最多三组主色。
- 32 px 可辨认大类，48 px 可辨认具体功能。
- 数量、数字、稀有度文字由代码叠加。

功能色语义全游戏固定；章节色只影响环境、材质、怪物主体和装饰。稀有度色只用于框、角标或小面积光效，不污染物品本体。

### 16. 动效与特效

- 待机：轻微呼吸、披风摆动或晶体微光。
- 移动：短促重心变化，不持续上下弹跳。
- 点击：约 0.08~0.15 秒压缩与回弹。
- UI 转场：约 0.15~0.3 秒。
- 命中、拾取、升级反馈集中在 0.15~0.5 秒。
- 常驻环境粒子低密度、低对比、移动慢。
- 同屏只保留一个主要特效焦点。
- 低端机可减少装饰粒子，但不得丢失玩法提示。

### 17. 构图与适配

- 参考竖屏构图为 720×1280。
- 背景采用中央玩法安全区与四周可裁切扩展区。
- 棋盘平台、关键遗迹和主光方向位于安全区。
- 浮岛、云海、晶体和远景装饰位于可裁切区。
- 顶部避让微信胶囊和异形屏，底部避让系统手势区。
- 背景不得拉伸，至少验证窄屏、标准屏和长屏。
- HUD、战场外框、战报和操作区绝对固定。
- 棋盘内容只在固定裁切窗口内移动；远景仅允许极弱视差。

### 18. 资源与版本

- 角色、怪物、Boss 源图以 1024 方图制作，运行资源按真机需求降采样。
- 图标源图 512；状态小图标可用 256。
- 角色透明边约 10%，Boss 约 12%，物品约 10%~12%。
- 透明边不得让主体在真机变小。
- UI 按目标槽位和 9-slice 制作，中心保持干净。
- 背景按安全裁切比例制作。
- 不把文字、数量、棋盘底纹或多个状态烘焙进单一资源。
- 新资产先以 `_v2` 或候选路径保存；批准并真机验证后再切换引用。
- 旧资产标记 deprecated/history，不随机参与加载。
- 不破坏 `.meta` UUID，不删除 PVP 资源。

## Examples

### 正确

第一章战场以暖砂岩连续平台承载代码格线，外缘有云暮遗迹和晶体；玩家棕发蓝金、占格约 80%，脚下青色命运环；HUD 使用高不透明深海蓝绘制面板，文字在正常握持距离清晰可读。

### 错误

使用高饱和蓝紫背景铺满棋盘、逐格重复石纹、玩家缩到难以辨认、文字直接压在云层上，再用强发光补救。
