# Lighting_Guide — 光照规范

## Purpose

定义《命运之塔》全项目的光照语言。

光照决定**体积感、调性、注意力焦点**。本项目所有角色、Boss、UI 元素、场景都共享**同一套虚拟光照**，这是 Pillar 2（同一只笔）在物理层面的实现。

> 比 `standards/03_Art/Animation_Guide.md` 或 `VFX_Guide.md` 更上游：本文件管"光从哪来、什么色、多强"。

---

## Standards

### 1. 光照 4 原则

| # | 原则 | 一句话 |
|---|------|-------|
| L1 | 单一主光方向 | 全项目主光统一从左上 45°（**不可漂移**） |
| L2 | 温度对偶 | 暖主光 + 冷反射，与 Color_Language §8.2 协同 |
| L3 | 高光克制 | 高光只点在金属 / 水晶 / 眼睛；面数 ≤ 2 |
| L4 | 软阴影 | 阴影边缘软 2~5px，永不硬切 |

---

### 2. 主光（Key Light）

| 属性 | 值 |
|------|----|
| 方向 | **左上 45°**（永远） |
| 色温 | ≈ 5000K（温暖白） |
| 色相 | 略偏暖黄 `#FFF6E5` |
| 强度 | 中等（不爆白、不锐刺） |
| 锁定状态 | **不可漂移**（违反需开评审会） |

**为什么左上 45°**：
- 与手机用户主要视觉习惯（从左到右扫读）一致
- 让所有角色在画面中"右下脸"形成阴影 → 体积感统一
- AI 模型对"左上光"提示响应最稳定

**实操**：所有 Prompt 必须显式包含 `soft warm key light from upper-left`，**不留模糊空间**。

---

### 3. 环境光 / 反射光（Fill / Bounce Light）

| 属性 | 值 |
|------|----|
| 方向 | 右下（与主光对称） |
| 色温 | 冷蓝青（≈ 7500K） |
| 色相 | `#5FB8C8` Cyan Magic 的 30% 强度 |
| 强度 | 主光的 ≈ 30% |
| 锁定状态 | 强度 / 色相可微调，方向不变 |

**为什么右下冷反射**：
- 与暖主光形成 §1 L2 温度对偶
- 让暗部不死黑，保留体积
- 给"魔法世界"暗示（冷反光来自世界的魔法本底）

---

### 4. 阴影规则

#### 4.1 阴影分层

```
受光面：       基础主色
半阴影：       基础主色 -25~35% 明度 + 偏冷
深阴影：       基础主色 -40% 明度 + 偏冷
接触阴影：     基础主色 -50% 明度 + 偏冷（脚下、衣摆与身体交界）
```

> 全部"层"≤ 3 层（除受光面），不做超过 5 层的厚涂层叠。

#### 4.2 阴影边缘

| 类别 | 边缘软度 |
|------|---------|
| 大块身体阴影 | 软 4~5 px 渐变 @ 1024 |
| 衣物褶皱 | 软 2~3 px |
| 接触阴影 | 软 1~2 px（最接近"硬"） |
| **禁止** | 0~1 px 硬切（赛璐璐） |

#### 4.3 阴影方向

- 所有阴影由 §2 主光方向决定
- 同一画面中**不允许出现两个方向的阴影**
- 角色 + 道具 + 装备 + UI 元素共享同一光照方向

---

### 5. 高光（Highlight）

#### 5.1 高光位置

| 位置 | 允许 | 备注 |
|------|------|------|
| 金属面 | ✅ 1~2 个小高光 | 长条状或点状 |
| 水晶 / 魔法面 | ✅ 1~2 个，颜色偏冷 | 表达透感 |
| 眼睛 | ✅ 1 个白点 | 让角色"活" |
| 皮肤 | ⚠️ 仅鼻尖 / 颧骨 1 点（极淡） | 不允许大面积 |
| 头发 | ⚠️ 1~2 条丝光 | 沿头发流向 |
| 布料 / 木 / 苔藓 | ❌ 无高光 | 软斜面体现体积即可 |

#### 5.2 高光色

- 暖材质（金属铜、皮肤）：高光偏暖白 `#FFF5DC`
- 冷材质（水晶、冰）：高光偏冷白 `#E8F6FF`
- **不用纯白 `#FFFFFF`**

#### 5.3 高光大小

- 单个高光面积 ≤ 总面积的 2%
- 全资产高光总面积 ≤ 8%
- 超出 → 滑向塑料 3D（违反 Pillar 4）

---

### 6. 特殊光照（章节 / Boss / VFX）

#### 6.1 章节边缘光（Chapter Rim Light）

> 在 Boss / 重要角色身上添加章节主题色的微弱边缘光，增加临场感。**不改变主光方向**。

| 章节 | Rim 色 | 强度 |
|------|--------|------|
| 第 1 章 | Cyan Magic `#5FB8C8` | 10% |
| 第 2 章 | Cyan Magic `#5FB8C8` 或 Oasis Green `#5FB05C` | 10% |
| 第 3 章 | 冰青 `#A8E8F0` | 15% |
| 第 4 章 | 火橙 `#E0581E` | 15% |
| 第 5 章 | 命运紫 `#7A4FB5` | 10% |

#### 6.2 Boss 底光（Boss Under-Glow）

- Boss 脚下可加章节元素色的**淡发光**（< 20% 面积、不形成完整光环）
- 用于强化 Boss 体量感
- 普通怪 / NPC **不用**

#### 6.3 VFX 光照（特效闪光）

- 命中闪光：白色，0.05~0.10s，覆盖区 ≤ 30%
- 元素光圈：元素色，scale 0→1.4，0.20s，**不要发光 halo**
- 详见 `standards/03_Art/VFX_Guide.md`

---

### 7. UI 光照

> UI 元素也"长在世界里"，必须有光照感。

- UI 面板顶部加 1~2 px 暖白高光（模拟左上光打到边缘）
- UI 面板底部加 1~2 px 冷阴影（模拟右下反光暗部）
- 按钮 Pressed 状态：高光位置不变，整体暗 10%
- **拒绝**：iOS 风毛玻璃 / Material Design 阴影 / 任何"现代 UI" 的光照风格

---

### 8. 不允许（Forbidden）

| 禁项 | 为什么 |
|------|-------|
| ❌ 全屏方向光 | 破坏 L1 单一方向 |
| ❌ 多向光（顶光 + 底光同时） | 同上 |
| ❌ HDR 高动态范围 | 与半厚涂语言冲突 |
| ❌ 镜面金属反光 | 违反 Pillar 4 半厚涂 |
| ❌ 大面积纯白高光 | 滑向塑料 |
| ❌ 硬阴影边缘 | 违反 L4 |
| ❌ 不同资产用不同光向 | 违反 L1 + Pillar 2 |
| ❌ Boss 用反向光（右下主光） | 章节统一性破坏 |

## Examples

### 正确：第 2 章流沙巨蝎光照
> 主光：左上 45° 暖白（`#FFF6E5`）✓ L1
> 反射：右下 30% 冷青蓝 ✓ L2
> 边缘：第 2 章青色晶体 rim 10% ✓ §6.1
> 底光：脚下柔和玫瑰灰沙尘 < 20% 面积 ✓ §6.2
> 高光：胸甲岩石面 2 个小高光 + 眼睛 1 点 ✓ §5.1

### 错误：自由发挥光照
> "我加了个戏剧性的下方红光让 Boss 更恐怖"
> 违反 L1（多方向）+ Pillar 5（恐怖调性）→ 返工

### 正确：UI 弹窗光照
> 弹窗顶部 2px 暖白高光，底部 2px 冷暗 → 与世界主光一致，自然贴合 → 通过

## AI Notes

- Prompt 中**必须显式**写 `soft warm key light from upper-left, faint cool fill from lower-right`，**不留漂移空间**
- 不要写 `dramatic lighting / cinematic lighting / studio lighting` → 模型会乱解
- 检查出图：先看右下角阴影方向是否一致（不一致 → 重生成或后期调整）
- 章节切换不改主光，只加 §6.1 Rim

## Checklist

- [ ] 主光方向 = 左上 45°（L1）
- [ ] 暖主光 + 右下冷反射（L2）
- [ ] 高光仅在金属 / 水晶 / 眼睛，总面积 ≤ 8%（L3）
- [ ] 阴影分层 ≤ 3 层 + 软边 2~5px（L4 + §4）
- [ ] 阴影色按 §4.1 偏冷
- [ ] 章节 Rim 颜色 + 强度对（§6.1）
- [ ] 没碰 §8 禁项
- [ ] Prompt 包含强制光照短语
