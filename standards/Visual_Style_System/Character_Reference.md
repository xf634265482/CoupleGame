# Character_Reference — 角色统一视觉语言

## Purpose

定义玩家、职业变体与 NPC 的唯一角色视觉规则。怪物和 Boss 分别查 `Monster_Reference.md` 与 `Boss_Reference.md`。

## Standards

### 1. 通用角色画法

- 精修 Q 版轻奇幻。
- 半厚涂软斜面。
- Deep Navy Charcoal `#17243A` 完整外轮廓。
- 左上柔和暖主光，右下弱冷填充。
- 大手大脚，简化手指。
- 单角色主要材质不超过五种。
- 真机 64/96/128 px 缩放可辨。

### 2. 默认玩家

默认玩家永久身份：

- 棕发。
- 蓝金轻装。
- 青色命运晶体或围巾。
- 约 1.9 头身，允许范围 1.8~2.0。
- 头部约占可见总高 48%~52%，大头、短躯干、短四肢。
- Compact Heroic / Compact Knight。
- 自然探索待机姿态，默认手持一把轮廓清楚的短剑。
- 默认不持盾，避免遮挡身体、脸部和同屏玩法信息。
- 自信、平静、清楚可读。

玩家不得因地图扩大而缩得难以辨认；地图内建议占格 75%~82%，真机主体高度原则上不低于约 64 px。

### 3. 玩家焦点

- 保持同屏最高局部清晰度与完整轮廓。
- 低强度青色命运环常亮。
- 移动、选中、回合开始时短暂增强。
- 危险预警出现时光环主动降亮。
- 禁止持续粒子喷发、巨大光柱和高频闪烁。

### 4. 职业变体

所有职业保留棕发、蓝金家族、青色命运标志、约 1.9 头身、脸型和人物气质。

| 职业 | 识别方式 |
|------|----------|
| 冒险者 | 蓝金轻装、手持短剑、均衡紧凑剪影 |
| 射手 | 短弓、青绿色披肩、羽饰、轻巧体态 |
| 狂战士 | 暖红金点缀、厚肩、短柄重武器、敦实体态 |
| 刺客 | 深蓝紫、短斗篷、双短刃、前倾体态；不纯黑蒙面 |

地图形象、角色面板、进阶卡和技能图标必须使用同一套职业身份。

### 5. NPC

- NPC 保持 2.2~2.5 头身。
- 暖意明显，站姿稳定。
- 不得夺取玩家的蓝金/青色身份组合。
- 通过剪影、职业道具和暖色表情区分身份。
- 不使用现代服饰、写实民族服饰或性化表现。

### 6. 配饰与姿态

- 每个角色至少一个剪影记忆点。
- 总配饰不超过五件。
- 标准资产为略俯视 3/4 view。
- 静态资源不画挥击中、飞跃中或强透视动作。
- 攻击动作由动画表达，基础资产保持清楚稳定。

### 7. 禁止

- 蓝发剑士继续作为默认玩家权威。
- 改变玩家 1.8~2.0 头身范围、脸型或核心身份。
- 玩家缩小到真机阅读吃力。
- 写实解剖、塑料 3D、硬赛璐璐、恐怖猎奇、现代服饰。
- 不同页面为同一职业发明不同造型。

## Examples

正确：棕发冒险者穿蓝金轻装，青色围巾形成固定剪影，约 1.9 头身并手持短剑，64 px 仍能辨认脸部与武器。

错误：职业进阶后改成银发六头身写实刺客，并取消青色命运标志。
