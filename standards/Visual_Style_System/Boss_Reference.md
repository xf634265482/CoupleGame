# Boss_Reference — Boss 视觉体系

## Purpose

为章节 Boss / Apex Boss 提供视觉规范，避免 Boss 沦为"高血量普通怪"。

本文件回答：
- 一个合格 Boss 在视觉上要具备什么？
- 怎么让 Boss "压住"画面但又不"恐怖"？
- Apex Boss（章末终极）与普通章节 Boss 在视觉上的差异？

> 继承 `Character_Reference.md` §1 通用基础；本文件只写 **Boss 专属**。

---

## Standards

### 1. Boss Tier 视觉差异表

| 项 | 章节 Boss（T6） | Apex Boss（T7，第 5 章末） |
|----|----------------|-------------------------|
| 头身比 | 2.5~3.0 | 2.8~3.5 |
| 体型相对玩家 | 1.5~2.5× | 2.5~3.5× |
| 外描边 | 基准 +15% | 基准 +20% |
| 章节 Rim 光 | ✅ 强（15%） | ✅ 极强（20%）+ 命运紫纹章光 |
| Boss 底光 | ✅ 弱 | ✅ 强（章节元素色） |
| 调色 | 章节"重 / 冷"变体 | 哑金 / 米白 + 命运紫 |
| 危险色点缀 | 8~10% | 10~12% |
| 剪影记忆点 | ≥ 2 | ≥ 1 独特元素 + 2 个章节呼应元素 |
| 配饰件数 | ≤ 5 | ≤ 6 |
| 情绪锚点 | 强（怒 / 冷 / 狂） | 极强（庄严 / 审判） |
| 视觉重量 | T6 | T7 |
| 站位 | 屏幕中上 50~60% | 屏幕中上 60~70% |

---

### 2. Boss 5 必备要素（Five Essentials）

任何 Boss 必须同时满足以下 5 条；缺一返工。

| # | 要素 | 描述 |
|---|------|------|
| E1 | 标志性轮廓（Iconic Silhouette） | 1~2 个剪影记忆点，让 Boss 黑剪后仍能被一秒识别 |
| E2 | 标志性符号（Iconic Symbol） | 1 个"看就懂"的视觉标识（双角 / 巨锤 / 长袍冠 / 锁链） |
| E3 | 章节元素呼应（Chapter Element Tie） | 至少 1 处材质 / 色彩 / Rim 与所在章节绑定 |
| E4 | 威压感（Presence） | 体型 ≥ 1.5 玩家 + 描边加粗 + Boss 底光 |
| E5 | 可读情绪（Readable Emotion） | 情绪清晰（怒 / 冷 / 狂），不滑入恐怖 / 痛苦 |

---

### 3. Boss 设计 7 步流程

```
[1] 确定章节 + 是否 Apex
[2] 选择章节 Boss 主题（火 / 冰 / 暗 / 命运 ...）
[3] 选 Shape_Language §1.2 二级身体原型（必须与同章节小怪家族对比）
[4] 定 E2 标志性符号（一句话写出来：'twin curved horns + chained molten hammer'）
[5] 三色 60/30/10（主用章节'重 / 冷'变体，点缀用章节强调色）
[6] 加 E3 章节呼应（章节 Rim + 材质特征）
[7] 验 E1/E4/E5（剪影测试 + 与玩家同框压迫感 + 情绪可读性）
```

### 4. Boss 主题与原型组合表

| 章节 | Boss 主题 | 推荐二级原型 | 标志性符号示例 | 主色策略 |
|------|---------|------------|-------------|---------|
| 第 1 章 | 哥布林酋长 | Hunched Brute | 宽大酋长头饰 + 重型武器 | 暖砂岩/草绿家族 + 珊瑚危险点缀 |
| 第 2 章 | 流沙巨蝎 | Hunched Brute / 独立低姿巨蝎形态 | 巨钳 + 高耸蝎尾 | 暖金沙 + 象牙甲壳 + 玫瑰灰危险 |
| 第 3 章 | 冰霜巨人 | Armored Titan / Tall Sorcerer | 冰冠 + 双手冰斧 | 冷蓝重 + 冰青强调 |
| 第 4 章 | 熔岩领主 | Armored Titan | 双弧形火角 + 锁链火锤 | 深蓝岩灰重 + 火橙危险 |
| 第 5 章（Apex） | 命运裁决者 | Tower Presence + 独立形态 | 哑金王冠 + 命运罗盘 + 长杖 | 哑金主 + 米白 + 命运紫 |

> 同章节 Boss **必须**与同章节小怪在身体原型 / 标志性符号上**形成对比**（如小怪 B 家族 / Boss A 家族）。

### 5. Boss 站姿与构图

#### 5.1 静态立绘姿态

- 站姿，居中
- 双手姿势开放（暗示力量在外延）：
  - 武器单手提起 + 另一手张开 / 握拳
  - 双手扶武器（如剑 / 杖触地）
  - 双手交叉胸前（冷面 Boss）
- **不**画"挥击中" / "蓄力中" / "扑出" 等动作姿态
- 头部略低或抬高（不正视镜头），暗示俯视玩家

#### 5.2 构图

- 留 12% 透明边（比普通怪 10% 略多，让 Boss 显得"塞满"画面）
- 武器 / 配饰允许超出常规边缘（但仍在透明边内）
- 单图无第二角色 / 无小弟

### 6. Boss 危险色规则

> 危险色 = 章节危险色（详见 `Color_Language.md` §4 各章节"危险"行）。

| Boss Tier | 危险色面积 | 位置 |
|----------|---------|------|
| 章节 Boss | 8~10% | 眼睛 / 武器纹 / 胸甲核心 / 脚下底光 |
| Apex Boss | 10~12% | 同上 + 命运紫纹章 |

> 危险色**集中**在 2~3 个点（不要均匀分布），形成视觉"焦点"。

---

### 7. Boss 情绪 5 类（与禁忌）

| 情绪 | 实现 | 例 |
|------|------|----|
| 怒 Wrath | 瞪眼 + 眉压低 + 牙齿略露 | 熔岩领主 |
| 冷 Cold | 半睁眼 + 嘴角平直 + 略仰视 | 冰霜巨人 |
| 狂 Mad | 大睁眼 + 嘴角斜上诡笑 | 暗影 Boss |
| 庄严 Solemn | 闭眼 / 半睁 + 嘴角下压 + 头略低 | Apex 命运裁决者 |
| 审判 Judge | 平视 + 眼神冷 + 武器垂直 | Apex 变体 |

**绝对禁止**：
- ❌ 痛苦惨叫（嘴大张 + 仰天）
- ❌ 流血 / 滴口水 / 流泪
- ❌ 多眼多嘴诡异组合
- ❌ 性化 Boss
- ❌ 卡通"萌系" Boss（破坏 E4 威压感）

---

### 8. Apex Boss 专属规则

Apex Boss = 第 5 章命运终塔末，**全项目唯一**：

| 项 | 锚定 |
|----|----|
| 头身比 | 2.8~3.5（独立比例规则） |
| 体型 | 2.5~3.5× 玩家 |
| 标志性符号 | 必须包含"命运罗盘 / 命运纹章"元素 |
| 调色 | 哑金主 + 米白辅 + **命运紫 10~12% 点缀** |
| 描边 | 基准 +20% |
| Rim | 章节命运紫 + 哑金辉光 |
| 形态变化 | 允许 2 阶段视觉变化（设计中走 spec） |
| 独有元素 | 必须有 ≥ 1 个其他角色禁用的剪影元素 |

---

### 9. Boss 与玩家同框（最关键）

> Boss 战画面是项目"视觉门面"，必须严格执行。

| 项 | 规则 |
|----|----|
| 体型差 | Boss ≥ 1.5× 玩家 |
| 站位 | Boss 屏幕中上 50~60% / 玩家屏幕下方 20% |
| 视线 | Boss 略俯视玩家（头略低、眼下扫） |
| 色彩对比 | Boss "重 / 冷"变体 vs 玩家蓝青保持 |
| HUD | Boss HP 条独立显示在 Boss 下方，**不**遮挡 Boss 头部 |
| 大招 telegraph | 视觉预警在 Boss 头顶 / 武器上发光（章节危险色） |

---

### 10. Boss 禁止表

| 禁项 | 为什么 |
|------|-------|
| ❌ Boss 体型 ≤ 玩家 | 违反 E4 + Visual_Hierarchy §5 |
| ❌ Boss 与同章节小怪剪影相似（IoU > 0.4） | 视觉无差异 |
| ❌ Boss 无章节呼应 | 违反 E3 |
| ❌ Boss 用霓虹 / 紫粉主导 | 违反 Color_Language §10 |
| ❌ Boss 多眼 / 多嘴 / 多肢诡异 | 违反 E5 + Pillar 5 |
| ❌ Boss 滴血 / 伤口 | 同上 |
| ❌ Boss 看起来"只是大号小怪" | 违反 E1 + E2 |

## Examples

### 正确：第 2 章 Boss · 流沙巨蝎
> 章节：2，Tier：T6
> 主题：流沙 + 潜地压迫
> 二级原型：独立低姿巨蝎形态
> 头身：2.8
> 体型：2.2× 玩家
> E1 标志性轮廓：巨钳 + 高耸弯曲蝎尾（剪影一秒识别）
> E2 标志性符号：双钳 + 分节毒尾
> E3 章节呼应：象牙甲壳 + 青色晶体 rim 10% + 脚下玫瑰灰沙尘
> E4 威压：描边 +15% + 体型 2.2× + 站姿张开
> E5 情绪：怒（瞪眼 + 牙齿略露）
> 三色：暖金沙 60% / 象牙甲壳 30% / 玫瑰灰危险点缀 8%
> 与同章节沙漠劫匪、沙虫幼体和毒蝎形成明显体量与尾部轮廓差异 ✓

### 错误：自创"萌系" Boss
> "我设计一个 Q 萌大眼 Boss 让玩家想抱"
> 违反 E4（无威压）+ §7 禁忌（萌系破坏 Boss 调性）
> 修正：保持 Q 版（Pillar 7）但情绪走 §7 的怒 / 冷 / 狂

### 错误：Boss 多眼诡异
> 设计 Boss "8 只发光眼睛 + 多嘴"
> 违反 §7 禁忌 + Pillar 5
> 修正：单一情绪锚点 + 1 双眼
