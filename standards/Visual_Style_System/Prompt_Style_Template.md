# Prompt_Style_Template — 统一 Prompt 模板

## Purpose

管理《命运之塔》视觉生成 Prompt 的生效状态与重建流程。

## Standards

### 1. 当前状态

> 状态：SUSPENDED — 暂停用于生成新资产。

旧模板包含蓝发剑士、苔藓灰石格、旧轮廓色和旧章节映射，已与 `Visual_Style_Baseline.md` 冲突。任何 AI 或脚本不得继续使用旧模板生产正式新资产。

### 2. 恢复条件

只有以下条件全部满足后，才能发布新模板：

1. Gold Standard 玩家、第一章怪物、交互物、棋盘、迷雾、UI 和背景均已制作。
2. 核心资产评分不低于 85。
3. 完成 64/96/128 px 与 32/48 px 缩放验证。
4. 完成微信真机验证。
5. 用户批准新的组合锚图。
6. 新 Style Anchor、Negative、机器 JSON 和示例同步完成。
7. 全库不存在旧锚点残留。

### 3. 新模板必须包含

- 明亮天空塔庭轻奇幻。
- 棕发蓝金玩家、青色命运围巾、约 1.9 头身与手持短剑。
- 精修 Q 版、半厚涂软斜面。
- Deep Navy Charcoal `#17243A` 轮廓家族。
- 左上暖主光与右下弱冷填充。
- 明亮章节材质与受控环境对比。
- 手机优先可读。
- 新 Gold Standard 锚图引用。
- 对应章节主题与禁止项。

### 4. 生效流程

Conflict Report → 用户裁决 → 修改 VSS → 制作 Gold Standard → 评分 → 真机验证 → 用户批准锚图 → 重建 Prompt → 同步机器配置 → 一致性检查。

未走完流程时，禁止创建“临时正式模板”。

## Examples

正确：在新锚图批准前，仅进行路线图、规格和生产计划工作，不调用图像生成。

错误：把旧 Prompt 中的“blue-haired”替换成“brown-haired”后继续批量生成。
