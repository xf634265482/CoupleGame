# Monster_Reference — 怪物视觉体系

## Purpose

为普通 / 精英怪物提供完整视觉规范。Boss 单独走 `Boss_Reference.md`。

本文件回答：
- 一只新怪物的"风格 DNA"怎么定？
- 同章节怪物怎么"像一家人但又有区别"？
- 普通怪 vs 精英怪在视觉上怎么拉开差距？

> 继承 `Character_Reference.md` §1 通用基础；本文件只写**怪物专属**部分。

---

## Standards

### 1. 怪物 Tier 视觉差异表

| 项 | Common（T3） | Elite（T5） |
|----|------------|-----------|
| 头身比 | 2.0~2.5 | 2.5~2.8 |
| 体型相对玩家 | ≤ 1.2× | ≤ 1.4× |
| 外描边 | 基准 6~10px | 基准 +10% |
| 章节 Rim 光 | ❌ 不用 | ✅ 微章节 Rim（10%） |
| 调色 | 章节 §4 基础 + 弱点缀 | 章节 §4 基础 + 章节强调色点缀（10%） |
| 危险色点缀 | 0~3% | 5~8% |
| 剪影记忆点 | ≥ 1 | ≥ 1 + 1 个差异点 |
| 配饰件数 | ≤ 3 | ≤ 4 |
| 表情情绪 | 凶 / 愣 / 狡（清晰） | 同 + 更强（更凶 / 更狡） |
| 视觉重量 | T3 | T5 |
| Boss 底光 | ❌ | ❌ |

### 2. 怪物 5 步设计流程（按顺序）

> AI 接到"设计一只新怪"任务时**必须**按此顺序，不允许跳步。

```
[1] 确定章节 + Tier（common / elite）
[2] 查 §3 章节家族表，确定继承的家族特征
[3] 选 Shape_Language §1.2 二级身体原型（家族内可选）
[4] 给 1 个剪影差异点（让它与同章节其它怪区分）
[5] 三色 60/30/10（主取章节基础、辅取章节装饰、点缀按章节强调）
```

**任何不按此顺序的生成视为违规。**

### 3. 章节怪物家族表（Family Matrix）

> 每章节有 1~2 个家族 + 1~2 个家族特征关键词。
> 新怪物**只能在其章节家族内变异**，不允许跨家族。

| 章节 | 家族 | 形状原型范围 | 共享家族特征 | 主色范围 |
|------|------|------------|------------|---------|
| 第 1 章 云暮塔庭 | B · Squat Creature | Low Crouched Scout / Hunched Brute | 低姿弓背 + 大耳 / 头巾 / 轻甲 | 柔和草绿主 + 暖砂岩/蓝金小面积点缀 |
| 第 2 章 日照秘境沙海 | A · Compact Heroic + B · Squat Creature | Slim Adventurer / Low Crouched Scout / Hunched Brute | 风化披巾 / 甲壳 + 沙地低姿 | 暖金沙主 + 象牙白辅 + 青绿或青色晶体点缀 |
| 第 3 章 冰霜回廊 | C · Tower Presence + A · Compact Heroic | Tall Sorcerer / Slim Adventurer | 棱角冰附着 + 长袍披风 | 冷蓝主 + 冰青强调 |
| 第 4 章 熔岩深层 | A · Compact Heroic + B · Squat Creature + C · Tower Presence | Compact Knight / Hunched Brute / Armored Titan | 焦黑岩壳 + 火光裂隙 | 深蓝岩灰主 + 焦褐辅 + 火橙点缀 |
| 第 5 章 命运终塔 | A + C 混合 | 由具体怪物决定 | 哑金命运纹 + 米白长袍 | 哑金主 + 米白 + 命运紫点缀 |

> 同章节怪物剪影 IoU 应 ≤ 0.6（既家族化又有差异）。

### 4. 普通怪命名族谱（建议命名模式）

> 用于命名一致性，方便记忆 / 检索。

| 章节 | 模式 | 例 |
|------|------|----|
| 第 1 章 | `goblin_<职业>` 哥布林 + 职业 | goblin_scout, goblin_brute, goblin_shaman |
| 第 2 章 | `desert_<职业/物种>` 沙漠 + 身份 | desert_raider, sandworm_larva, poison_scorpion |
| 第 3 章 | `frost_<职业>` 冰霜 + 职业 | frost_acolyte, frost_lancer |
| 第 4 章 | `lava_<职业/物种>` 熔岩 + 身份 | lava_grunt, lava_crab, fire_elemental |
| 第 5 章 | `judge_<元素>` 裁决 + 元素 | judge_initiate（裁决见习） |

资源命名：`monster_ch{n}_{tier}_<name>.png`（与 `standards/08_Assets/Naming.md` 一致）。

### 5. 视觉差异化 5 维度

> 同章节多只怪如何区分？

| 维度 | 操作 | 例 |
|------|------|----|
| 1. 武器形状 | 不同武器轮廓 | 短棒 / 长弓 / 头骨杖 |
| 2. 头饰 / 头形 | 不同头部记忆点 | 兜帽 / 头骨 / 鹿角 |
| 3. 体态 | 同家族不同姿态 | 弓背 vs 持杖站立 |
| 4. 色彩点缀 | 不同点缀色（仍在章节调色板内） | 火橙 / 暗红 / 火黄 |
| 5. 配饰 | 不同小挂件 | 骨链 / 火符 / 锁链 |

每只新怪至少在 **2 个维度**与同章节已有怪不同，才能通过设计。

### 6. 怪物配色策略

#### 6.1 章节基础 + 强调
- 主色 60% = 章节基础色
- 辅色 30% = 章节装饰色
- 点缀 10% = 章节强调色 OR 危险色

#### 6.2 危险等级表达
- 越凶的怪点缀色饱和度越高（但仍 ≤ §3 章节梯度）
- Elite 比 common 点缀色面积大 2~3%

#### 6.3 不允许
- ❌ 跨章节借色（如第 1 章怪使用第 4 章火橙熔岩裂隙）
- ❌ 玩家蓝青作主色（与玩家"撞色"）
- ❌ 全黑 / 全白主色

---

### 7. 怪物表情与情绪锚点

| 类型 | 情绪 | 实现 |
|------|------|------|
| 斥候 / 灵巧型 | 狡 | 眯眼 + 嘴角斜上 |
| 战士 / 粗暴型 | 凶 | 瞪眼 + 龇牙（不画血） |
| 萨满 / 法师型 | 阴 | 半睁眼 + 嘴角下压 |
| 矮怪 / 萌威胁 | 愣 / 萌凶 | 大眼 + 张嘴 |
| 飘浮 / 幽魂 | 空 / 阴 | 无瞳孔 + 鬼火青光 |

**禁止**：恐怖扭曲 / 痛苦惨叫 / 流泪 / 多眼诡异。

---

### 8. 视觉重量调控（Visual Hierarchy 工具）

> Common（T3）与 Elite（T5）在 `Visual_Hierarchy.md` §1 不同 Tier，调控手段固定：

| Common 应该 | Elite 应该 |
|------------|----------|
| 描边基准 | 描边 +10% |
| 无 Rim | 微章节 Rim 10% |
| 较小剪影 | 较大剪影 |
| 点缀 ≤ 3% 危险色 | 点缀 5~8% 危险色 |
| 中等饱和 | 略高饱和（仍在章节梯度内） |
| 单一标志性头饰 | 标志性头饰 + 1 个肩 / 武器装饰 |

---

### 9. 怪物禁止表

| 禁项 | 为什么 |
|------|-------|
| ❌ 自创跨章节家族（如第 1 章用 C 高耸） | 违反 §3 家族表 |
| ❌ 与玩家剪影 IoU > 0.4 | 战斗中分不清谁是谁 |
| ❌ 头身比超出 §1 范围 | 违反 Shape §2 |
| ❌ 暴力 / 血腥 / 恐怖外观 | 违反 Pillar 5 |
| ❌ 完全相同的双胞胎怪（视觉无差异） | 违反 §5 差异化 |
| ❌ Boss 级体量（≥ 1.5 玩家）的"普通怪" | 视觉重量错配 |
| ❌ 真实人类装束（士兵 / 警察 / 现代） | 违反 Pillar 5 |

## Examples

### 正确：第 1 章 Elite 设计
> 章节：1 / Tier：Elite
> 家族特征：低姿弓背 + 大斗篷（§3 ch1）
> 二级原型：Hunched Brute（B 家族内）
> 头身：2.6
> 差异点：右肩骨片护肩 + 左手长柄战槌
> 三色：Moss Green 主 / Worn Wood 辅 / 危险红 8% 点缀（眼睛 + 战槌纹）
> 描边：基准 +10%
> 微章节 Rim：第 1 章 Cyan Magic 10%
> 与同章节 common 哥布林斥候差异：体型 +30% / 装备 +1 件 / 危险色 +5%
> § 5 维度差异：武器形状 + 头饰 + 色彩点缀 = 3 ✓

### 错误：跨章节借色
> 给第 1 章一只 elite 加火橙熔岩裂隙"为了与第 4 章伏笔"
> 违反 §6.3 + §3 家族表
> 修正：熔岩裂隙属于第 4 章；第 1 章伏笔只使用受控的 Cyan Magic 命运痕迹
