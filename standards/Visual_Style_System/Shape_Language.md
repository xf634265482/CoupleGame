# Shape_Language — 形状语言

## Purpose

定义《命运之塔》所有视觉资产的**几何骨架与剪影规范**。

形状是视觉识别的基础。色彩可以丢、纹理可以糊、表情可以模糊，但**剪影必须清楚**。
本文件回答 4 个问题：
1. 角色用什么几何骨架？
2. 比例怎么定？
3. 剪影怎么设计？
4. 描边怎么画？

下游 `Character / Monster / Boss / Item / Icon / UI _Reference.md` 全部引用本文件。

---

## Standards

### 1. 形状家族（Shape Families）

整个项目共 **3 个一级形状家族** + **6 个二级身体原型**。
任何新角色 / 怪物 / Boss 必须归属其中之一，**不允许"自创"**。

#### 1.1 一级形状家族

| 家族 | 几何骨架关键词 | 代表角色 |
|------|--------------|---------|
| **A · Compact Heroic**（紧凑英雄） | 倒梯形上身 + 圆头 + 中等四肢 | 玩家、剑士类 NPC |
| **B · Squat Creature**（蹲伏生物） | 椭圆躯干 + 短四肢 + 大头 + 低姿 | 哥布林、地精、小型怪 |
| **C · Tower Presence**（高耸存在） | 长矩形躯干 + 厚肩 + 长披风 / 长袍 | Boss、巫师、Tall NPC |

#### 1.2 二级身体原型（Body Archetypes）

| 原型 | 家族 | 用途 |
|------|------|------|
| `Compact Knight` | A | 玩家、骑士敌人 |
| `Slim Adventurer` | A | 弓手、盗贼、灵巧型 |
| `Low Crouched Scout` | B | 哥布林斥候、低姿小怪 |
| `Hunched Brute` | B | 矮粗怪、地精战士 |
| `Tall Sorcerer` | C | 法师、长袍 Boss |
| `Armored Titan` | C | 重甲 Boss、巨型怪 |

> 同一章节内的怪物**优先用 1~2 个家族**（保家族感）；Boss 用对比家族（保差异）。

### 2. 头身比（Head-to-Body Ratio）

| 角色类 | 头身比 | 锁定状态 |
|--------|------|---------|
| 玩家 | **1.8~2.0，目标 1.9** | 锁定范围 |
| NPC | 2.2~2.5 | 范围内自由 |
| 普通怪（小型 / B 家族） | 2.0~2.5 | 范围 |
| 普通怪（中型 / A 家族） | 2.3~2.5 | 范围 |
| 精英怪 | 2.5~2.8 | 范围 |
| Boss | 2.5~3.0 | 范围 |
| Apex Boss（章末大 Boss / 巨型） | 2.8~3.5 | 范围 |

**头身比测量法**：
- 站立姿态下，头顶到下巴 = 1 头长
- 测量从头顶到脚底的总高度 ÷ 头长 = 头身比
- 角 / 头饰**不计入**头长（按"颅骨"算）

**为什么不允许 6+ 头身**：违反 Pillar 7（Q 版可识别）+ Pillar 1（100px 下头部太小看不清）。

**玩家专用比例**：玩家头部含头发约占可见总高 48%~52%；躯干和四肢主动缩短。默认玩家以 64 px 下脸部方向、棕发轮廓和手持短剑同时可辨为最终裁判。

### 3. 身体结构原则（Q-Body Structure）

#### 3.1 比例分配（基于 1 头长 H）

```
头部：       1.0 H
颈：         0.1 H（几乎隐藏）
躯干（含胸+腰）：1.0 ~ 1.2 H
腿（含脚）：  1.0 ~ 1.3 H
手臂全长：   0.9 ~ 1.1 H（垂下时到大腿中部）
手：         0.4 H（相对大）
脚：         0.5 H 长（相对大）
```

玩家是本表的紧凑特例：头部约 1.0H，头部以下全部身体约 0.8~1.0H；躯干、腿和关节不得按普通角色比例纵向展开。玩家总高以 1.8~2.0H 为硬范围。

#### 3.2 手脚处理

- **大手大脚原则**：手 ≈ 0.4 头长，脚 ≈ 0.5 头长
- **不画 5 指**：合并为"拳形手" / 3~4 指简化形
- **不画指甲、指节细节**
- 鞋 / 靴底部加厚（增加底部视觉重量，符合 Pillar 7）

#### 3.3 头部

- 圆润，下颌略圆（避免尖锐写实下巴）
- 眼睛占面部宽度 ≈ 1/3，间距 ≈ 1 眼宽
- 鼻 / 嘴极简（暗示性 2~3 笔）
- 头发用大块色 + 2~3 条暗线分组，**不画单根**

#### 3.4 装备相对比例

- 单手武器 ≤ 0.9× 体高
- 双手武器 ≤ 1.2× 体高
- 法杖 0.9~1.1× 体高，顶端水晶为剪影记忆点
- Boss 武器可至 1.5× Boss 体高（Apex 例外）

### 4. 描边规范（Outline Spec）

> 详见 `Visual_Style_Baseline.md` §3 A4~A6。本节给出可执行细节。

#### 4.1 描边参数（1024×1024 源图）

| 项 | 值 |
|----|----|
| 外描边粗细 | **6~10 px** |
| 内分隔线粗细 | 外描边的 50~70%（3~7 px） |
| 描边色 | `#17243A`（Deep Navy Charcoal） |
| 高光面附近偏移 | 可暖移至 `#2A2520`（≤ 5° 偏移） |
| 边界暗边覆盖率 | ≥ **42%** |

#### 4.2 描边粗细按角色类别

| 类别 | 外描边 |
|------|--------|
| 玩家 / 普通怪 | 基准（6~10px） |
| Elite | 基准 +10% |
| Boss | 基准 +15% |
| Apex Boss | 基准 +20% |
| Icon / 小型道具 | 基准 +10%（缩到 256 仍可见） |
| UI 框 | 4~6px（@1024）独立尺度 |

#### 4.3 描边覆盖率检测

- 取角色边界一圈像素带（向内 3px 宽）
- 计算暗值 ≤ `#404040` 的像素占比
- 占比 < 42% → 描边不足，必须重画 / 后处理

#### 4.4 描边禁止

- ❌ 渐变描边（外深内浅）
- ❌ 彩色描边
- ❌ 双描边
- ❌ 虚线 / 点描边
- ❌ 局部"虚化"或"消失"
- ❌ 纯黑 `#000000`（在暗背景上隐形）
- ❌ 高饱和彩色描边或发光描边

### 5. 剪影设计（Silhouette Design）

#### 5.1 剪影 3 大测试

| 测试 | 方法 | 通过线 |
|------|------|--------|
| **黑剪测试** | 角色填纯黑、缩 64px | 能 1 秒识别身份 |
| **家族差异测试** | 同章节任意 2 角色剪影并排 | IoU ≤ 0.6（小怪间） / ≤ 0.4（Boss vs 小怪） |
| **背景独立测试** | 把剪影放在亮 / 暗两种背景上 | 都能跳出来 |

#### 5.2 剪影记忆点（Silhouette Landmark）

每个角色**必须有 ≥ 1 个**位于轮廓上的"标志性凸起"：

| 类型 | 例 |
|------|----|
| 头部 | 角、独角、长耳、宽帽、头冠、长发束 |
| 肩部 | 厚肩甲、披风缺口、肩刺 |
| 手部 | 武器、长杖、巨爪 |
| 背部 | 翅膀、长袍裙摆、尾巴 |

**Boss** 必须有 ≥ 2 个剪影记忆点（如 "双角 + 锁链锤"）。
**Apex Boss** 必须有 1 个**独一无二**的剪影元素（其他角色禁用同形）。

#### 5.3 剪影家族（Silhouette Family）

同一章节怪物共享"剪影家族特征"，但每只必有差异点：

```
第 1 章 (B 家族 - Low Crouched):
  ├─ 共享：低姿弓背 + 大斗篷
  ├─ 哥布林斥候：差异 = 短棒右倾
  ├─ 哥布林弓手：差异 = 长弓背左
  └─ 哥布林萨满：差异 = 头骨杖
```

#### 5.4 剪影禁止

- ❌ 飘带 / 流苏 / 碎发 / 毛刺让轮廓"模糊"
- ❌ 装饰物超过剪影周长 20% 不收束
- ❌ 同章节怪物剪影 IoU > 0.6（看着像）
- ❌ 没有任何记忆点的"光头光体"角色

### 6. 形状对比（Shape Contrast）

剪影内部用形状对比表达角色属性：

| 内部形状语言 | 暗示属性 |
|------------|---------|
| 圆 / 椭圆为主 | 友善、温和、Q 萌（NPC、宠物） |
| 方 / 矩形为主 | 稳定、防御、力量（重甲、装甲 Boss） |
| 三角 / 尖锐为主 | 攻击性、危险、邪恶（暗影 Boss、刺客） |
| 圆+尖混合 | 复杂角色（玩家、复杂 NPC） |

**Boss 通常用对比形状**（如圆头身 + 三角武器）制造视觉张力。

---

### 7. Items / Icons / UI 的形状语言

#### 7.1 Items
- 主体用"侧立 / 45° 摆置"
- 武器：刀刃朝右上、握柄朝左下（统一画面方向感）
- 卷轴：横向展开 + 火漆居中
- 命痕：符印、水晶核心与能量轮廓为主

#### 7.2 Icons
- 圆形或圆角方形底框（圆角 12px @ 512）
- 主体居中，留 10% 透明边
- 单一主体（拒绝"剑+盾+光环"塞一个 Icon）

#### 7.3 UI 框
- 圆角 ≤ 20px @ 1024（避免过圆滑向 iOS Glass）
- 框上必须有克制的品牌记忆点（青色晶体角、柔金纹章或星尘节点）

## Examples

### 正确：身体原型选择
> 设计第 3 章冰系新精英怪
> 决策："属于 C · Tower Presence，原型 = Tall Sorcerer，因第 3 章主基调高耸寒冷，与第 1 章 B 家族形成跨章节差异。"
> 头身 2.7、外描边 9px、记忆点 = 长袍下摆 + 顶部冰晶头饰

### 错误：自创身体原型
> "我画了个 6 头身的写实冰巨人，比例更威猛"
> 违反 §1（不在 6 原型中）+ §2（超出头身范围）+ Pillar 7
> 必须返工

### 正确：剪影测试通过
> 新怪填黑缩 64px → 团队 3 人 1 秒识别"是地精斥候" → 通过
> 与同章节弓手剪影 IoU ≈ 0.5 → 通过

### 错误：剪影测试失败
> 新怪剪影像一个圆形球 → 没有记忆点 → 黑剪测试无人能识别 → 不通过

## AI Notes

- **AI 接到角色任务的第一件事**：先选 §1.2 二级身体原型 + §2 头身比，**不要**直接写视觉描述
- 决定身体原型后再决定剪影记忆点（§5.2），再决定内部形状对比（§6），最后才填色与材质
- 任何"独特身体比例"的请求 → 触发 §2 锁定，先与用户确认
- 描边在生成后必须用 §4.3 覆盖率检查；不通过 → Prompt 增加 "stronger thicker continuous dark charcoal outer outline" 重生成
