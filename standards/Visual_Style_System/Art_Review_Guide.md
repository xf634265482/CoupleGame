# Art_Review_Guide — 美术评分标准

## Purpose

为所有美术资产建立**可量化、可执行、可追溯**的评审体系。

任何 AI 生成的资源必须先按本系统自评。通用资产未达 80 分不得入库；玩家、Boss、核心按钮、关键交互物与 Gold Standard 未达 85 分不得入库。

> 本文件是 VSS 的"质保层"——把 Pillars / Baseline / 基础层 / 类目层全部翻译成一份评分卡。

---

### 2. 评分细则

#### A · Style Anchor（20 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| A1 符合当前 Baseline / 新锚图 | 8 | 新锚图批准前按文字规则；批准后做并排评审 |
| A2 风格 8 句话已写入 Prompt | 4 | 全 8 句无缺失 |
| A3 未触 §6 近邻风格 | 4 | 无写实 / 赛璐璐 / 矢量 / 美漫 / 像素 滑移 |
| A4 Style Family ID 标注 | 2 | manifest 含 `fate-tower-sky-fantasy-v2`；锚图批准前标 pending |
| A5 未引用外部艺术家名 | 2 | Prompt + 备注无"by xxx" / "style of xxx" |

#### B · Shape & Silhouette（15 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| B1 头身比在范围 | 3 | 见 Shape §2 |
| B2 选定二级身体原型 | 2 | 6 原型之一 |
| B3 大手大脚 + 不画细指 | 2 | 满足 Shape §3.2 |
| B4 剪影记忆点 ≥ 1（Boss ≥ 2） | 3 | 黑剪测试一秒识别 |
| B5 同章节家族差异 IoU ≤ 0.6 | 3 | 与同章节其它资产剪影对比 |
| B6 无 §5.4 剪影禁项 | 2 | 无飘带 / 毛刺让剪影模糊 |

#### C · Outline（10 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| C1 描边色 Deep Navy Charcoal `#17243A` 家族 | 3 | 取色器抽样确认 |
| C2 外描边粗细在 §4.1 范围 | 2 | 1024 源图量测 6~10 px |
| C3 内分隔线 50~70% 外描边 | 1 | 抽样 |
| C4 描边覆盖率 ≥ 42% | 3 | 用 §4.3 检测方法 |
| C5 无禁项（渐变 / 双线 / 彩色 / 局部消失） | 1 | 肉眼 + 边缘扫描 |

#### D · Color（15 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| D1 三色 60/30/10 | 3 | 主色明确 |
| D2 在章节调色板内 | 3 | 取色 → 比对 §4 子表 |
| D3 温度对偶（暖+冷点 / 冷+暖点） | 3 | 全冷 / 全暖 = -3 |
| D4 饱和度 ≤ 章节梯度 + 项目 80% | 3 | 取色 → HSV S |
| D5 未触禁色（霓虹 / 纯白 / 纯黑 / 粉紫主导） | 3 | 取色检测 |

#### E · Lighting（10 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| E1 主光方向左上 45° | 3 | 阴影位置一致 |
| E2 暖主光 + 右下冷反射 | 2 | 阴影偏冷 |
| E3 阴影分层 ≤ 3 + 软边 2~5 px | 2 | 边缘抽样 |
| E4 高光仅在金属 / 水晶 / 眼睛 | 2 | 抽样检查 |
| E5 章节 Rim 用法对（仅 T5+） | 1 | 普通怪不加 Rim |

#### F · Material（10 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| F1 材质来自 §2 表 | 3 | 无自创 |
| F2 单资产材质 ≤ 5 | 2 | 计数 |
| F3 相邻材质对比明显 | 2 | 不"三种金属并排" |
| F4 高危材质（M05/M10/M12/M13）按详解画 | 2 | 无镜面 / 真透明 / 现代特效 |
| F5 材质交界有内分隔 | 1 | M03~M13 强制 |

#### G · Hierarchy（5 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| G1 Tier 已明确并对应 §1 表 | 2 | 在评审单标注 T# |
| G2 视觉重量手段从 §2 工具表选 | 2 | 无自创发光 / 帧动画 |
| G3 与同框元素层级关系正确 | 1 | 玩家 vs Boss / 装饰 vs 交互 |

#### H · 100px Readability（10 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| H1 缩 64 px 可识别身份 | 4 | 3 人 / 3 AI 一秒识别 |
| H2 缩 96 px 可识别细类 | 3 | 同 |
| H3 缩 128 px 可识别具体角色 / 物品 | 2 | 同 |
| H4 装饰 < 8% 面积已剔除 | 1 | 抽样统计 |

#### I · Pillars Compliance（5 分）

| 子项 | 分值 | 通过线 |
|------|----|------|
| I1 通过 P1~P7 7 条 Pillar 自检 | 5 | 任意 1 条违反 = -5 |

章节背景额外检查：统一世界身份与章节内容身份必须同时成立。只换颜色、没有敌人/Boss/机制环境叙事的背景，A 与 G 维度不得满分；若完全无法辨认章节，视为风格锚定失败。

### 3. 总分等级与处置

| 分数 | 等级 | 处置 |
|------|------|------|
| 95~100 | S · Approved with Praise | 直接 integrated，可作为 `09_Examples/` 范例 |
| 85~94 | A · Approved | integrated |
| 80~84 | B · Approved with Notes | integrated + 在 manifest 记录扣分项以便后续优化 |
| 70~79 | C · Reject - Minor Rework | 退回，标注 1~3 个改进点重生成 |
| < 70 | D · Reject - Major Rework | 退回，从头来（重新 Prompt + 重生成） |

通用资产 < 80 不得入库；核心资产与 Gold Standard < 85 不得入库。

---

### 4. 单维度否决线（Hard Veto）

> 单项任何分数低于以下线 → 无论总分多少 → **自动判负，退回**。

| 维度 | 否决线 |
|------|------|
| A · Style Anchor | < 12（不像我们风格 = 必须退） |
| C · Outline | < 6（描边不达标 = 必须退） |
| D · Color | < 9（色彩错乱 = 必须退） |
| H · 100px Readability | < 5（手机上看不清 = 必须退） |
| I · Pillars | < 3（违反原则 = 必须退） |
| 真机阅读 | 玩家身份不清、文字吃力、交互物难找或危险预警不明确，任一直接否决 |

任何 Hard Veto 触发后**禁止"加分硬过"**。

---

### 5. 评审流程

```
[1] AI 自评：填评分卡 → 算总分 + 检查 Hard Veto
[2] 达到对应门槛且无 Veto：标 "AI-self-approved"，提交人类审稿
[3] 若 < 80 或有 Veto：列出扣分点，自行重生成
[4] 人类审稿：在 AI 自评基础上复评（可推翻 AI）
[5] 最终决定：人类 approve + 必要真机证据 → integrated
```

> AI **不允许跳过自评直接提交**。每次提交必须附带评分卡。

### 7. 常见扣分点（速查）

| 现象 | 扣分点 |
|------|------|
| 出图像 3D 塑料 | A3 -4 / F4 -2 / I -2 |
| 无描边 / 描边断裂 | C1~C5 全失 |
| 颜色全冷或全暖 | D3 -3 |
| 紫粉主导 | D5 -3 / Veto D |
| 主体糊在 96px | H1~H3 失 / Veto H |
| 角色与场景饱和度相同 | G3 -1 / Veto Hierarchy 风险 |
| 章节背景只换颜色、无内容关联 | A1 -3 / G3 -1 |
| 装饰元素 > 5 | B6 -2 / H4 -1 |
| Boss 视觉重量 < 玩家 | G2 -2 / Pillar 5 |
| 高光大面积白 | E4 -2 / F1 -2 |
| 真半透明水晶 | F4 -2 |
| 多眼诡异 Boss | I -5 / Veto |
| Prompt 写艺术家名 | A5 -2 / Pipeline 流程违规 |

### 8. AI 自评的 5 大陷阱

| 陷阱 | 反制 |
|------|------|
| "我觉得它挺好" → 主观满分 | 必须**逐项打分**，每项写**证据**（取色 / 量测 / 测试） |
| 跳过 H1~H3 缩放测试 | 缩放测试是 Hard Veto，**必须做** |
| 偏向自己生成的结果（model bias） | 让另一个 AI / 人类做 cross-check |
| 把 < 80 的资产硬提交 | 任何 < 80 自动退回，不允许"补漂亮"硬过 |
| 总分加错 / 漏算权重 | 必须用 §6 模板，**完整 9 维度** |

## Examples

### 正确：A 级评审通过
> 第 2 章 Boss 流沙巨蝎
> A 18 / B 14 / C 9 / D 14 / E 9 / F 9 / G 5 / H 9 / I 5 = **92 (A)**
> 无 Hard Veto
> 处置：integrated
> 评审人：Claude（AI 自评） + 人类二审

### 错误：硬要 80 分
> 资产 H1 = 3 / H2 = 2 / H3 = 1（H 只 6 分），其他维度堆到 75
> 总分 81 但 H < 5 触发 Hard Veto
> 处置：必须退回，不允许"总分够就过"

## AI Notes

- AI 每次评审**必须**用 §6 模板，不允许简化
- 评分必须有**证据**（取色截图 / 测量数值 / 测试结果），不允许"感觉"
- AI 不能给自己 90+ 不交叉检查；高分必须 cross-check
- 评分卡入库必须真实存在（manifest 中），便于回溯
