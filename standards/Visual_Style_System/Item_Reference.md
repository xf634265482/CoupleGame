# Item_Reference — 道具与拾取物视觉规范

## Purpose

定义武器 / 防具 / 卷轴 / 遗物 / 消耗品 / 关键道具的视觉规范。

道具 = "玩家想要的东西"，必须在画面里**显得值得拿**。

> 视觉细节继承 `Material_Library.md` + `Icon_Reference.md`；本文件给"道具专属"的取舍。

---

## Standards

### 1. 道具分类

| 类别 | 显示尺寸 | 来源 | 视觉关键 |
|------|---------|------|---------|
| Weapon 武器 | 106 px Icon | 战斗 / 商店 / 宝箱 / Boss | 标志性形状 + 主材质明显 |
| Armor 防具 | 106 px Icon | 同 | 同 |
| Scroll 卷轴 | 96 px Icon | 战斗 / 商店 / 事件 | 横向展开 + 火漆 + 符文 |
| Relic 遗物 | 106 px Icon | Boss / 章节末 / 命运树 | 古物感 + 哑金 / 水晶 |
| Consumable 消耗品 | 80 px Icon | 战斗 / 商店 | 药瓶 + 液体高光 |
| Key Item 关键道具 | 96 px Icon | 任务 / 解谜 | 钥匙 / 信物形 |

---

### 2. 道具 5 通则

| # | 通则 | 一句话 |
|---|------|-------|
| IT1 | 单一道具 | 一个 Icon 一件道具，无组合 |
| IT2 | 无角色无场景 | 不画手 / 角色 / 背景 |
| IT3 | 物体居中 + 标准角度 | 见 §3 |
| IT4 | 稀有度走底框 | 不污染物体本身色 |
| IT5 | 32 px 仍能识别大类 | 同 Icon §8 |

---

### 3. 道具标准摆置

| 类别 | 角度 / 姿态 |
|------|-----------|
| 单手剑 / 锤 | 45°，刀刃右上 / 握柄左下 |
| 双手剑 / 锤 | 45°，更竖直 |
| 短剑 / 匕首 | 45°，更扁 |
| 弓 | 略侧，弓弦清晰可见 |
| 法杖 | 略向右倾，顶端水晶在右上 |
| 防具（胸甲） | 正面对称 |
| 头盔 | 略侧 3/4 view |
| 盾 | 正面 + 微 3/4 |
| 卷轴 | 横向展开 20~30°，火漆居中 |
| 遗物 | 正侧立或正面 |
| 药水 | 正面 + 玻璃高光 |
| 钥匙 | 45°，齿朝右 |

> 标准角度是为了**让玩家在多个道具图标并排时一眼分类**。

---

### 4. 武器视觉细节

#### 4.1 武器组件分隔

每件武器必须能分辨 3 个组件：
- 刃 / 头（金属）
- 护手 / 套 (金属或皮革)
- 握柄（皮革或木）

组件之间用 §`Material_Library.md` §4.3 内分隔线区分。

#### 4.2 武器材质

- 刃 / 头：M05 哑光金属 或 M06 铭金（视稀有度）
- 护手：M06 铭金 或 M04 皮革
- 握柄：M04 皮革 或 M07 木

#### 4.3 武器装饰

- Common：素 / 无装饰
- Uncommon：1 个小铆钉 / 1 条线纹
- Rare：1 个小符文 / 1 个小宝石
- Epic+：1 个大符文 / 1 个大宝石 / 1 段魔法痕（用 M10 水晶）
- **永远** ≤ 3 个装饰元素，避免"堆"

---

### 5. 卷轴视觉细节

```
┌──────────────────┐
│      ╔══════╗     │
│ 卷边 ║ 符文 ║ 卷边│
│      ╚══════╝     │
│      [火漆]       │
└──────────────────┘
```

- 横向展开 20~30°
- 中央展示 1~2 个符文（"形状"不"字"）
- 火漆在底部中央，用元素色（火 = 火橙、冰 = 冰青等）
- 纸纹用 M03 布料画法略带

---

### 6. 遗物视觉细节

- 必须有"古物感"（裂痕 / 磨损 / 苔藓 / 残缺）
- 主材质金属或水晶
- 形状有"故事感"（圆 + 长 + 不规则）
- 描边 +5% 强调古物厚重

---

### 7. 消耗品（药水）视觉细节

- 圆瓶 / 三角瓶 / 锥瓶（3 种基本形）
- 液体颜色对应效果（HP 红 / MP 蓝 / Buff 绿 / 解毒紫）
- 瓶身轻微 M10 水晶画法（伪透明）
- 瓶塞用 M07 木

---

### 8. 关键道具

- 钥匙：齿形 + Muted Gold + Worn Wood 握柄
- 任务信物：圆牌 + 哑金 + 章节命运纹
- 必有"独特性"（与常见物不重）

---

### 9. 道具配色策略

#### 9.1 颜色与稀有度

| 项 | 规则 |
|----|----|
| 物体主色 | 由材质决定（哑光银 / 哑光金 / 木褐 ...） |
| 稀有度色 | 仅在底框 + 1 px 外发光 |
| **不允许** | 物体色彩跟稀有度变（同一把剑不同稀有度看起来不同物体） |

#### 9.2 章节归属（仅限章节限定道具）

- 章节限定道具（如 Boss 掉落）允许加章节强调色 ≤ 8% 点缀
- 普通道具保持中性世界色

---

### 10. 道具 Icon 与 World 表现一致性

> 一件道具有两套表现：**Icon**（背包 / 商店） 和 **World**（地图上的拾取物）。

| 项 | Icon | World |
|----|------|------|
| 角度 | §3 标准角度 | 45° 缓飘 + 微微旋转 |
| 大小 | 80~106 px | 1 格的 60~80% |
| 描边 | 4~6 px @ 512 | 同 |
| 底框 | 圆角方框 | 无（直接在 Tile 上） |
| 高光 | 1~2 个 | + 微微脉冲发光（让拾取物"召唤"玩家） |

两套表现必须**形状 / 色 / 材质完全一致**（玩家在地图上看到的钥匙 = 背包里的钥匙）。

---

### 11. 道具禁止表

| 禁项 | 为什么 |
|------|-------|
| ❌ Icon 里画手 / 角色 / 场景 | 违反 IT2 |
| ❌ 物体多于 1 件 | 违反 IT1 |
| ❌ 物体颜色因稀有度变 | 违反 §9.1 |
| ❌ Icon 上写字 / 数字 / 价格 | 违反 Icon §10 |
| ❌ 现代武器（步枪 / 手枪 / 机械） | 违反 Pillar 5 |
| ❌ 多变体一图（"史诗剑 3 种颜色"放一起） | 违反 IT1 |
| ❌ 装饰元素 > 3 个 | 违反 §4.3 / §5 / §6 |

## Examples

### 正确：Epic 法杖 Icon
> 类型：Weapon - Staff
> 摆置：略向右倾，顶端水晶在右上
> 组件：水晶头（M10）/ 铜环（M06）/ 长杖木（M07 + M04 皮缠握柄）
> 装饰：杖身 1 条苔绿符文（章节呼应）
> 稀有度：Epic → 底框 Debuff 紫边 1 px + 暗光
> 描边：Charcoal 5 px @ 512
> 32 px 测试：仍能识别"是一根法杖"✓

### 错误：稀有度污染物体色
> Common 长剑画成灰色 / Epic 长剑画成紫色
> → 违反 §9.1（同一把剑因稀有度变色，玩家会以为不同物体）
> 修正：物体本身颜色不变，稀有度走底框
