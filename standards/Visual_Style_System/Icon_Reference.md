# Icon_Reference — Icon 视觉规范

## Purpose

定义所有 Icon 在 32~128 px 尺寸下的视觉规范，让"一秒读懂这是什么"成为可能。

Icon 是项目里**最频繁出现**的视觉元素之一，也是**最容易被画废**的元素 —— 因为 AI 模型默认"画出复杂细节"，而 Icon 要的是"极简又有标志性"。

---

## Standards

### 1. Icon 分类

| 类型 | 显示尺寸 | 源资源尺寸 | 用途 |
|------|---------|---------|------|
| HUD Status | 32~48 px | 256 px | Buff / Debuff |
| HUD Action | 48~64 px | 256 px | 行动按钮 / 通用 |
| Item Slot | 80~106 px | 512 px | 道具 / 装备格 |
| Skill Slot | 80~96 px | 512 px | 技能格 |
| Chapter Entry | 96~128 px | 512 px | 章节入口 |
| Floating Number | 32 px | 128 px | 金币 / 经验 飘字 |

---

### 2. Icon 4 通则

| # | 通则 | 一句话 |
|---|------|-------|
| I1 | 单一主体 | 每个 Icon 只画一件事 |
| I2 | 32px 仍可识别 | 缩到 32 px 仍能正确回答"这是什么" |
| I3 | 强外描边 | Charcoal 4~6 px @ 512 |
| I4 | 留 10% 边 | 主体不顶到画面边缘 |

---

### 3. Icon 视觉结构

```
┌─────────────────────┐
│  10% 透明边          │
│  ┌───────────────┐  │
│  │  外描边（4~6px）│  │
│  │  ┌─────────┐  │  │
│  │  │  主体    │  │  │
│  │  │  (居中)  │  │  │
│  │  └─────────┘  │  │
│  └───────────────┘  │
└─────────────────────┘
```

- 底框：圆角方形（圆角 12 px @ 512）
- 底色：Panel Dark `#1B1F26` 半透 70%
- 描边：Deep Navy Charcoal `#17243A` 4~6 px @ 512
- 主体：居中，30~70% 面积
- 高稀有度可加 1 px 外发光（在底框外）

---

### 4. Icon 主体设计原则

#### 4.1 主体角度

| 类型 | 角度 |
|------|-----|
| 武器 | 45° 摆置，刀刃右上 / 握柄左下 |
| 卷轴 | 横向略展开 + 火漆居中 |
| 命痕 | 正面符印或核心轮廓 |
| 药水 | 正面 + 玻璃高光（用 M10 水晶画法） |
| 钥匙 | 45° |
| 状态 / Buff | 抽象符号 + 元素色 |

#### 4.2 主体面积

- 30~70% 画面（小于 30% 看不见，大于 70% 顶边）
- 重要识别元素必须 ≥ 主体的 40%

#### 4.3 主体细节

- 简化到"能识别身份"的最低细节
- 32 px 下能区分"剑 vs 锤" / "卷轴 vs 钥匙" / "燃烧 vs 中毒"
- 装饰花纹 / 文字符号一律省略

---

### 5. Icon 配色规则

#### 5.1 主体配色

- 主色 1 + 辅色 1 + 高光 1（**最多 3 色**）
- 主色按所属系统：
  - 物品：稀有度色（底框） + 物品本体材质色
  - 技能：元素色为主
  - 状态：状态色（HP 红 / Buff 绿 / Debuff 紫 / 冷热色）

#### 5.2 底框配色

| 稀有度 | 底框 |
|--------|-----|
| Common | Panel Dark + Common 灰边 1 px |
| Uncommon | Panel Dark + Buff 绿边 1 px |
| Rare | Panel Dark + 蓝青边 1 px |
| Epic | Panel Dark + Debuff 紫边 1 px |
| Legendary | Panel Dark + Amber 边 1 px + 暖光 |
| Mythic | Panel Dark + 危险红边 1 px + 强光 |

> 稀有度色只在**底框**表达，不污染物体本身色彩。

---

### 6. Icon 光照

- 主体：左上 45° 主光（同 Lighting §2）
- 高光：仅在金属 / 水晶上，1~2 个小点
- 阴影：底部 1~2 px 内分隔，软边

---

### 7. Icon 命名

| 类型 | 模式 |
|------|------|
| HUD | `icon_hud_<name>.png` |

| Status | `icon_status_<name>.png` |
| Chapter | `icon_chapter_<n>.png` |

---

### 8. 32px 自检（最重要）

> 任何 Icon 必须通过这步测试，否则返工。

| 测试步骤 | 通过线 |
|---------|--------|
| 缩到 32 px | 主体仍能区分大类（剑 vs 杖 vs 卷轴 vs 药水） |
| 缩到 48 px | 能区分细类（短剑 vs 长剑） |
| 缩到 64 px | 能区分稀有度（底框色可分辨） |
| 缩到 96 px | 能识别具体物品（"哑金长剑"） |

不通过的修复手段：
- 简化装饰
- 加大主体记忆点
- 拉开主体与底框对比度
- **不**通过加描边粗细补救（影响 §3）

---

### 9. 状态 Icon（Buff / Debuff）专属

- 用**符号**表达而非"图"（不画"燃烧的角色"，画"火焰符号"）
- 元素色饱满（但仍 ≤ S 80%）
- 圆形或圆角小，32 px 即可

| 状态 | 符号 |
|------|-----|
| 燃烧 | 火苗 |
| 冰冻 | 雪花 |
| 麻痹 | 闪电 |
| 中毒 | 滴形 |
| 护盾 | 圆盾 |
| 暴怒 | 怒拳 / 火 |
| 治疗 | 十字 / 心 |
| 减速 | 时钟 / 龟形 |

---

### 10. Icon 禁止表

| 禁项 | 为什么 |
|------|-------|
| ❌ 多主体（剑+盾+光环）塞一个 Icon | 违反 I1 |
| ❌ 32 px 下看不清是什么 | 违反 I2 |
| ❌ 无描边 / 描边 < 4 px @ 512 | 违反 I3 |
| ❌ 主体顶到边缘 | 违反 I4 |
| ❌ 渐变背景 / 霓虹光晕 | 违反 UI §10 |
| ❌ 塑料 3D 透视 | 违反 Pillar 4 |
| ❌ 真实文字 / 数字 / 字母 | 由代码运行时填 |
| ❌ 不同 Icon 主体角度 / 大小 不一致 | 视觉系统破裂 |

## Examples

### 正确：Rare 钥匙 Icon
> 底框：Panel Dark + 蓝青稀有边 1 px + 圆角 12 px
> 主体：45° 摆置铜钥匙，主色 Muted Gold + 辅色 Worn Wood 握柄 + 高光 1 个小点
> 描边：Charcoal 5 px
> 32 px 自检：钥匙形仍能识别 ✓
> 通过

### 错误：复杂物品 Icon
> 一个 Icon 画了：长剑 + 盾 + 头盔 + 光环 + 背景火光
> 违反 I1 + I2（32 px 糊成一坨）
> 修正：只画长剑

---

## AI Notes

- Icon Prompt 必须明确 "single centered subject, no decorative background, no multiple items"
- 不要让模型"自由发挥添加细节" — Icon 要的是减法
- §8 32px 测试必做，**最重要**
- 状态 Icon 用符号不用人物（§9）
