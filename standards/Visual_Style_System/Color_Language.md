# Color_Language — 色彩语言

## Purpose

定义《命运之塔》全项目的色彩使用规则：**用什么色、怎么组色、怎么避免色彩失控**。

色彩是命运之塔最高频被违反的规范之一。AI 模型默认偏好"鲜艳 / 高饱和 / 紫粉 / 渐变 / 霓虹"，而本项目要的是"暖中带克制冷魔法、低中饱和、永远有描边压住色块"。

本文件比 `standards/03_Art/Color_System.md` 更深一层：那份讲"调色板表"，这份讲**色彩判断方法**。

---

## Standards

### 1. 色彩 5 原则（Color Principles）

| # | 原则 | 一句话 |
|---|------|-------|
| C1 | 三色法 | 每个角色 = 主 60% + 辅 30% + 点缀 10% |
| C2 | 温度对偶 | 暖主调 + 受控冷点缀（魔法），冷主调 + 暖反光（火光） |
| C3 | 饱和度封顶 | 项目最大饱和度 = HSV S ≤ 80%（拒绝霓虹） |
| C4 | 章节归属 | 任何角色色都必须能定位到 § 4 章节调色板的一个子表 |
| C5 | 描边永远收 | 不存在"无描边色块"；描边把任何色压回我们的世界 |

> 任何色彩争议先回 C1~C5 判断。

---

### 2. 色彩空间与表示

- 全部用 **HEX**（如 `#5C7A4B`）作为权威表示；HSL / HSV 仅在推理时使用
- 不允许使用线性色或浮点色（仅限渲染管线内部）
- 同一资产内不允许出现 ≥ 5 种"主要色块"（除装饰大场景）

### 3. 基础色板（World Base Palette）

> 同步自 `standards/03_Art/Color_System.md` §2，本节给出**为什么这些色被选**的解释。

| 名 | HEX | 角色 | 为什么这个色 |
|----|-----|------|-----------|
| Sky Blue | `#4F8FE0` | 跨页面天空基底 | 明亮、通透的世界识别 |
| Ivory Light | `#EDE3CC` | 云层、浅色遗迹、明亮底色 | 避免纯白过曝 |
| Warm Sandstone | `#D7A85B` | 暖砂岩、遗迹平台 | 明亮而有物质感 |
| Soft Gold | `#D6AE55` | 金属铭饰、奖励、品牌边饰 | 柔和金，避免廉价金光感 |
| Cyan Magic | `#5FB8C8` | 蓝青魔法、玩家主色 | 唯一允许的"冷点缀"，全项目魔法语言 |
| Amber Glow | `#E6A553` | 火光、奖励暖光 | 暖反光，与 Cyan Magic 形成温度对偶 |

**为什么不用纯黑 / 纯白 / 高饱和原色**：
- 纯黑 `#000` 在暗背景上消失
- 纯白 `#FFF` 让油画感掉成赛璐璐
- 高饱和原色破坏"轻奇幻童话史诗"温度（违反 Pillar 5）

### 8. 色彩和声法（Color Harmony）

#### 8.1 三色法（主辅点缀 · 60/30/10）

每个角色 / 物品 / UI 元素都遵循：

```
主色 ≈ 60% 面积   → 定义身份（如玩家"蓝青"）
辅色 ≈ 30% 面积   → 服装次色 / 皮肤 / 金属件
点缀 ≈ 10% 面积   → 眼睛 / 符文 / 关键装饰
```

> 比例不必精确，但**严禁出现"四等分四色"或"五彩斑斓"**。

#### 8.2 温度对偶（Warm + Cool Counterpoint）

> 命运之塔的色彩签名 = **暖主调 + 受控冷魔法**。

- 暖主调（角色 / 物品 / 友善场景）：必须包含 ≤ 10% 的冷色点缀（Cyan Magic / 月光）
- 冷主调（魔法 / 第 3 章场景）：必须包含 ≤ 10% 的暖色反光（火光 / Amber Glow）
- 第 4 章以深色岩灰承载明亮火橙；岩层不得吞没熔岩警告，火橙也不得铺满画面
- **不允许"全冷"或"全暖"画面**

#### 8.3 章节饱和度梯度

| 章节 | 平均饱和度（HSV S 上限） |
|------|---------------------|
| 第 1 章 | 65% |
| 第 2 章 | 70%（日照沙海明亮，但沙暴与地面避免刺眼） |
| 第 3 章 | 60% |
| 第 4 章 | 75%（熔岩危险色允许更鲜，环境主体仍需受控） |
| 第 5 章 | 70% |

> 项目全局封顶 S ≤ **80%**。任何超过此值的色 = 触发"霓虹"红线。

### 9. 阴影色规则

> 与 `Lighting_Guide.md` §4 协同。

- 阴影色 = 主色降低 25~35% 明度 + **略微偏冷**（除非主色已冷，则偏中性）
- 接触阴影（脚下、手与身体交界）可压至 -50% 明度
- **不**用纯黑 / Charcoal 做阴影色
- 阴影边缘软（2~5px 渐变），不做硬切

```
示例：玩家蓝青皮肤主色 #C0D8E0
  → 阴影色 #7A98A8（明度 -30% + 略偏冷蓝）
  → 接触阴影 #4A6878
```

### 10. 调色禁止表（Forbidden Colors）

| 禁色 | 为什么禁 |
|------|---------|
| `#FF00FF` 霓虹紫 | S=100, V=100 → 破坏 Pillar 5 |
| `#00FF00` 霓虹绿 | 同上 |
| `#FFFFFF` 纯白 | 破坏 Pillar 4 半厚涂 |
| `#000000` 纯黑 | 描边在暗背景隐形 |
| 任何 S > 80% | 滑向霓虹（违反 §8.3） |
| 紫粉主导（同时 H ∈ 280~340, S > 50%） | 违反 Pillar 5 |
| 高饱和粉橙 | 廉价手游色 |

### 11. AI 模型偏差校正（Model Drift Correction）

> 实战经验：图像模型倾向于以下偏移，AI 必须主动反制。

| 模型偏移 | 反制 Prompt 关键词 |
|---------|----------------|
| 偏向霓虹紫主调 | `controlled cyan-blue accent only, no purple dominance` |
| 偏向高饱和粉色 | `low saturation muted palette` |
| 偏向纯白高光 | `restrained highlights, no shiny plastic specular` |
| 偏向阴影硬切赛璐璐 | `soft painterly shadow, no hard cel shadow` |
| 偏向白色描边 / 无描边 | `strong continuous dark charcoal outer outline` |

> 这些反制词应写入 `Prompt_Style_Template.md` 的标准段。

## Examples

### 正确：用 C1 + C2 设计第 2 章 Boss 色
> **目标**：第 2 章流沙巨蝎
> **应用**：
> - C1 三色：**主** = 暖金沙 `#E6A553` (60%) + **辅** = 象牙浅石 `#EDE3CC` (30%) + **点缀** = 青色晶体 `#5FB8C8` (10%)
> - C2 温度：暖主调 + 受控冷色晶体反光
> - §8.3 第 2 章饱和度 ≤ 70% ✓
> - §10 没碰禁色 ✓

### 错误：忽略 C2 导致全冷
> 设计第 3 章 Boss：主蓝、辅银白、点缀冰青 → 全冷画面，违反 §8.2
> 修正：加 5~10% 暖琥珀于角色护符 / 眼睛

### 错误：自创"个性色"
> "我觉得这只 Elite 用霓虹紫眼睛会很酷"
> 违反 §10 紫粉主导（点缀也不允许霓虹 S>80%）
> 修正：改用 Cyan Magic 或 Amber Glow 眼睛

## AI Notes

- AI 写 Prompt 前先决定"这是第几章"→ 锁定 §4 子表 → 再决定三色（§8.1）
- 不允许在 Prompt 里用模糊词（"colorful / vibrant / mystical"）；必须用 HEX 或本文件命名色
- 任何"破例用紫粉"请求 → 触发 §10 + Pillar 5；蓝紫与玫瑰灰只可按章节规则用于暮色、迷雾、沙暴或命运效果，不得默认成为主色
- 每次生成完，用 §11 偏差校正自检（截图肉眼看是否偏霓虹 / 高饱和）
