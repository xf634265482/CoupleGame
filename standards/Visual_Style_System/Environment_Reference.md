# Environment_Reference — 场景视觉规范

## Purpose

定义地图 / Tile / 背景 / 装饰物的视觉规范，让"角色站在场景里"是同一个世界。

场景是**最该安静**的画面元素：它的任务是托住角色，**不抢戏**。

---

## Standards

### 1. 场景视觉定位

| 是 | 不是 |
|----|-----|
| 明亮天空塔庭与章节幻想环境 | 写实环境贴图 |
| 略俯视 3/4 view（与角色一致） | 一人称 / 平视 |
| 半厚涂软斜面 | HDR 高反 / Photo |
| 轻雾 + 萤光粒子 | 厚烟 / 真实粒子流 |
| 暖光主调 + 弱冷反射 | 全冷绝望调 |
| 比角色饱和度低 30% | 与角色等亮 |

---

### 2. 场景 4 通则

| # | 通则 | 一句话 |
|---|------|-------|
| EV1 | 场景安静 | 比角色暗、低饱和、无内描边，让角色 / 实体跳出来 |
| EV2 | 同角色光源 | 主光左上 45°，与角色一致 |
| EV3 | Tile 无内描边 | Tile 平铺无描边，描边交给实体 |
| EV4 | 章节呼应 | 主色按 `Color_Language.md` §4 章节调色板 |

---

### 3. 场景 3 层结构

```
[远景] Sky / Backdrop      — 最弱、最模糊、最低饱和
[中景] Tile / Ground        — 主操作平面，无内描边
[前景装饰] Decoration       — 残柱 / 火把 / 藤蔓，描边 60%
```

| 层 | 饱和度（vs 角色基准） | 描边 |
|----|------------------|------|
| 远景 | -50% + 模糊 | 无 |
| 中景 Tile | -40% | 无内描边 |
| 前景装饰 | -30% | 60% 描边 |

---

### 4. 连续棋盘规范

#### 4.1 结构

- 使用一整块连续半透明战场平面。
- 普通格线由代码绘制，低对比但清楚。
- 不使用逐格完整实心地砖和重复高对比纹理。
- 与实体的区分依靠实体强轮廓、局部对比和状态覆盖层。

**代码实现规范（FogMapView）：**
- 战场平面 = `_floorPlane` 单 Sprite 节点，加载 `pve/map/tile_floor_ch{N}`，opacity ≈ 120（约 47%，真正"半透明"）。
- 基底暗面 = `_boardOverlay` Graphics 节点用 `g.fill()` 绘制 `Color(15,10,5,70)`（α≈27%）的暗暖基底，然后叠加格线。基底作用：中和背景色溢出。GS-BG-CH1 正式集成且背景色温与地面纹理一致后，可将基底 α 调低至 30~40 甚至去除。
- 层级顺序：`_background`（场景层）< `_floorPlane` < `_boardOverlay`（暗基底+格线）< 格子高亮 < 迷雾 < 单位。
- 章节切换时调用 `_refreshFloorPlane(chapter)` 更换 spriteFrame，无需重建节点。
- **必须**在设置 spriteFrame 前先设 `sp.sizeMode = Sprite.SizeMode.CUSTOM`，否则 Cocos auto-trim 会把 alpha 渐变边缘裁剪掉，导致纹理面积小于战场，部分已探索格无地面纹理。
- 逐格 `FloorArt` 节点（每个 cell 的子节点）保留用于**单格状态覆盖效果**（灼烧 / 冰冻 / 命运格等），日常保持 `active = false`。

#### 4.3 章节 Tile 库

| 章节 | 连续平台主色 | 装饰元素 |
|------|---------|---------|
| 第 1 章 | 暖砂岩 + 柔和草绿 | 低细节平台 + 青色命运痕迹 |
| 第 2 章 | 暖金沙 + 象牙白 | 风化砂纹 + 绿洲植被 + 青色晶体 |
| 第 3 章 | 冷蓝 + 银白 | 霜冻 + 冰晶散斑 |
| 第 4 章 | 深蓝岩灰 + 焦褐 | 熔岩缝 + 火橙弱光 |
| 第 5 章 | 米白 + 哑金 | 大理石纹 + 命运紫淡纹 |

#### 4.4 雾 Tile

- 与未探索区相同色调 + 60~80% 透明
- 大块毛笔触（避免硬边）
- **不**用实色块平铺

---

### 5. 背景规范

- 模糊化（高斯 8~16 px）
- 饱和度 -30~50%
- 颜色与所在章节调色板一致
- **不**画清晰人物 / 怪物 / 建筑

---

### 6. 装饰物（Decoration）

#### 6.1 装饰物上限

- 单个 Tile 最多 1 个装饰物
- 同屏装饰物 ≤ 5~7 件

#### 6.2 装饰物列表

| 章节 | 装饰物 |
|------|-------|
| 第 1 章 | 残柱 / 藤蔓 / 火把 / 苔斑 / 小石堆 |
| 第 2 章 | 风化石柱 / 浅色遗迹 / 绿洲植被 / 沙丘 / 青色晶体 |
| 第 3 章 | 冰柱 / 冰晶 / 雪堆 / 凝结的灯 |
| 第 4 章 | 火山岩柱 / 熔岩裂隙 / 火盆 / 焦木 |
| 第 5 章 | 命运碑 / 哑金支柱 / 米白基座 |

#### 6.3 装饰物视觉

- 描边 60%（比角色弱，比 Tile 强）
- 不放在格子中心（让位给实体）
- 偏向格子角 / 边

---

### 7. 实体（Map Entity）

> 玩家 / 怪物 / 宝箱 / 楼梯 / 钥匙等可交互或重要元素。

- 走 `Character_Reference.md` / `Item_Reference.md` 规范
- 必须有 100% 强外描边
- 与 Tile 描边对比形成"能交互 vs 装饰"的视觉提示
- 位于格子中心

---

### 8. 章节场景调度

#### 8.0 内容关联

章节场景不是单纯换调色板。每章必须包含可读的环境叙事，使背景关联本章怪物、Boss、机制与探索内容，同时保留统一天空塔庭世界身份。

- 第 1 章：哥布林前哨、粗制木构、号角与补给痕迹。
- 第 2 章：沙漠劫掠、流沙、沙暴防护与巨蝎领地痕迹。
- 第 3 章：冻结设施、破碎冰障、巨人活动与寒气侵蚀。
- 第 4 章：火山工事、熔岩潮汐痕迹、锁链和熔火领地。
- 第 5 章：命运审判、预言纹、镜像结构与终塔仪式感。

叙事元素集中在棋盘外缘与远景，中央安全区保持低细节。背景中不得直接烘焙具体怪物、角色、交互物、格线或预警。

#### 8.1 主光（不变）

所有章节主光仍是左上 45° 暖光（详见 `Lighting_Guide.md` §2）。
不允许章节切换改主光方向。

#### 8.2 章节大气

| 章节 | 大气 |
|------|-----|
| 第 1 章 | 轻雾 + 弱蓝青魔法尘 |
| 第 2 章 | 淡紫灰热雾 + 沙尘浮粒 |
| 第 3 章 | 冷雾 + 雪粒 |
| 第 4 章 | 紫灰热浪 + 火星浮粒 |
| 第 5 章 | 神性光斑 + 哑金浮粒 |

#### 8.3 章节远景

- 第 1 章：苔藓塔轮廓
- 第 2 章：日照沙丘、象牙遗迹与远方绿洲剪影
- 第 3 章：冰封山脉剪影
- 第 4 章：熔岩裂谷与火山岩柱剪影
- 第 5 章：金光塔顶

> 远景必须**模糊 + 低饱和**，不抢戏。

---

### 9. Tile 不允许

| 禁项 | 为什么 |
|------|-------|
| ❌ Tile 加内描边 | 违反 EV3，与实体视觉权重一致 |
| ❌ Tile 上写文字 / 路标 | 违反 Pillar 5 |
| ❌ Tile 接缝有硬边 | 平铺破裂 |
| ❌ 连续平台主色 = 实体主色 | 实体在背景里"消失" |
| ❌ HDR / Photo 风 | 违反 Pillar 4 |
| ❌ 单 Tile 装饰 > 1 个 | 违反 §6.1 |

## Examples

### 正确：第 1 章地面
> 连续平台：暖砂岩 + 柔和草绿 + 弱蓝青命运痕迹
> 代码格线低对比
> 大气：云暮轻雾 + 蓝青魔法尘
> 远景：浮岛塔庭与桃金夕照
> 装饰物：每 4~5 格 1 个残柱 / 藤蔓
> 玩家 + 宝箱 + 怪物 站在上面，外描边让它们一秒跳出 ✓

### 错误：背景太抢戏
> 背景画了清晰的远山 + 龙形剪影 + 高饱和云
> 违反 §5 + §3 远景应弱
> 修正：模糊 16 px + 饱和度 -50%

## AI Notes

- Tile / 背景 / 装饰的 Prompt 必须包含 "muted saturation, soft soft painted ambient, no internal outline, do not steal attention from foreground entities"
- 不要让模型自由发挥背景细节 — 背景越简单越好
- 装饰物用 `art_pipeline/prompts/map_entity.json` 模板
- §7 实体不归本文件，跳到 Character / Item Reference
