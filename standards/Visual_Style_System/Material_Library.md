# Material_Library — 材质语言

## Purpose

定义《命运之塔》全部"表面材质"的统一画法。

材质是 AI 模型最容易"自由发挥"的地方。同一种"金属"，模型可以画成锈铁、镀铬、塑料镜面 —— 而本项目要的是**哑光铭金**。本文件锁定每一种材质的**形状、色彩、光照、高光位置、内描边规则**。

> 与 `standards/03_Art/Material_Library.md` 互补：那份是 03_Art 模块的"应用速查"；本文件是 VSS 的"画法手册"。冲突以本文件为准。

## Standards

### 1. 材质 4 通则

| # | 通则 | 一句话 |
|---|------|-------|
| MA1 | 半厚涂铺底 | 任何材质都先用半厚涂铺底，**再**附加材质特征 |
| MA2 | 描边永远 | 任何材质都保留 Charcoal 外描边 |
| MA3 | 高光克制 | 详见 `Lighting_Guide.md` §5；金属 / 水晶 / 眼睛之外**无高光** |
| MA4 | 阴影偏冷 | 暖材质阴影偏冷；冷材质阴影偏中性 |

### 3. 材质详解（最易翻车的 4 种）

#### 3.1 M05 哑光金属（Matte Metal） — **最常被画成镜面**

**正确画法**：
- 主色铺底（哑光，**无反射**）
- 阴影偏冷蓝 -40% 明度
- 高光：1~2 个 **小点**（≤ 2% 面积），偏暖白 `#FFF5DC`，**绝不**长条扫光
- 边缘略亮 1 px（暗示金属面边缘反光）
- 描边 Charcoal

**错误画法**：
- ❌ 镜面反光（octane render / chrome）
- ❌ 长条形扫光 > 5% 面积
- ❌ 纯白高光
- ❌ 渐变金属感

**Prompt 关键词**：`matte metal, restrained highlights, no shiny chrome, no mirror reflection`

#### 3.2 M10 水晶 / 魔法 — **最常被画成玻璃球**

**正确画法**：
- 主色铺底 Cyan Magic
- 内部叠 2~3 层不同明度（深 → 中 → 浅）表达**伪透明感**
- 1~2 个偏冷高光（`#E8F6FF`）
- 内部隐约可见 1~2 条更亮的"光脉"
- 内描边用**亮内描边**（如 `#7AD8E8`），区别于外 Charcoal
- **不**真的画"透明背景透过水晶"

**错误画法**：
- ❌ 真半透明（让背景透过）
- ❌ 玻璃球反射高光（弧形扫光）
- ❌ 内部空心透视

**Prompt 关键词**：`painted crystal with inner glow layers, no real transparency, no glass refraction`

#### 3.3 M12 火 / M13 冰 — **最常被画成现代特效**

**火正确画法**：
- 中心亮黄白 `#FFE680` → 中层火橙 `#E0581E` → 外层暗红 `#7A2F1F`
- 笔触卷曲、向上、有"舌状"分叉
- 元素色软描边（不必 Charcoal），可暖深红 `#5A2B1F`

**冰正确画法**：
- 中心透感冰青 → 外层银白
- 棱角分明（不画圆球冰）
- 高光在棱角顶点
- Charcoal 描边

**错误画法**：
- ❌ 真实粒子流（违反 Pillar 4）
- ❌ 现代 VFX 的色散虹光
- ❌ 完全圆滑的冰球

### 4. 材质组合规则

#### 4.1 同资产材质上限

- 单一角色 / 道具 ≤ **5 种**主要材质
- 超出 → 简化（合并相近材质 / 减装备件）

#### 4.2 材质对比

为加强可读性，相邻材质应**对比明显**：

| 推荐对比 | 例 |
|---------|----|
| 皮肤 + 金属 | 角色头部 + 头盔 |
| 布料 + 皮革 | 上衣 + 腰带 |
| 木 + 金属 | 武器握柄 + 刀刃 |
| 石 + 苔藓 | 场景墙面 |
| 水晶 + 金属 | 法杖顶部 |

**禁止**：3 种"看起来都是金属"的材质并排（如哑光金 + 铭金 + 暗金属灰），玩家无法分辨。

#### 4.3 材质过渡

- 材质交界处加内分隔线（M03/M04/M05/M06/M10/M13 强制）
- 内分隔线粗细 = 外描边的 50~70%

### 5. 章节扩展材质

> 每章可有 1~2 个章节限定材质，但**必须继承 §1 通则**。

| 章节 | 限定材质 | 关键画法 |
|------|---------|---------|
| 第 1 章 | 苔藓石（M08+M09 复合） | 灰岩主体 + Moss Green 散斑 |
| 第 2 章 | 暖金沙 + 象牙砂岩（M08 变体） | 明亮砂粒大块铺色 + 风化浅石 + 少量青色晶体 |
| 第 3 章 | 霜冻金属（M05+M13） | 哑光银 + 棱角冰附着 |
| 第 4 章 | 焦黑岩 + 熔岩缝（M08+M12） | 深蓝岩灰主 + 内部火橙缝光 |
| 第 5 章 | 命运大理石（M08 变体） | 米白主 + 哑金命运纹 |

新章节材质需先加入本表才能使用。

### 6. 材质不允许（Forbidden）

| 禁项 | 为什么 |
|------|-------|
| ❌ 真实写实皮肤毛孔 | 违反 Pillar 4 半厚涂 |
| ❌ 镜面金属反射 | 违反 MA3 + Pillar 4 |
| ❌ 真半透明玻璃 | 违反 Pillar 4 |
| ❌ HDR 金属反光 | 违反 Lighting §8 |
| ❌ 现代织物 / 牛仔 / 涤纶 | 违反 Pillar 5 调性 |
| ❌ 塑料 / 等离子 / 霓虹材质 | 违反 Pillar 2 + 4 + 5 |

---

### 7. AI 模型偏差校正

| 模型偏移 | 反制 Prompt 关键词 |
|---------|----------------|
| 金属画成镜面 | `matte metal, no chrome, no mirror, no specular highlight reflection` |
| 水晶画成真玻璃 | `painted crystal with inner color layers, no real transparency, no glass refraction` |
| 高光过强 | `restrained highlights, soft beveled surfaces` |
| 添加现代材质（塑料 / 涤纶） | `traditional fantasy materials only: stone, wood, brass, leather, cloth, crystal` |
| 漏画描边 | `strong continuous dark charcoal outer outline on every material edge` |

## Examples

### 正确：玩家剑刃材质
> 哑光金属（M05）：
> - 主色冷灰 `#A8B2BA`
> - 阴影 -40% 偏冷
> - 高光：刃尖 1 个小点 + 中部 1 个小点
> - 边缘略亮 1 px
> - 内描边将刃 / 护手 / 握柄分隔
> - 整体 Charcoal 外描边
> - 评价：哑光金属语言 ✓

### 错误：把法杖水晶画成玻璃球
> 模型生成时给了"水晶球反射 + 透明背景透过"
> 违反 §3.2 + Pillar 4
> 修正：Prompt 加 `painted crystal with inner glow layers, no real transparency`，重生成

### 错误：5 种以上材质堆叠
> 一只 Boss：胸甲哑光金 + 护肩铭金 + 武器铭金 + 裙甲哑光银 + 头盔铭金 + 靴皮革 + 披风布
> → 6 种材质 + 3 种相似金属，违反 §4.1 + §4.2
> 修正：合并金属为 2 种（哑光 + 铭金各一），减装备件

## AI Notes

- **AI 起 Prompt 时，必须列出所有材质 ID**（如 "primary: M05; secondary: M06, M04, M10"），便于评审追溯
- 不允许在 Prompt 用模糊词（"metallic / shiny / glowing"）；必须用本表名 + §3 详解关键词
- 出图后用 §7 偏差校正肉眼自检
- 新材质（§5 章节扩展）需先在本表登记再用
