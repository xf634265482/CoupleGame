# Animation_Guide — 动作规范

## Purpose

定义《命运之塔》的动作语言。本项目以**静帧 + 程序化动效**为主，不做帧动画 / 骨骼动画。

## Standards

### 1. 动作类型

| 类型 | 实现方式 | 时长 |
|------|---------|------|
| 待机 Idle | tween 微浮动（Y ±4 px, 0.8s 循环） | 持续 |
| 走格 Move | 直线 tween + 落脚回弹 | 0.20s |
| 攻击 Attack | 前压 + 后甩 + 屏震 | 0.30s |
| 受击 Hit | 红闪 + 横震（±6 px, 2 次） | 0.20s |
| 死亡 Death | 缩放 1→0 + 透明 + 旋转 ±15° | 0.35s |
| 入场 Spawn | 透明 0→1 + scale 0.6→1.0 | 0.25s |

### 2. 节奏

- 全局基准帧率 30 FPS
- Easing：进入 `cubicOut`，离开 `cubicIn`，受击 `backOut`
- 不允许动作时长超过 0.6s（爬塔节奏要求）

### 3. UI 动效

| 场景 | 动效 |
|------|------|
| 面板打开 | 透明 0→1 + scale 0.92→1.0，0.18s |
| 按钮点击 | scale 0.95（0.08s），松开回 1.0 |
| 飘字 | 上飘 32 px + 透明 1→0，0.6s |
| 章节切换 | 全屏黑色帘幕 + 章节图标淡入，0.6s |

### 4. 特殊角色

- Boss 入场：scale 0.5→1.0 + 屏震 + 短暂全屏雾化
- 玩家胜利：单帧抬手 + 头顶光柱粒子
- 不做完整的"骨骼跑步"或"翻滚"动画

## Examples

### 正确
> 玩家攻击：tween X +12 px (0.12s, cubicOut) → tween X -12 px (0.18s, cubicIn) + 屏震 6 px

### 错误
> 写一套帧动画做"挥剑 8 帧" → 不符合本项目动效语言，浪费包体

## AI Notes

- 实现走 cocos `tween`；动效逻辑放 `views/` 层，**不**进入 `core/`
- 不要为新角色生成 sprite sheet 动画帧；静帧 + tween 即可

## Checklist

- [ ] 动作时长 ≤ 0.6s
- [ ] 用 tween 不用帧动画
- [ ] Easing 在 §2 范围
- [ ] 动效在 views/ 层
