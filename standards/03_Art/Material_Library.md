# Material_Library — 材质语言库

## Purpose

为所有角色 / 道具 / 场景的"表面材质"提供统一的视觉处理规则，避免同一种材质（如金属）在不同资产上画得截然不同。

## Standards

### 1. 材质总表

| 材质 | 主色相 | 阴影偏移 | 高光 | 内描边 |
|------|--------|---------|------|--------|
| 皮肤 Skin | 暖肉色 | -25% 明度 + 偏冷 | 鼻尖 / 颧骨 1 点 | 否 |
| 头发 Hair | 主色 | -30% 明度 | 1~2 条丝光 | 否 |
| 布料 Cloth | 主色 | -30% 明度 + 偏冷 | 无 / 极弱 | 衣摆与身体交界 |
| 皮革 Leather | 暗褐 / 暗红 | -35% 明度 | 极小 1 点 | 是 |
| 木 Wood | Worn Wood `#5A3E2A` | -40% 明度 | 无 | 仅边角 |
| 金属哑光 Metal Matte | Muted Gold `#B58A3A` 或冷灰 | -40% 偏冷 | 1~2 点小高光 | 是 |
| 金属铭金 Brass | 暖金 | -35% 偏褐 | 长条状高光 | 是 |
| 水晶 / 魔法 Crystal | Cyan Magic | 2~3 层叠色 | 1~2 高光 + 内透光感 | 是（亮内描边） |
| 苔藓 Moss | Moss Green | 不规则斑点 | 无 | 否 |
| 石 Stone | Stone Gray | 大块阴影 + 苔斑 | 无 | 否 |

### 2. 通用规则

- 阴影偏色与主色相反（暖色主体→冷阴影）
- 高光极度克制（详见 [`Character_Art_Guide.md`](Character_Art_Guide.md) §8.1）
- 同一资产内不混用 5 种以上材质
- 任何材质都遵循 Charcoal Outline 外描边

### 3. 章节材质倾向

| 章节 | 偏好材质 |
|------|---------|
| 第 1 章 | 苔藓 / 石 / 木 / 哑光铜 |
| 第 2 章 | 暖金沙 / 象牙砂岩 / 风化浅石 / 青色晶体 |
| 第 3 章 | 冰晶 / 银 / 冷石 |
| 第 4 章 | 深色火山岩 / 熔岩缝 / 火铜 / 焦木 |
| 第 5 章 | 哑金 / 大理石 / 命运紫水晶 |

## Examples

### 正确
> 玩家剑刃 = 冷灰 Metal Matte + 一条蓝青符文 + 内部 1 点高光

### 错误
> 剑刃用纯白 + 长条强反光 → 滑向写实金属

## AI Notes

- AI 容易把所有金属画成"高反光"；本项目所有金属都是**哑光**
- 水晶不能"真透明"；用色彩叠加表达透感

## Checklist

- [ ] 材质处理在本表范围内
- [ ] 阴影偏色与主色相反
- [ ] 同资产 ≤ 5 种材质
