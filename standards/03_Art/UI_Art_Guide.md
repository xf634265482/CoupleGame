# UI_Art_Guide — UI 美术执行指南

## Purpose

执行 VSS `UI_Reference.md`。本文件不复制另一套 UI 视觉规则。

## Standards

- UI 使用深海蓝绘制式幻想面板。
- 阅读区优先高不透明与高对比。
- 轮廓使用 Deep Navy Charcoal `#17243A` 家族。
- 青色命运内光与柔金边饰必须克制。
- 装饰集中在角落和标题节点。
- UI 资产不烘焙真实文字。
- 面板与按钮按目标槽位和 9-slice 设计。
- 新 Gold Standard 锚图批准前，不使用旧 UI Prompt 生成正式资产。

## Examples

正确：高不透明深海蓝战报面板，角落一个柔金纹章，正文区域无纹理。

错误：苔藓石框、密集铆钉、透明毛玻璃和细灰文字混用。
