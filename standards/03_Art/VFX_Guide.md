# VFX_Guide — 特效规范

## Purpose

定义攻击 / 技能 / 状态 / 反馈特效的视觉语言。本项目特效以**轻量粒子 + tween 形变 + 静态贴图叠加**为主。

## Standards

### 1. 特效层级

| 层级 | 用途 | 性能预算 |
|------|------|---------|
| 屏震 Screen Shake | 受击 / 重要反馈 | 0 粒子 |
| 飘字 Floating Text | 数字反馈 | 0 粒子 |
| 单次贴图叠加 | 攻击溅射 / 技能光圈 | 1~3 sprite |
| 短粒子 | Boss 入场 / 章节切换 | ≤ 20 粒子 |
| 不允许 | 全屏粒子风暴 / 连续粒子流 | — |

### 2. 色彩

- 攻击命中：白闪 + 元素色边缘
- 元素色：火 = 火橙 `#E0581E`；冰 = 冰青 `#A8E8F0`；雷 = 哑金 `#B58A3A`；暗 = 鬼火青 `#88E2C7`；命运 = 命运紫 `#7A4FB5`
- 治疗：Buff 绿 `#5FB05C` + 上升粒子
- 危险预警：危险红 `#E04F4F` 闪烁

### 3. 时长

- 攻击命中：0.15s
- 技能：0.30s 主帧 + 0.20s 残留
- Boss 入场：0.6s
- 不超过 0.6s

### 4. 形变与缩放

- 命中环：scale 0 → 1.4，透明 1 → 0
- 元素光圈：scale 0.8 → 1.2 + 旋转 ±20°
- 不做"螺旋飞射"或"连续轨迹"

## Examples

### 正确
> 火球命中 → 白色十字闪光（0.05s）+ 火橙圆环 scale 0→1.4 + 屏震 4 px

### 错误
> 火球留 60 帧火焰拖尾粒子 → 性能超预算 / 视觉过重

## AI Notes

- 特效由代码触发，不依赖 prefab；写在 `views/` 里
- 微信小游戏对粒子性能极敏感，禁止脑补"加点粒子更炫"

## Checklist

- [ ] 单特效 ≤ §1 性能预算
- [ ] 元素色与 §2 一致
- [ ] 总时长 ≤ 0.6s
