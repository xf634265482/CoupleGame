# Item_Art_Guide — 道具美术规范

## Purpose

定义武器 / 装备 / 卷轴 / 遗物 / 消耗品 的视觉规范。

## Standards

### 1. 道具类别

| 类别 | 用途 | 默认 Icon 尺寸 |
|------|------|---------------|
| 武器 Weapon | 玩家攻击 | 106 px |
| 防具 Armor | 玩家防御 | 106 px |
| 卷轴 Scroll | 一次性技能 | 96 px |
| 遗物 Relic | 永久 Buff | 106 px |
| 消耗品 Consumable | 药水 / 食物 | 80 px |
| 关键道具 Key Item | 钥匙 / 任务物 | 96 px |

### 2. 视觉规则

- 走 `Icon_Style_Guide.md` 通用规则
- 主体保持"侧立"或"45° 摆置"角度
- 武器：刀刃朝右上，握柄朝左下
- 卷轴：横向展开 + 火漆 / 符文 + 隐约纸纹
- 遗物：金属 / 水晶 / 古物，有"古老感"
- 消耗品：药瓶必须有清晰瓶身轮廓与液体高光

### 3. 稀有度视觉差异

- 底框色按 `Color_System.md` §4
- 高稀有度可加：1 px 外发光 + 内部 1~2 笔强调高光
- **不**用全屏粒子 / 闪烁动画做稀有度（费性能）

### 4. 描边

- 与角色一致：Charcoal Outline 4~6 px @ 1024
- 内部不同材质交界加细内分隔（如刀刃与握柄）

## Examples

### 正确
> Epic 长剑：紫色稀有底框 + 深炭描边 + 哑金护手 + 蓝青符文刃 + 单笔白色刀光

### 错误
> 把武器堆三件叠放成一个图标 → 违反 Icon §2 单一主体

## AI Notes

- 道具 Prompt 复用 Character_Prompt_Template 的"风格段落"，主体段落用"single centered item"
- 不要为不同稀有度画完全不同的道具；同一道具的稀有度由底框 + 强调色区分

## Checklist

- [ ] 描边与角色一致
- [ ] 稀有度通过底框 + 微强调色表达
- [ ] 主体 32~48 px 仍可识别类别
