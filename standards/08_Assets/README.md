# 08_Assets — 资产规范

## Purpose

定义资产的命名、目录、导入参数、质量门槛。让任何 AI 入库的资产都"放对地方、叫对名字、设对参数"。

## Standards

### 8.0 模块清单

| 文件 | 范围 |
|------|------|
| [`Naming.md`](Naming.md) | 资产命名（与 02_Programming/Naming_Convention 互补） |
| [`Folder_Structure.md`](Folder_Structure.md) | 资产目录结构 |
| [`Import_Settings.md`](Import_Settings.md) | Cocos 导入参数 |
| [`Asset_Quality_Checklist.md`](Asset_Quality_Checklist.md) | 入库前质量门槛 |

### 8.1 元规则

- 任何资产入库前必须过 `Asset_Quality_Checklist.md`
- 命名严格按 `Naming.md`；目录严格按 `Folder_Structure.md`
- 改导入参数必须记录原因
