# Progression — 元进度 / 命运树

## Purpose

定义跨单局的长期成长系统（命运树 / 章节解锁 / 永久遗物）。

## Standards

### 1. 命运树（Destiny Tree）

> 玩家长期成长主轴。元 UI 见 `specs/260610-destiny-tree-ui/`。

- 树状结构，根节点 → 多分支 → 叶节点
- 每节点解锁需"命运碎片"
- 节点效果：
  - 起始 HP / ATK / 能量
  - 解锁新卷轴 / 遗物池
  - 解锁新章节
  - 解锁勇者皮肤

### 2. 命运碎片来源

| 来源 | 数量 |
|------|------|
| 单局结算（按进度） | 5~30 |
| 章节首通 | 100 |
| 章节高难首通 | 200 |
| 每日任务 | 10 |
| 成就 | 20~100 |

### 3. 章节解锁

- 第 1 章默认解锁
- 第 N 章需"完成第 N-1 章 Boss"
- 高难度章节需特定命运树节点

### 4. 不可碾压原则

- 命运树节点**不直接提升伤害**（避免后期碾压）
- 大部分节点是"解锁选项"（新卷轴 / 新遗物 / 新章节）
- 仅起始资源类节点（HP / 能量）允许小幅提升

### 5. 永久遗物

- 通过命运树高级节点解锁
- 单局开始时自动生效
- 每位玩家上限 3 个永久遗物槽

### 6. 勇者皮肤

- 视觉变体，**不**提供数值
- 必须符合 `03_Art/Character_Art_Guide.md`
- 默认棕发蓝金冒险者的身份骨架不可被替代；职业变体必须保留青色命运标志与约 1.9 头身

### 7. 不允许

- ❌ 命运树节点直接 +100% 伤害（破坏 §4）
- ❌ 付费解锁命运节点（不做付费）
- ❌ 永久负面节点
- ❌ "重置树"功能（鼓励一次性的命运选择）

## Examples

### 正确
> "命运之眼"节点：解锁"探查"卷轴（可揭开 3 格迷雾）

### 错误
> "命运之力"节点：永久 +50% 攻击 → 违反 §4

## AI Notes

- 改命运树前必读 `specs/260610-destiny-tree-ui/`
- AI 设计新节点时，先看 §4 不可碾压原则
