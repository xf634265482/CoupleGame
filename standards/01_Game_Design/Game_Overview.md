# Game_Overview — 游戏总览

## Purpose

让任何人 / AI 在 5 分钟内理解《命运之塔》核心循环、节奏、爽点、留存动力。

## Standards

### 1. 一句话

> 一名循着血脉指引的勇者，攀登迷雾中的命运之塔；每一步都是命运的一次审判，每一次远征都让命运树长出新枝。

### 2. 核心循环

```
[选择章节] → [踏入远征] → [迷雾中走格子]
   ↓ 每一格触发事件（战斗 / 宝箱 / 商店 / 陷阱 / 事件）
   ↓ 击败章节 Boss
[远征结算] → [命运树成长] → [回到大厅] → [下一次远征]
```

### 3. 单局节奏

- 单局时长目标：**15~25 分钟**
- 一格事件反馈在 **5~15 秒** 内
- 一章 Boss 战在 **2~4 分钟** 内
- 退出 / 失败都有正反馈（命运碎片入树）

### 4. 章节结构

| 章节 | 主题 | 关键玩法增量 |
|------|------|------------|
| 第 1 章 · 云暮塔庭 | 入门 | 走格子 + 基础战斗 + 宝箱 |
| 第 2 章 · 日照秘境沙海 | 地形 | 沙漠怪物 / 流沙地形 / 沙暴 |
| 第 3 章 · 冰霜回廊 | 控制 | 冰冻 / 移动受限 |
| 第 4 章 · 熔岩深层 | 元素 | 火元素 / 燃烧状态 / 熔岩地块 |
| 第 5 章 · 命运终塔 | 综合 | 多 Boss / 命运抉择 |

### 5. 玩家爽点（设计目标）

1. **每一格的微小决策**：去 / 不去、打 / 跑、开 / 不开
2. **构筑（Build）发现**：卷轴 + 遗物组合带来的"我发现了一个套路"
3. **Boss 攻略**：识别 Boss 机制并破解
4. **章节攻克**：第一次通章的成就感
5. **命运树长枝**：长期收集与解锁

### 6. 留存动力

- **短期**（单局内）：构筑乐趣、宝箱期待
- **中期**（一周）：章节解锁、新卷轴 / 新遗物
- **长期**（一月+）：命运树满成、勇者皮肤、章节高难

### 7. 不做什么

- ❌ 联机 / PVP / 排行榜（违反 PROJECT_CONTEXT 单人定位）
- ❌ 体力 / 抽卡 / 强付费（与轻奇幻调性冲突）
- ❌ 写实战斗 / 血腥死亡
- ❌ 复杂养成（不做装备打孔 / 强化 / 重铸）

## Examples

### 正确判断
> 提议："加一个公会战" → 不符合 §7

### 错误判断
> 提议："简化战斗，只剩自动战斗" → 破坏 §5.1 微决策爽点
