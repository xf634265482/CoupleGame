# Core_Gameplay — 核心玩法循环

## Purpose

定义"一次远征"内的玩法循环与触发规则。

## Standards

### 1. 单局循环（Run Loop）

```
[选章节 + 出征] → [初始化地图 + 起点] →
  [玩家选择移动方向] → [踏入新格] → [触发该格事件] → [事件结算] →
  [更新血量/能量/物品/视野] → [是否到 Boss] →
    否 → 回到"玩家选择"
    是 → [Boss 战] → [章节结算 + 命运碎片入树]
```

### 2. 一格事件类型

| 类型 | 触发率（默认） | 玩家选择 |
|------|------------|---------|
| 空地 Empty | 可定义 | 无 |
| 普通怪 Common Monster | 主体 | 打 / 跑（消耗能量） |
| 精英怪 Elite | 中频 | 打 / 跳过（弃奖励） |
| 宝箱 Chest | 中频 | 开 / 不开（可能陷阱） |
| 商店 Shop | 低频 | 购买 / 离开 |
| 事件 Event | 低频 | 多选项分支 |
| 陷阱 Trap | 低频 | 触发 / 解除（消耗道具） |
| 楼梯 Exit | 终点 | 进入下一层 / Boss |

> 具体概率与配置走 `specs/260608-pve-destiny-expedition/design.md` 与 `cloudfunctions/common/pve/` 配置。

### 3. 行动与回合

- 玩家在地图上**每移动一格 = 一回合**
- 战斗中**双方轮流出招**（玩家 → 敌人 → 玩家 ...）
- 战斗不打断地图（战斗 UI 在地图之上叠加）

### 4. 资源系统

| 资源 | 来源 | 用途 |
|------|------|------|
| HP | 起始 + 治疗 | 受伤死亡 |
| 能量 / 行动点 | 每回合恢复 | 战斗技能 / 卷轴 / 跑路 |
| 金币 | 战斗 / 宝箱 | 商店 |
| 钥匙 | 特殊宝箱 / 商店 | 锁门 / 高级宝箱 |
| 命运碎片 | 远征结算 | 命运树解锁 |

### 5. 死亡 / 失败

- HP ≤ 0 → 远征结束 → 仍获得命运碎片（按进度）
- 不允许"读档"或"复活回到上一格"
- 永久遗物在死亡后仍保留

### 6. 退出 / 撤退

- 允许玩家中途撤退（消耗钥匙 / 卷轴）→ 保留已获得的金币与碎片
- 撤退视为"安全失败"，不扣命运碎片

### 7. 不允许的设计

- ❌ 同一格反复触发同一事件（违反节奏）
- ❌ 一格事件 > 15 秒（违反节奏 §3 of Game_Overview）
- ❌ 强行劝退的"巨型陷阱"（破坏爽点）
- ❌ 单局超过 30 分钟

## Examples

### 正确
> 玩家踏入未探索格 → 视野扩 1 圈 → 显示 "宝箱" → 玩家选"开" → 出宝石 + 金币 → 5 秒内完成

### 错误
> 玩家踏入空地 → 弹出 3 个选项 + 3 段对话 → 30 秒后才能继续走 → 违反节奏

## AI Notes

- 设计新事件类型前先检查 §2 是否够用，能复用就复用
- 任何破坏 §3 单局时长目标的设计都要打回

## Checklist

- [ ] 新事件在 §2 类型范围内
- [ ] 反馈在 5~15 秒内
- [ ] 资源消耗合理（不让玩家"卡死"）
- [ ] 没有强行劝退或反爽点
