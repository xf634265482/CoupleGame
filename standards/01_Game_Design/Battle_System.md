# Battle_System — 战斗系统

## Purpose

定义战斗的轮次、技能、状态、伤害公式与可读性原则。

## Standards

### 1. 轮次

- 双方轮流出招：玩家先手（除某些 Boss 特殊机制）
- 一回合内玩家可执行：移动（地图） / 攻击 / 使用卷轴 / 防御
- 战斗中不能换装备 / 不能离开战斗界面

### 2. 行动类型

| 行动 | 消耗 | 节奏 |
|------|------|------|
| 普通攻击 | 0 能量 | 0.3s 动效 |
| 防御 | 0 能量 | 0.2s |
| 使用卷轴 | 看卷轴 | 0.4s + 特效 |
| 使用消耗品 | 0~1 能量 | 0.3s |
| 撤退（如允许） | 钥匙/卷轴 | 0.5s |

### 3. 伤害公式

> 具体数值走 `specs/260608-pve-destiny-expedition/design.md`；本节定义结构。

```
基础伤害 = 攻击 - 防御
随机抖动 = ±10%
状态加成 = 元素相克 / Buff / 装备特效
最终伤害 = clamp((基础 + 状态) × 抖动, 1, 999)
```

- 最低伤害 1（避免"0 伤害不打架"）
- 上限 999（屏显两位数体验差）
- 暴击：基准 5%，可被装备 + 状态加

### 4. 元素与相克

| 元素 | 克 | 被克 |
|------|----|----|
| 物理 | — | — |
| 火 | 冰 / 自然 | 水 |
| 冰 | 水 / 雷 | 火 |
| 雷 | 水 / 自然 | 地 |
| 暗 | 命运 | 光 |
| 命运 | 暗 | — |

- 相克：伤害 ×1.5
- 被克：伤害 ×0.7
- 不出"相克 ×2 / 被克 ×0.3"（差距过大破坏数值平衡）

### 5. 状态（Status）

| 状态 | 效果 | 持续 |
|------|------|------|
| 燃烧 | 每回合 5% HP 伤害 | 3 回合 |
| 冰冻 | 跳过下回合 | 1 回合 |
| 麻痹 | 25% 攻击落空 | 2 回合 |
| 中毒 | 每回合 3% HP | 4 回合 |
| 护盾 | 抵消 N 伤害 | 用完或战斗结束 |
| 暴怒 | 攻击 +20% | 2 回合 |

- 同状态不叠加，**刷新持续**
- 不同状态可共存（最多 3 个）

### 6. 战斗 UI 可读性

- 玩家 HP / 能量条始终可见
- 敌人 HP 数字 + 条
- 当前回合方高亮
- 伤害飘字 ≥ 30 px，受类型色染色
- 状态图标在角色下方一排

### 7. 不允许

- ❌ 一击秒杀（除非剧情演出）
- ❌ 战斗 > 4 分钟（章节 Boss）
- ❌ 普通怪战斗 > 1 分钟
- ❌ 无视防御的 % HP 伤害（除少数 Boss 机制）
- ❌ 隐藏数值（玩家应能看到关键状态条与数字）

## Examples

### 正确
> 玩家 ATK 25 vs 怪 DEF 10 → 基础 15 → 火克冰 ×1.5 → 22 → 飘字 22 红橙色

### 错误
> 设计一招 "瞬杀目标当前 HP 50%" → 违反 §7 隐性破坏数值结构
