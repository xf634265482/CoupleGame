# Dungeon_System — 迷宫 / 格子系统

## Purpose

定义迷宫地图生成、格子、视野、连接的规则。

## Standards

### 1. 地图

- 每章节是一张固定大小的格子地图（推荐 8×8 ~ 12×12）
- 起点：地图一边的中点
- 终点：Boss 房间在对面边的中点
- 每章节有 2~4 个支线分叉

### 2. 格子类型

见 `Core_Gameplay.md` §2。

- 每个格子的事件类型在远征开始时生成（可种子化以便重放）
- 同一格事件触发一次即消耗（除非特殊配置）

### 3. 视野与迷雾

- 初始视野：玩家所在格 + 周围 1 圈
- 视野范围可通过卷轴 / 遗物扩展
- 未探索格全黑或高斯模糊处理（详见 `03_Art/Environment_Art_Guide.md` §2）
- 已探索但离开后："已知"（去饱和 + 暗化）

### 4. 视野规则

- 视野不是"上帝视角"；离开后只能记住"事件位置"，看不到实时状态
- 不允许全局小地图（破坏 PROJECT_CONTEXT P1）
- Boss 房间在未抵达时只显示位置图标，不显示房间内容

### 5. 连接

- 格子之间四方向连接（不允许斜向，保持心智简单）
- 不允许"密室"（不可达格子）
- 锁门：需要钥匙的格子用门图标表示

### 6. 重生 / 重玩

- 同一章节再次远征 → 全新随机地图（基于新种子）
- 元进度可解锁"种子选择"等高阶玩法
- 不允许"读档"

### 7. 章节难度递增

- 1 章：8×8，怪物 6~8 只
- 2 章：9×9，怪物 8~10 只，加陷阱
- 3 章：10×10，怪物 10~12 只，加控制
- 4 章：11×11，怪物 12~14 只，加视野削弱
- 5 章：12×12，怪物 14~16 只，多 Boss

## Examples

### 正确
> 玩家在地图中央，视野显示周围 1 圈，迷雾覆盖外围；走一步后视野前推

### 错误
> 给玩家一个"按钮 X 显示整张地图" → 违反 §4 / PROJECT_CONTEXT P1

## AI Notes

- 关卡生成器要支持种子化（用 `core/rng.ts`）
- 不要为了"AI 觉得难度更平衡"而修改基础布局规则；走 spec 流程
