# Item_System — 道具系统

## Purpose

定义卷轴 / 遗物 / 装备 / 消耗品 / 关键道具的类别、稀有度、获取与使用规则。

## Standards

### 1. 道具类别

| 类别 | 用途 | 单局上限 | 跨局 |
|------|------|---------|------|
| 武器 Weapon | 装备 | 1 件 | 可解锁 |
| 防具 Armor | 装备 | 1 件 | 可解锁 |
| 卷轴 Scroll | 一次性技能 | 6 个槽位 | 单局消耗 |
| 遗物 Relic | 永久 Buff | 3~5 个槽 | 单局有效 |
| 消耗品 | 药水 / 食物 | 6 个槽 | 单局消耗 |
| 关键道具 | 钥匙 / 任务物 | 不限 | 单局有效 |

### 2. 稀有度

见 `03_Art/Color_System.md` §4。

| 稀有度 | 出现概率（默认） | 数值倾向 |
|--------|--------------|---------|
| Common | 60% | 单一基础效果 |
| Uncommon | 25% | 基础 + 微强化 |
| Rare | 10% | 1 个特别效果 |
| Epic | 4% | 改变玩法的效果 |
| Legendary | 0.9% | 章节级别强力 |
| Mythic | 0.1% | 跨章节最强 |

### 3. 获取来源

- 战斗 → 普通 / 优秀
- 精英战 → 优秀 / 稀有
- 宝箱 → 视宝箱稀有度
- 商店 → 任意（金币购买）
- Boss → 史诗保底
- 事件 → 视分支

### 4. 卷轴

- 一次性使用，使用即消耗
- 6 槽位，超出无法拾取
- 类型：攻击 / 治疗 / 召唤 / 控制 / 移动
- 设计上鼓励"主动决策"，不允许"全自动卷轴"

### 5. 遗物

- 单局有效，远征结束清空（除非元进度解锁"永久遗物"）
- 永久 Buff，被动触发
- 设计鼓励"组合发现"（A + B 触发额外效果）
- 不允许单遗物碾压全局

### 6. 装备

- 武器影响 ATK + 元素
- 防具影响 DEF + 抗性
- 单件覆盖，不堆叠
- 装备稀有度反映在视觉（底框 + 微强调）

### 7. 关键道具

- 钥匙：解锁宝箱 / 门
- 任务物：剧情专用
- 不允许"关键道具被怪物秒走"

### 8. 不允许

- ❌ "自动战斗" / "扫荡" 类道具
- ❌ 单道具效果 > 当前章节难度系数 ×2
- ❌ 永久负面遗物（不符合调性）
- ❌ "随机抽取"获得机制（避免赌博感）

## Examples

### 正确
> 史诗卷轴"破灭一击"：消耗 2 能量，对单体造成 200% ATK 物理伤害；与"暴怒"遗物联动 → 暴怒回合内伤害 +30%

### 错误
> 道具"一键扫平本层" → 违反 §8
