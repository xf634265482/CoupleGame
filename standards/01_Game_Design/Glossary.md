# Glossary — 玩法术语表

## Purpose

让团队、AI、文档使用同一套术语，避免"远征 / 副本 / 关卡 / dungeon"等同义词混乱。

## Standards

| 中文 | 英文 / 代号 | 定义 |
|------|-----------|------|
| 命运之塔 | Fate Tower | 项目正式名 |
| 远征 | expedition | 一次单局游戏 |
| 章节 | chapter | 一段封闭关卡集（Boss 收尾） |
| 房间 / 格子 | room / cell | 地图最小单元 |
| 迷雾 | fog | 视野遮蔽机制 |
| 命运树 | destiny tree | 元进度系统 |
| 命运碎片 | destiny shard | 元进度货币 |
| 勇者 / 玩家 | hero / player | 玩家化身（默认棕发蓝金冒险者，带青色命运标志） |
| 怪物 | monster | 普通敌人 |
| 精英 | elite | 强化版怪物 |
| 章节 Boss | chapter boss | 章节最终敌人 |
| 命运裁决者 | judge | Boss 的统称 / 剧情称呼 |
| 卷轴 | scroll | 一次性技能道具 |
| 遗物 | relic | 单局被动 Buff |
| 永久遗物 | permanent relic | 跨局保留的遗物 |
| 命运抉择 | destiny choice | 关键剧情多选 |
| 元素 | element | 火 / 冰 / 雷 / 暗 / 命运 / 物理 |
| 行动点 / 能量 | energy / AP | 战斗资源 |
| 拍走 | knockback | 敌人击退（如有） |
| 燃烧 / 冰冻 / 麻痹 | burning / frozen / paralyzed | 见 `Battle_System.md` §5 |

## Examples

### 正确
> "本次远征第 3 章 Boss 战胜利，获得 30 命运碎片"

### 错误
> "本次副本第 3 关 Boss 通关，获得 30 经验值" → 用了 4 个不在表里的词
