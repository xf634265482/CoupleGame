# 09_Examples — 示例集

## Purpose

通过具体范例展示其他模块的"正确做法"。本目录是**活资料**：每出一个被项目认可的角色 / 怪物 / UI / Prompt，都应在这里登记一条。

## Standards

### 9.0 模块清单

| 文件 | 范围 |
|------|------|
| [`Character_Examples.md`](Character_Examples.md) | 玩家 / NPC 范例 |
| [`Monster_Examples.md`](Monster_Examples.md) | 怪物 / Boss 范例 |
| [`UI_Examples.md`](UI_Examples.md) | UI 范例 |
| [`Prompt_Examples.md`](Prompt_Examples.md) | 完整 Prompt 范例 |

### 9.1 元规则

- 每条 example 必须指向真实资产路径或具体 Prompt 文本
- 不写"假想例子"
- 出现新风格里程碑 → 必登记
