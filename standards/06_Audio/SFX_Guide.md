# SFX_Guide — 音效

## Purpose

定义所有触发型音效的风格、长度、用途。

## Standards

### 1. 风格

- 卡通幻想 + 木头 / 石头 / 金属 / 魔法残响
- 不写实（无真实金属撞击 / 真实兵刃声）
- 不刺耳

### 2. 类别

| 类别 | 用途 | 长度 |
|------|------|------|
| 按钮点击 | UI | ≤ 0.15s |
| 攻击命中 | 战斗 | ≤ 0.3s |
| 受击 | 战斗 | ≤ 0.3s |
| 治疗 | 战斗 | ≤ 0.5s |
| 卷轴使用 | 战斗 | ≤ 0.5s |
| 宝箱开 | 探索 | ≤ 0.8s |
| 走格 | 探索 | ≤ 0.15s |
| 胜利 | 结算 | ≤ 1.0s |
| 失败 | 结算 | ≤ 1.0s |
| Boss 出场 | 战斗 | ≤ 1.5s |
| 状态触发 | 战斗 | ≤ 0.3s |

### 3. 格式

- m4a，48 kbps
- ≤ 30 KB / 个
- 单声道

### 4. 元素色彩

- 火 SFX：低沉 + 爆裂
- 冰 SFX：清脆 + 颤动
- 雷 SFX：闷雷 + 短脉冲
- 暗 SFX：低吟 + 残响
- 命运 SFX：钟琴 + 长尾

### 5. 不允许

- ❌ SFX > 30 KB
- ❌ 同一事件多个 SFX 同时触发
- ❌ 刺耳 / 失真 / 真实暴力

## Examples

### 正确
> 攻击命中："咚 + 短金属" 0.2s，10 KB，单声道

### 错误
> 攻击命中：1.5s 写实金属撞击声 → 太长 / 写实 / 体积

## AI Notes

- AI 规划 SFX 需求，不生成音频

## Checklist

- [ ] 体积 ≤ 30 KB
- [ ] 长度 ≤ §2
- [ ] 风格匹配
