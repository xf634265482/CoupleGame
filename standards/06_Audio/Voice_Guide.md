# Voice_Guide — 配音 / 旁白

> **Deprecated for current milestone**：命运之塔 M1~M3 不规划配音；本文件保留占位与未来启用规则。

## Purpose

为后续启用配音 / 旁白时提供风格与流程规范。

## Standards

### 1. 启用条件

- 当玩家累计单局 ≥ 1 万次、立项 voice 阶段后再启用
- 初始只做"勇者出征 / 章节首通 / Boss 出场" 3 类短语音

### 2. 风格（未来）

- 中文配音；偏温暖男声 / 中性沉稳
- 不带方言 / 戏剧腔
- 与 BGM 不冲突（语音淡入时 BGM -6 dB ducking）

### 3. 格式（未来）

- m4a，48 kbps，单声道
- 单条 ≤ 50 KB

### 4. 不允许（未来）

- ❌ 全程旁白（破坏单局节奏）
- ❌ 长对话超 5 秒
- ❌ 真人嘶吼 / 死亡惨叫
