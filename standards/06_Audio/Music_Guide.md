# Music_Guide — BGM

## Purpose

锁定 BGM 风格、长度、章节归属。

## Standards

### 1. 风格

- 轻奇幻交响 + 弦乐 + 木笛 + 远古打击乐
- **不**用：电子合成 / 重金属 / 现代流行 / 民谣吉他
- 情感对应当前章节设计文档的章节调性

### 2. 长度

- 单曲 60~120 秒，无缝循环
- 章节有 1~2 首主题曲；Boss 战独立 1 首

### 3. 章节 BGM

| 场景 | 调性 |
|------|------|
| 大厅 | 温暖远古史诗 |
| 第 1 章 | 云暮探索 + 温暖木笛 |
| 第 2 章 | 日照沙海 + 手鼓与轻快低音弦 |
| 第 3 章 | 冷弦 + 钟琴 |
| 第 4 章 | 熔岩压迫 + 强节奏低弦 |
| 第 5 章 | 宏大史诗 |
| Boss 战 | 章节调性 + 强鼓点 |
| 胜利结算 | 短促 5~10s 胜利曲 |

### 4. 格式

- m4a / mp3，96~128 kbps
- ≤ 200 KB / 曲
- 循环点必须无缝（导出前测）

### 5. 切换

- 章节切换 → 淡出 0.5s → 新曲淡入 0.5s
- 战斗触发 → BGM 平行加层（drum stem）而非整曲切换（若实现复杂可降级为整曲切换）
- 进 Boss → 整曲切换 + 屏幕特效

### 6. 不允许

- ❌ 同曲贯穿多章节
- ❌ 单曲 > 200 KB
- ❌ 现代流行风
- ❌ 有人声歌词

## Examples

### 正确
> 第 1 章主题：60s 木笛 + 弦乐，循环点静默 0 ms，无缝

### 错误
> 同一首 80s 史诗曲贯穿 1~3 章 → 玩家会"听腻"

## AI Notes

- AI 不直接生成音乐；只规划需求文档（"需要一首 60s 第 2 章紧张曲"）
- 找音乐时优先 royalty-free + 风格匹配

## Checklist

- [ ] 风格匹配
- [ ] 体积 ≤ 200 KB
- [ ] 无缝循环
- [ ] 章节归属正确
