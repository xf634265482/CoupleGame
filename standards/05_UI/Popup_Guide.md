# Popup_Guide — 弹窗规范

## Purpose

定义弹窗类型、堆叠、入场 / 离场动效与文案。

## Standards

### 1. 弹窗类型

| 类型 | 用途 | 模态 |
|------|------|------|
| 玩法弹窗 | 战斗结算 / 章节完成 / 宝箱获得 | 模态 |
| 对话弹窗 | 事件分支 / 商店 / NPC | 模态 |
| 设置弹窗 | 暂停 / 设置 | 模态 |
| Toast | 提示 / 错误 | 非模态 |
| 确认弹窗 | 销毁 / 撤退 | 模态 |

### 2. 堆叠

- 同时只允许 1 个模态弹窗
- Toast 与模态共存（Toast 在最顶层）
- 弹窗队列：新弹窗等当前关闭后展示

### 3. 入场动效

- 透明 0→1 + scale 0.92→1.0
- 时长 0.18s
- Easing `cubicOut`
- 背景遮罩淡入 0→0.5（黑）

### 4. 离场

- 反向：scale 1.0→0.92 + 透明 1→0
- 时长 0.12s

### 5. 文案规则

- 标题 1 行，≤ 8 字
- 正文 ≤ 60 字
- 按钮文字 ≤ 4 字（"确定" / "取消" / "再来" / "撤退"）
- 用 `Glossary.md` 术语

### 6. 视觉

- 背板按 `03_Art/UI_Art_Guide.md` §4
- 标题哑金底 + 米白字
- 按钮按 `Button_Guide.md`

### 7. 不允许

- ❌ 模态弹窗叠 3 层
- ❌ 弹窗无关闭按钮（除非强制流程）
- ❌ 弹窗内嵌滚动列表 > 屏幕高 80%
- ❌ 弹窗按钮 > 3 个

## Examples

### 正确
> 战斗结算弹窗：标题“楼层结算” + 展示星尘、装备或命痕奖励 + “回到大厅”按钮。

### 错误
> 弹窗显示"加载失败 (errno=ECONNRESET, retry_count=3, last_attempt=...)" → 文案不友好
