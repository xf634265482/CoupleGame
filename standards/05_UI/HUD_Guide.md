# HUD_Guide — 战斗 HUD

## Purpose

定义战斗 / 探索时屏幕常驻 HUD 的元素、位置、优先级。

## Standards

### 1. HUD 元素

| 元素 | 位置 | 必显 |
|------|------|------|
| 章节 / 楼层 / 回合 / 碎片 | 顶部第一层 | 是 |
| 当前怪物卡 | 顶部第二层左约 60% | 是 |
| 灵气 / 金币 / 可选钥匙 | 顶部第二层右约 40% | 是 |
| 状态图标条 | 角色下方 | 战斗中 |
| 最近战报 / 玩家 HP、AP、攻击 | 战场下方约 6:4 | 是 |
| 返回/角色、方向键、攻击/互动/结束回合 | 屏幕底部三列 | 是 |
| 迷雾地图主视图 | 屏幕中央 | 探索中 |

### 2. 布局

- HUD、战场外框、战报和操作区固定
- 地图内容只在固定战场裁切窗口内部移动
- 无怪物时怪物卡保持尺寸，不允许布局跳动
- 顶部避让微信胶囊，底部避让系统手势区

### 3. 颜色

- HP 条：HP 红 `#D24B4B`
- 能量条：MP 蓝 `#5FB8C8`
- 金币：Amber Glow `#E6A553`
- 详见 `Color_System.md` §5

### 4. 动效

- HP 条变化：tween 0.2s
- 受伤：屏震 4 px + HP 数字红闪
- 获得金币：金币图标弹一下 + 飘字

### 5. 不允许

- ❌ HUD 元素遮挡主玩法区
- ❌ 滚动 HUD（必须固定）
- ❌ 关键 HUD 在屏幕最底（误触）

## Examples

### 正确
> 玩家受伤 5 → HP 数字从 50 tween 到 45 + 飘字 "-5" + 屏震 → 0.3s 完成

### 错误
> HP 数字立刻跳变 → 玩家感受不到伤害节奏

## AI Notes

- HUD 是玩家"读取游戏状态"的唯一通道；任何遮挡都是 bug
- 改 HUD 必须真机测试不同尺寸
