# Icon_Size — 图标尺寸规范

## Purpose

让所有图标在不同 UI 场景使用统一尺寸。

## Standards

### 1. 显示尺寸表（@ 设计 1334×750）

| 使用场景 | 显示尺寸 | 源资源尺寸 |
|---------|---------|---------|
| HUD 状态图标 | 48 × 48 | 256 × 256 |
| HUD 主按钮图标 | 64 × 64 | 256 × 256 |
| 物品槽图标 | 96 × 96 | 512 × 512 |
| 卷轴 / 遗物详情 | 128 × 128 | 512 × 512 |
| 章节入口 | 128 × 128 | 512 × 512 |
| 弹窗内主图标 | 192 × 192 | 1024 × 1024 |
| Buff / Debuff | 32 × 32 | 128 × 128 |
| 飘字图标（金币 / 经验） | 32 × 32 | 128 × 128 |

### 2. 适配缩放

- 显示尺寸为基准；不同屏幕通过 Cocos Widget 缩放
- 不允许在源资产上"画几个不同尺寸版本"

### 3. 命中区

- 图标按钮命中区 ≥ 64 × 64（即使图标 48，命中区放大）
- 详情类图标不命中区可设计 = 显示区

### 4. 不允许

- ❌ 在 §1 表外凭感觉用 33 × 33 等奇怪尺寸
- ❌ 图标小于 32 显示尺寸（看不清）
- ❌ 在源资产层硬编码尺寸（让代码缩放）

## Examples

### 正确
> 玩家 HP 旁的 HUD HP 图标显示 48×48，源资产 256×256

### 错误
> 章节入口图标显示 50×50 → 不在表内 / 看不清

## AI Notes

- 新场景需要新尺寸时，先入本表再用
- 缩放交给 Cocos，不要预先生成多分辨率版本

## Checklist

- [ ] 显示尺寸在 §1
- [ ] 源资产在 §1
- [ ] 命中区符合 §3
