# 07_Project — 项目管理

## Purpose

定义项目层的路线图、里程碑、任务流程、发版清单。

## Standards

### 7.0 模块清单

| 文件 | 范围 |
|------|------|
| [`Development_Roadmap.md`](Development_Roadmap.md) | 1~6 个月路线图 |
| [`TODO.md`](TODO.md) | 当前未排期但要做的事 |
| [`Milestones.md`](Milestones.md) | 里程碑定义与验收标准 |
| [`Task_Workflow.md`](Task_Workflow.md) | 任务从立项到合并的流程 |
| [`Release_Checklist.md`](Release_Checklist.md) | 发版前必过清单 |

### 7.1 元规则

- 一切非琐碎工作都立 spec（`specs/<date>-<slug>/`）
- 合并前必读 `Release_Checklist.md`（即使不是版本发布）

## Checklist

- [ ] 当前工作有 spec
- [ ] 知道当前里程碑目标
