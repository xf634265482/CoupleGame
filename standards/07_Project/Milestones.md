# Milestones — 里程碑

## Purpose

定义里程碑节点与验收标准。完成一个 milestone 才进入下一个。

## Standards

### 1. 里程碑列表

| ID | 名称 | 目标 | 验收标准 |
|----|------|------|---------|
| M0 | 规范库 v1 | `standards/` 初版完整 | 9 个模块 + AI_AGENT_RULES + README + PROJECT_CONTEXT 都存在并可用 |
| M1 | 单局闭环 | 第 1 章可玩到 Boss 通关 | 玩家可完整跑完一次第 1 章远征 |
| M2 | 元进度上线 | 命运树 + 永久遗物 | 跨局解锁与生效完整 |
| M3 | 双章可玩 | 章节 1+2 都可通 | 含 Boss、含元素相克 |
| M4 | 美术全量 v1 | 全章节美术达到统一 | 美术覆盖率 100% + 风格统一审核通过 |
| M5 | 音频全量 v1 | BGM/SFX 全章节 | 全部章节有 BGM + 战斗 SFX 完整 |
| M6 | 性能达标 | 真机 60 FPS 战斗 | 中端机 + 5s 启动 |
| M7 | 公开测试 | 邀测 + 反馈迭代 | 反馈闭环 ≥ 100 人次 |
| M8 | 正式发布 | 上线微信 | 提交审核通过 + 运营准备就绪 |

### 2. 验收规则

- 每个 milestone 必须有完成日志（写入 `specs/` 对应 spec 的"完成验收"段）
- 验收未过不能开下一个 milestone

### 3. 不允许

- ❌ 多个 milestone 并行
- ❌ 跳跃 milestone
- ❌ "差不多了"通过验收

## Checklist

- [ ] 当前 milestone 明确
- [ ] 验收标准可量化
- [ ] 完成有日志
