# Development_Roadmap — 路线图

## Purpose

让团队 / AI 在任何时间点都知道"我们在哪一站、下一站是什么"。

> 本文件是**滚动更新**的概览，单次迭代细节走 `specs/`。

## Standards

### 1. 当前阶段（2026-06）

- **正式开发阶段启动**：完成 PVE-only 构建拆分（`specs/260619-pve-only-build`）
- **本月聚焦**：
  - 完成 `standards/` 规范库初版（本目录）
  - PVE 美术 pipeline 全量落地
  - 章节 1~2 玩法稳定可玩

### 2. 短期（接下来 1~2 个月）

- 章节 3 玩法 + Boss 接入
- 命运树 UI 完整版（`specs/260610-destiny-tree-ui/` 收尾）
- 大厅 UI 视觉对齐 `standards/03_Art/UI_Art_Guide.md`
- 音效首批 30 个落地
- 真机性能优化（启动 ≤ 5s / 60 FPS 战斗）

### 3. 中期（3~4 个月）

- 章节 4~5 玩法 + Boss
- 永久遗物系统
- 元进度 UI 完整版
- 公开测试预演

### 4. 长期（5~6 个月）

- 公开测试 → 正式发布
- 多平台扩展评估（H5 / 抖音小游戏）
- 长线运营内容规划

### 5. 不在路线图

- 联机 / PVP（明确不做）
- 抽卡 / 付费养成（明确不做）
- 横屏支持
- 多语言（待用户基础起来再评估）
